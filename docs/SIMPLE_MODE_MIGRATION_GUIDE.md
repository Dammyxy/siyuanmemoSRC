# 简单模式迁移指南

## 概述

从插件版本 X.X.X 开始，简单模式（Simple Mode）已被移除。本指南将帮助您从简单模式平滑迁移到高级模式（Advanced Mode）。

## 为什么移除简单模式？

简单模式的移除是为了：

1. **简化架构**：减少代码复杂度，降低维护成本
2. **提升性能**：高级模式性能更优（< 1ms vs 50-200ms）
3. **增强功能**：高级模式支持更多功能和离线使用
4. **减少问题**：消除模式切换带来的数据不一致问题

## 自动迁移

### 迁移过程

当您升级到新版本后，插件会自动执行以下操作：

1. **检测配置**：检查您是否使用简单模式
2. **触发同步**：自动从 Riff 执行增量同步
3. **更新配置**：将配置更新为高级模式
4. **显示通知**：告知您迁移已完成

### 迁移时间

- 首次加载可能需要几秒钟（取决于卡片数量）
- 迁移过程在后台进行，不会阻塞插件使用
- 迁移完成后会显示通知

## 功能对比

### 简单模式 vs 高级模式

| 特性 | 简单模式（已移除） | 高级模式（现在） |
|------|------------------|----------------|
| 数据源 | Riff API（实时） | 本地存储 + Riff 同步 |
| 调度器 | Riff 原生 | FSRS/SM-15/A-Factor |
| 性能 | 50-200ms | < 1ms |
| 离线使用 | ❌ 不支持 | ✅ 支持 |
| 队列类型 | 2 种 | 5 种 |
| 上下文菜单 | 4 个选项 | 7 个选项 |
| Xiuyuan 多卡片 | ❌ 不支持 | ✅ 支持 |
| 数据同步 | 实时 | 后台混合同步 |

### 您将获得的新功能

✅ **更快的性能**：卡片加载速度提升 98%+  
✅ **离线使用**：无需网络连接即可复习  
✅ **更多队列**：5 种队列类型满足不同需求  
✅ **高级调度**：FSRS v6、SM-15、A-Factor 等算法  
✅ **Xiuyuan 支持**：一个块创建多张卡片  
✅ **更多选项**：7 个上下文菜单选项  

## 迁移后的变化

### 1. 设置界面

**之前**：
```
┌─────────────────────────────────────┐
│ 数据源模式                           │
│ ( ) 简单模式                         │
│ (•) 高级模式                         │
└─────────────────────────────────────┘
```

**现在**：
```
┌─────────────────────────────────────┐
│ 高级模式配置                         │
│ [✓] 启用增量同步                     │
│ [✓] 启用全量同步                     │
│ [✓] 启用双向删除同步                 │
└─────────────────────────────────────┘
```

### 2. 队列类型

**新增队列**：
- **FilterGroup**（筛选复习）：自定义过滤条件
- **NeuralRoam**（神经漫游）：智能关联复习
- **LeechQueue**（难点攻坚）：专注困难卡片

### 3. 上下文菜单

**新增选项**：
- **切换调度器**：在不同调度算法间切换
- **修改卡片类型**：Item/Topic 类型转换
- **设置优先级**：调整卡片优先级

### 4. 同步机制

**新的同步策略**：

1. **增量同步**（Incremental Sync）
   - 触发时机：插件启动、浏览器打开、复习打开
   - 功能：快速获取新卡片
   - 黑名单过滤：防止已删除卡片重新出现

2. **全量同步**（Full Sync）
   - 触发时机：每 24 小时自动执行
   - 功能：检测双向删除 + 清理黑名单
   - 策略：对比 Riff 和本地的所有卡片 ID

3. **删除同步**（Delete Sync）
   - 触发时机：用户删除卡片时
   - 功能：双向删除同步
   - 策略：尝试从 Riff 删除，失败则加入黑名单

## 常见问题

### Q1: 我的数据会丢失吗？

**A**: 不会！迁移过程会自动从 Riff 同步所有卡片到本地存储。您的复习历史和卡片数据都会保留。

### Q2: 迁移失败怎么办？

**A**: 如果迁移失败：
1. 插件会记录错误日志
2. 系统会继续使用高级模式（不会阻塞）
3. 您可以手动触发全量同步来重新获取数据
4. 查看控制台日志了解详细错误信息

### Q3: 我可以继续使用 Riff 吗？

**A**: 可以！高级模式支持与 Riff 的双向同步：
- 从 Riff 同步新卡片到本地
- 将复习结果同步回 Riff
- 双向删除同步

### Q4: 性能会有什么变化？

**A**: 性能会显著提升：
- 打开 SRS 浏览器：从 100-500ms 降至 < 10ms
- 获取下一张卡片：从 50-200ms 降至 < 1ms
- 复习卡片：从 100-300ms 降至 < 10ms

### Q5: 我需要做什么？

**A**: 通常不需要做任何事情！
1. 升级插件到新版本
2. 重启思源笔记
3. 插件会自动迁移
4. 查看迁移通知确认完成

### Q6: 如何手动触发同步？

**A**: 在 SRS 浏览器中：
1. 点击顶部的"手动同步"按钮（增量同步）
2. 或点击"全量同步"按钮（完整同步）

### Q7: 黑名单是什么？

**A**: 黑名单用于防止已删除的卡片重新出现：
- 当您删除卡片时，如果无法从 Riff 删除，会加入黑名单
- 增量同步时会过滤黑名单中的卡片
- 全量同步时会清理黑名单（移除 Riff 中已不存在的 ID）

### Q8: 我可以回退到简单模式吗？

**A**: 不可以。简单模式已从代码库中完全移除。但高级模式提供了更好的功能和性能，我们相信您会喜欢它。

### Q9: 离线使用有什么限制？

**A**: 离线使用时：
- ✅ 可以正常复习卡片
- ✅ 可以查看卡片列表
- ✅ 可以删除卡片
- ❌ 无法从 Riff 同步新卡片
- ❌ 无法同步复习结果到 Riff

恢复网络后，插件会自动同步。

### Q10: 如何查看同步状态？

**A**: 在 SRS 浏览器顶部可以看到同步状态指示器：
- ✅ 同步成功：显示上次同步时间
- ⏳ 同步中：显示进度
- ❌ 同步失败：显示错误和重试按钮

## 故障排除

### 问题 1：迁移通知未显示

**可能原因**：
- 您之前使用的就是高级模式
- 通知被关闭

**解决方法**：
- 检查设置面板，确认配置正确
- 查看控制台日志

### 问题 2：卡片数量不对

**可能原因**：
- 同步未完成
- 黑名单过滤了部分卡片

**解决方法**：
1. 手动触发全量同步
2. 检查黑名单（在设置中）
3. 对比 Riff 中的卡片数量

### 问题 3：同步一直失败

**可能原因**：
- 网络连接问题
- Riff 服务异常
- API 权限问题

**解决方法**：
1. 检查网络连接
2. 重启思源笔记
3. 查看控制台日志
4. 在 GitHub 提交 Issue

### 问题 4：性能没有提升

**可能原因**：
- 卡片数量过多
- 系统资源不足

**解决方法**：
1. 检查卡片数量（建议 < 10000）
2. 清理无效卡片
3. 重启思源笔记

## 手动迁移步骤（如果自动迁移失败）

如果自动迁移失败，您可以手动执行以下步骤：

### 步骤 1：备份数据

```bash
# 备份插件数据目录
cp -r workspace/data/storage/petal/siyuan-plugin-fsrs workspace/data/storage/petal/siyuan-plugin-fsrs.backup
```

### 步骤 2：清除配置

1. 打开设置面板
2. 找到"Riff 集成"部分
3. 确认配置已更新为高级模式

### 步骤 3：手动同步

1. 在 SRS 浏览器中点击"全量同步"
2. 等待同步完成
3. 检查卡片数量是否正确

### 步骤 4：验证

1. 打开 SRS 浏览器
2. 检查卡片列表
3. 尝试复习几张卡片
4. 确认功能正常
