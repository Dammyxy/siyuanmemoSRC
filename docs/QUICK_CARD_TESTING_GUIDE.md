## 📋 测试前准备

### 1. 构建插件

在项目目录下运行:

```bash
cd siyuan-plugin-siyuanmemo
npm run build
```

或者使用开发模式(自动重新构建):

```bash
npm run dev
```

### 2. 安装插件到思源

将构建好的插件复制到思源的插件目录:

**Windows**:
```
C:\Users\[用户名]\AppData\Roaming\SiYuan\data\plugins\siyuan-plugin-siyuanmemo\
```

**macOS**:
```
~/Library/Application Support/SiYuan/data/plugins/siyuan-plugin-siyuanmemo/
```

**Linux**:
```
~/.config/SiYuan/data/plugins/siyuan-plugin-siyuanmemo/
```

### 3. 启用插件

1. 打开思源笔记
2. 点击右上角 `设置` → `集市` → `已下载`
3. 找到 `SiYuan Memo` 插件
4. 点击 `启用`

### 4. 检查配置

1. 打开插件设置面板
2. 找到 `快速制卡` 部分
3. 确认以下选项已启用:
   - ✅ 启用快速制卡
   - ✅ 基础卡片 (>>, <<, <>)
   - ✅ 概念卡片 (::)
   - ✅ 描述符卡片 (;;)
   - ✅ 填空卡片 ({{}}）
   - ✅ 列表模版 (>>>)

## 🧪 测试用例

### 测试 1: 正向卡片 (>>)

**步骤**:
1. 在思源中创建一个新文档
2. 输入以下内容:
   ```
   什么是FSRS？ >> 一种间隔重复算法
   ```
3. 等待 300ms (防抖时间)

**预期结果**:
- ✅ 右上角显示成功提示: "✅ 已创建正向卡片 (>>)"
- ✅ 块被添加到 Riff 卡组
- ✅ 块被标记为卡片 (显示卡片图标)

**验证方法**:
- 打开卡片浏览器,查看是否有新卡片
- 检查卡片元数据: `direction: 'forward'`, `symbolType: '>>>'`

### 测试 10: 符号优先级

**步骤**:
1. 输入包含多个符号的内容:
   ```
   问题 <> 答案
   ```
2. 等待 300ms

**预期结果**:
- ✅ 只创建双向卡片 (<>)
- ✅ 不会创建正向卡片 (>>)

**说明**: 符号优先级: `<>` > `>>` > `<<` > `::` > `;;` > `{{}}`

## 🔍 调试技巧

### 1. 查看控制台日志

打开浏览器开发者工具 (F12):
- 查看 `[AutoCard]` 开头的日志
- 查看 `[RiffSync]` 开头的日志
- 查看 `[TransactionWS]` 开头的日志

### 2. 检查 WebSocket 连接

在控制台中查看:
```
[TransactionWS] Connected to ws://127.0.0.1:6806/ws
```

如果没有连接,检查:
- 思源笔记是否正在运行
- 端口是否正确 (默认 6806)

### 3. 检查卡片存储

在浏览器控制台中运行:
```javascript
// 获取插件实例
const plugin = window.siyuan.ws.app.plugins.find(p => p.name === 'siyuan-plugin-siyuanmemo');

// 查看所有卡片
console.log(plugin.storage.getAllCards());

// 查看特定块的卡片
console.log(plugin.storage.getCardByBlockId('block-id'));
```

### 4. 检查配置

在浏览器控制台中运行:
```javascript
const plugin = window.siyuan.ws.app.plugins.find(p => p.name === 'siyuan-plugin-siyuanmemo');
console.log(plugin.data['fsrs-config'].quickCard);
```

## ⚠️ 常见问题

### 问题 1: 卡片没有创建

**可能原因**:
1. 快速制卡功能未启用
2. 对应符号类型被禁用
3. 防抖时间未到
4. 块已经是卡片
5. WebSocket 未连接

**解决方法**:
1. 检查插件设置
2. 查看控制台日志
3. 等待足够的防抖时间
4. 检查 WebSocket 连接状态

### 问题 2: 列表模版不工作

**可能原因**:
1. 不是列表项
2. 子项少于 2 个
3. 防抖时间未到 (2000ms)

**解决方法**:
1. 确保使用列表项 (`-` 开头)
2. 添加至少 2 个子项
3. 等待 2 秒

### 问题 3: 描述符卡片降级

**说明**: 这是正常行为
- 如果父块不是概念 (`::`),描述符卡片会降级为普通卡片
- 这是设计的功能,不是 bug

### 问题 4: 符号被识别为其他类型

**可能原因**:
- 符号优先级导致

**解决方法**:
- 检查符号优先级顺序
- 使用更高优先级的符号
