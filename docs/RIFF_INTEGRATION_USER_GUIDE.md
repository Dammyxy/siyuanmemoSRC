# Riff 集成用户指南

## 简介

本指南帮助用户理解和使用 FSRS 插件的 Riff 集成功能。

## 什么是 Riff？

Riff 是思源笔记的原生闪卡系统，提供基础的间隔重复学习功能。FSRS 插件通过 Riff 解耦架构，可以灵活地与 Riff 系统集成。

## 快速开始

### 1. 打开设置面板

在思源笔记中：
1. 点击顶部菜单栏的"插件"
2. 找到"FSRS 插件"
3. 点击"设置"按钮

### 2. 配置 Riff 集成

在设置面板中找到"Riff 集成"部分：

**选择运行模式**：
- 禁用：不使用 Riff，完全独立运行
- 数据同步：使用 Riff 作为数据源，本地调度
- Riff 调度器：使用 Riff 原生调度

**选择数据源模式**（仅数据同步和 Riff 调度器模式）：
- 仅到期：只获取到期的卡片（推荐）
- 所有卡片：获取所有卡片
- 增量更新：定期同步新卡片

**同步选项**：
- 双向同步：将本地调度结果同步到 Riff
- 增量更新间隔：设置自动同步间隔（毫秒）

### 3. 保存设置

点击"保存"按钮，配置立即生效，无需重启。

## 运行模式详解

### 模式 1：禁用（推荐新用户）

**特点**：
- 完全独立运行，不依赖 Riff
- 支持所有 FSRS 高级功能
- 支持 Xiuyuan 多卡片功能
- 性能最优

**适合人群**：
- 不使用思源原生 Riff 系统
- 追求最佳性能和稳定性
- 需要使用高级功能

**使用步骤**：
1. 选择"禁用"模式
2. 保存设置
3. 开始创建和复习卡片

### 模式 2：数据同步（推荐高级用户）

**特点**：
- 使用 Riff 作为数据源
- 使用本地 FSRS 调度器
- 可选同步结果到 Riff
- 支持 Xiuyuan 多卡片功能

**适合人群**：
- 同时使用 FSRS 和 Riff
- 希望在 Riff 中查看复习记录
- 需要数据备份

**使用步骤**：
1. 选择"数据同步"模式
2. 选择数据源模式（推荐"仅到期"）
3. 开启"双向同步"（可选）
4. 保存设置
5. 开始复习

**注意事项**：
- Riff 同步失败不影响本地数据
- Riff 只能存储部分调度参数（due 字段）
- 需要网络连接（同步时）

### 模式 3：Riff 调度器（简单模式）

**特点**：
- 使用 Riff 原生调度算法
- 与 Riff 生态完全兼容
- 简单模式（一个块 = 一张卡片）

**适合人群**：
- 主要使用 Riff 原生功能
- 不需要高级功能
- 简单使用场景

**使用步骤**：
1. 选择"Riff 调度器"模式
2. 选择数据源模式（推荐"所有卡片"）
3. 保存设置
4. 开始复习

**限制**：
- 不支持 Xiuyuan 多卡片功能
- 不支持 FSRS 高级功能
- 依赖 Riff 系统

## 数据源模式选择

### 仅到期（推荐）

**优点**：
- 性能最优
- 只显示需要复习的卡片
- 适合日常复习

**缺点**：
- 看不到未到期的卡片
- 不适合浏览和管理

**使用场景**：
- 日常复习
- 追求性能
- 卡片数量较多

### 所有卡片

**优点**：
- 数据完整
- 可以浏览所有卡片
- 适合管理和统计

**缺点**：
- 性能较差（卡片多时）
- 数据量大

**使用场景**：
- 浏览卡片
- 管理卡片
- 统计分析

### 增量更新

**优点**：
- 性能较好
- 自动同步新卡片
- 适合大量卡片

**缺点**：
- 需要定期同步
- 配置稍复杂

**使用场景**：
- 卡片数量很多
- 经常添加新卡片
- 需要自动同步

## 使用技巧

### 技巧 1：选择合适的模式

**新用户**：
- 推荐模式 1（禁用）
- 简单易用，功能完整

**高级用户**：
- 推荐模式 2（数据同步）
- 灵活配置，功能强大

**Riff 用户**：
- 推荐模式 3（Riff 调度器）
- 与 Riff 生态兼容

### 技巧 2：优化性能

**卡片数量少（< 1000）**：
- 使用"所有卡片"模式
- 方便浏览和管理

**卡片数量多（> 1000）**：
- 使用"仅到期"模式
- 或使用"增量更新"模式

**追求极致性能**：
- 使用模式 1（禁用）
- 完全本地运行

### 技巧 3：数据备份

**方法 1：使用模式 2**
- 开启"双向同步"
- 自动备份到 Riff

**方法 2：手动备份**
- 备份插件数据目录
- 定期导出数据

### 技巧 4：故障排除

**Riff 同步失败**：
1. 检查网络连接
2. 检查 Riff 服务状态
3. 查看控制台日志
4. 不用担心，本地数据不受影响

**性能问题**：
1. 切换到"仅到期"模式
2. 减少增量更新频率
3. 考虑使用模式 1

**数据不一致**：
1. 检查同步状态
2. 手动触发增量更新
3. 重启思源笔记

## 常见问题

### Q1: 我应该选择哪个模式？

A: 根据使用场景选择：
- 不使用 Riff → 模式 1（禁用）
- 需要 Riff 备份 → 模式 2（数据同步）
- 主要使用 Riff → 模式 3（Riff 调度器）

### Q2: 可以随时切换模式吗？

A: 可以。在设置面板中切换模式，保存后立即生效，无需重启。

### Q3: Riff 同步失败会丢失数据吗？

A: 不会。本地数据不受影响，Riff 同步失败只会记录警告。

### Q4: 模式 3 为什么不支持 Xiuyuan？

A: Riff 原生调度采用简单模式（一个块 = 一张卡片），与 Xiuyuan 的多卡片设计不兼容。如需使用 Xiuyuan，请选择模式 1 或模式 2。

### Q5: 如何查看同步状态？

A: 在复习界面可以看到同步状态指示器，显示最后同步时间和失败警告（如果有）。

### Q6: 增量更新间隔设置多少合适？

A: 建议设置：
- 频繁添加卡片：30 分钟（1800000 毫秒）
- 正常使用：1 小时（3600000 毫秒）
- 偶尔添加：2 小时（7200000 毫秒）

### Q7: Riff 只能存储 due 字段吗？

A: 是的。目前 Riff API 只支持更新 due（到期时间）字段，不支持更新 state、reps、lapses 等字段。这是 Riff 系统的限制。

### Q8: 如何手动触发增量更新？

A: 在设置面板的"Riff 集成"部分，点击"立即更新"按钮。

### Q9: 模式 2 的双向同步是实时的吗？

A: 是的。每次复习后，如果开启了双向同步，会立即尝试同步到 Riff。同步失败不影响本地数据。

### Q10: 可以同时使用多个数据源吗？

A: 不可以。每次只能选择一个数据源模式。但可以随时切换。

## 高级配置

### 自定义配置文件

如果需要更精细的控制，可以直接编辑配置文件：

**配置文件位置**：
```
workspace/data/storage/petal/siyuan-plugin-fsrs/settings.json
```

**配置示例**：
```json
{
  "scheduler": {
    "defaultScheduler": "fsrs-v5",
    "riffIntegration": {
      "mode": "data-only",
      "dataSourceMode": "due-only",
      "syncToRiff": true,
      "useRiffScheduler": false,
      "incrementalUpdateInterval": 3600000
    }
  }
}
```

### 配置参数说明

| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| mode | string | 运行模式 | 'disabled' |
| dataSourceMode | string | 数据源模式 | 'due-only' |
| syncToRiff | boolean | 是否同步到 Riff | false |
| useRiffScheduler | boolean | 是否使用 Riff 调度器 | false |
| incrementalUpdateInterval | number | 增量更新间隔（毫秒） | 3600000 |

## 故障排除

### 问题 1：Riff 同步一直失败

**可能原因**：
- 网络连接问题
- Riff 服务未启动
- API 权限问题

**解决方法**：
1. 检查网络连接
2. 重启思源笔记
3. 检查 Riff 服务状态
4. 查看控制台日志

### 问题 2：性能很慢

**可能原因**：
- 卡片数量太多
- 使用"所有卡片"模式
- 频繁同步

**解决方法**：
1. 切换到"仅到期"模式
2. 增加增量更新间隔
3. 考虑使用模式 1（禁用）

### 问题 3：数据不一致

**可能原因**：
- 同步失败
- 配置错误
- 缓存问题

**解决方法**：
1. 手动触发增量更新
2. 检查配置设置
3. 清除缓存并重启

### 问题 4：Xiuyuan 功能不可用

**可能原因**：
- 使用了模式 3（Riff 调度器）

**解决方法**：
1. 切换到模式 1 或模式 2
2. 保存设置
3. 重新创建 Xiuyuan 卡片
