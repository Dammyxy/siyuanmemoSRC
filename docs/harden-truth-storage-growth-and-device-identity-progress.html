Accepted architecture

  • Temporary SQLite is a disposable projection, not canonical truth.
  • Worker is the only formal storage mutation authority.
  • Each business command has one mutation ID, one SQL transaction, and one replayable durability unit.
  • journaled means SQL plus complete delta is durable; truth-committed means canonical truth outputs verify.
  • Canonical truth uses append-only Review facts plus compactable Card/Schedule/Queue state and tombstones.
  • Plugin installation identity is redundantly stored in IndexedDB and localStorage; SiYuan System.ID is fingerprint evidence only.
