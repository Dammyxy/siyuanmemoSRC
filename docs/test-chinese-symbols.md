# 中文符号测试

## 测试用例

1. 正向卡片（英文）：`问题 >> 答案`
2. 正向卡片（中文）：`问题》》答案`

3. 反向卡片（英文）：`答案 << 问题`
4. 反向卡片（中文）：`答案《《问题`

5. 双向卡片（英文）：`术语 <> 定义`
6. 双向卡片（中文）：`术语《》定义`

7. 概念卡片（英文）：`概念 :: 定义`
8. 概念卡片（中文）：`概念：：定义`

9. 描述符卡片（英文）：`属性 ;; 描述`
10. 描述符卡片（中文）：`属性；；描述`

11. 多行卡片（英文）：`问题 >>>`
12. 多行卡片（中文）：`问题》》》`

## 支持的符号对照表

| 英文符号 | 中文符号 | 用途 |
|---------|---------|------|
| `>>` | `》》` | 正向卡片 |
| `<<` | `《《` | 反向卡片 |
| `<>` | `《》` | 双向卡片 |
| `::` | `：：` | 概念卡片 |
| `;;` | `；；` | 描述符卡片 |
| `>>>` | `》》》` | 多行卡片 |
