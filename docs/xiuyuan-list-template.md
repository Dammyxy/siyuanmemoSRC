# Xiuyuan 列表模板卡

## 快速开始

### 创建列表模板卡

1. 创建列表结构（至少 2 个子项）：
   ```markdown
   - 什么是 FSRS？
     - FSRS 是一种间隔重复算法
     - 它基于记忆遗忘曲线
     - 可以优化复习时间
   ```

2. 右键点击父列表项 → "创建列表模版卡"

3. 自动创建 3 张卡片：
   - 卡片 1：问题 = "什么是 FSRS？" | 答案 = "FSRS 是一种间隔重复算法"
   - 卡片 2：问题 = "什么是 FSRS？" | 答案 = "它基于记忆遗忘曲线"
   - 卡片 3：问题 = "什么是 FSRS？" | 答案 = "可以优化复习时间"

## 核心概念

### 一对多关系

```
1 个父列表项（问题）
  ├─ 子列表项 1 → 卡片 1
  ├─ 子列表项 2 → 卡片 2
  └─ 子列表项 3 → 卡片 3

= 1 个 Xiuyuan + 3 张独立的 FSRSCard
```

### 独立调度

每张卡片有独立的：
- 卡片 ID
- FSRS 状态（难度、稳定性）
- 复习历史
- 到期时间

## 复习体验

1. **显示问题**：父列表项内容
2. **点击"显示答案"**：在问题下方显示对应的子列表项
3. **评分**：按照 FSRS 算法独立调度

## 适用场景

- **知识点拆分**：一个概念的多个方面
- **定义列举**：一个术语的多个定义
- **步骤分解**：一个流程的多个步骤
- **特征描述**：一个事物的多个特征

## 技术细节

### 数据结构

每张卡片的 meta 包含：
```typescript
{
  xiuyuanID: string,           // 所属 Xiuyuan
  frontBlockIDs: [parentId],   // 问题块
  backBlockIDs: [childId],     // 答案块（每张卡片不同）
  fieldMapping: {
    question: parentId,
    answer: childId
  }
}
```

### 卡片 ID 格式

`xy_card_{xiuyuanID}_{index}_{timestamp}_{random}`

示例：`xy_card_xy_1771059401526_re5m75_0_1771059401526_pyknjr`

## 限制

- 仅支持一级子列表项（不递归）
- 至少需要 2 个子列表项
- 父列表项和子列表项都必须有内容
