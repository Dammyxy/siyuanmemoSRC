# Riff 集成功能说明

## 概述

本插件提供了强大的 Riff 集成功能，支持两种使用模式，满足不同用户的需求。

## 核心特性

### 🎯 两种模式

#### 高阶模式（Advanced Mode）
- **本地调度器**：使用 FSRS、SM-15 或 A-Factor 算法
- **混合同步**：结合增量同步和全量同步，性能与一致性兼顾
- **双向删除**：插件和 Riff 的删除操作自动同步
- **离线可用**：完全支持离线复习
- **极致性能**：本地读取，响应速度 < 100ms

#### 简单模式（Simple Mode）
- **Riff 调度器**：直接使用 Riff 的原生调度算法
- **开箱即用**：无需配置，启用即可使用
- **自动管理**：所有数据和调度由 Riff 管理
- **实时同步**：操作立即同步到 Riff

### 🔄 混合同步方案（高阶模式）

#### 增量同步（Incremental Sync）
- **快速获取新卡片**：只同步自上次以来的新卡片
- **自动触发**：插件启动、打开浏览器、打开复习界面时自动执行
- **黑名单过滤**：防止已删除卡片重新出现
- **性能优化**：同步时间 < 1 秒

#### 全量同步（Full Sync）
- **检测双向删除**：对比 Riff 和本地的所有卡片
- **自动清理黑名单**：清理 Riff 中已不存在的 ID
- **定期执行**：默认每 24 小时自动执行
- **数据一致性**：确保本地和 Riff 数据完全一致

#### 删除同步（Delete Sync）
- **双向删除**：插件删除 → Riff 删除，Riff 删除 → 本地删除
- **黑名单后备**：删除失败时自动加入黑名单
- **自动恢复**：网络恢复后自动处理

### 🛡️ 黑名单机制

- **智能防护**：防止已删除卡片重新出现
- **自动清理**：全量同步时自动清理
- **不会无限增长**：定期维护，保持精简

## 快速开始

### 1. 选择模式

打开插件设置 → Riff 集成 → 选择模式：

- **追求性能和离线使用** → 选择高阶模式
- **追求简单和开箱即用** → 选择简单模式

### 2. 配置同步策略（高阶模式）

高阶模式提供丰富的配置选项：

**增量同步**：
- 启用/禁用自动同步
- 选择触发时机（插件启动、浏览器打开、复习打开）
- 启用/禁用黑名单过滤

**全量同步**：
- 设置同步间隔（12h、24h、48h、7天）
- 启用/禁用黑名单清理

**删除同步**：
- 启用/禁用双向删除
- 启用/禁用黑名单后备

### 3. 开始使用

配置完成后，插件会自动处理同步：

- 日常使用：增量同步在后台自动运行
- 定期维护：全量同步定期执行
- 删除操作：自动同步到 Riff

您也可以随时手动触发同步：

- 点击"手动同步"按钮 → 增量同步
- 点击"全量同步"按钮 → 全量同步

## 同步状态指示器

在 SRS 浏览器顶部，实时显示同步状态：

- ✅ **同步成功**：显示上次同步时间和统计信息
- ⏳ **同步中**：显示同步进度
- ❌ **同步失败**：显示错误信息和重试按钮
- 🔄 **全量同步**：显示详细统计（新增、删除、清理）

## 使用场景

### 场景 1：日常复习（高阶模式）

1. 打开思源笔记（自动增量同步）
2. 打开 SRS 浏览器（查看卡片）
3. 开始复习（使用本地调度器）
4. 复习结果自动保存到本地

### 场景 2：离线使用（高阶模式）

1. 在有网络时完成一次同步
2. 断开网络
3. 正常使用 SRS 浏览器和复习功能
4. 恢复网络后自动同步

### 场景 3：多设备同步（高阶模式）

1. 设备 A：复习卡片，执行全量同步
2. 设备 B：打开插件，自动增量同步
3. 设备 B：获取设备 A 的新卡片

### 场景 4：简单使用（简单模式）

1. 启用简单模式
2. 打开 SRS 浏览器（自动从 Riff 获取）
3. 开始复习（使用 Riff 调度器）
4. 复习结果自动同步到 Riff

## 技术架构

### 高阶模式架构

```
Riff 系统（数据源）
    ↓ 后台混合同步
本地存储（主数据）
    ↓ 直接读取（极快）
SRS 浏览器 / 复习界面
```

### 简单模式架构

```
Riff 系统（数据源 + 调度器）
    ↓ 实时获取
SRS 浏览器 / 复习界面
```

### 核心组件

- **HybridSyncService**：混合同步服务，管理增量/全量/删除同步
- **LocalStorageDataSource**：本地存储数据源，高性能读取
- **RiffDataSource**：Riff 数据源，实时获取
- **ConfigMigrator**：配置迁移器，自动迁移旧配置
- **SyncStatusIndicator**：同步状态指示器，实时显示状态

## 错误处理

### 同步失败

- 自动重试机制
- 友好的错误提示
- 不影响本地操作

### 删除失败

- 自动加入黑名单
- 防止卡片重新出现
- 全量同步时自动清理

### 网络断开

- 高阶模式：完全可用（离线）
- 简单模式：显示友好提示

## 常见问题

### Q: 高阶模式和简单模式有什么区别？

**A**: 高阶模式使用本地调度器和混合同步，性能更好，支持离线；简单模式使用 Riff 调度器，开箱即用，需要网络。

### Q: 同步会覆盖我的本地数据吗？

**A**: 不会！增量同步只添加新卡片，全量同步遵循"Riff 有但本地没有 → 添加，本地有但 Riff 没有 → 删除，都有 → 保留本地"的原则。

### Q: 黑名单是什么？会无限增长吗？

**A**: 黑名单用于记录删除失败的卡片 ID，防止它们重新出现。不会无限增长，全量同步会自动清理。

### Q: 同步失败怎么办？

**A**: 检查网络连接和 Riff 服务状态，查看错误提示，点击重试按钮，或查看日志排查问题。
