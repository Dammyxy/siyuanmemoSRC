## Phase 8.1: 集成测试 - 完整工作流

### 测试目标
验证从创建卡片到复习的完整流程正常工作。

### 测试步骤

#### 1. 创建新卡片
- [ ] 创建一张 Item 类型卡片
- [ ] 创建一张 Topic 类型卡片
- [ ] 验证卡片成功保存到数据库
- [ ] 验证卡片显示在复习队列中

**预期结果**：
- Item 卡片使用配置的调度器（默认 fsrs-v6）
- Topic 卡片自动使用 A-Factor v2 调度器

#### 2. 复习卡片
- [ ] 打开复习界面
- [ ] 复习 Item 卡片，选择不同评分（Again, Hard, Good, Easy）
- [ ] 复习 Topic 卡片，选择不同评分
- [ ] 验证下次复习时间计算正确

**预期结果**：
- 评分后卡片状态正确更新
- 下次复习时间符合 FSRS v6 算法预期
- Topic 卡片使用 A-Factor v2 算法计算间隔

#### 3. 检查调度准确性
- [ ] 查看卡片详情，检查调度参数（difficulty, stability）
- [ ] 验证参数值在合理范围内
- [ ] 检查复习历史记录完整

**预期结果**：
- FSRS v6 参数正确保存
- 历史记录包含所有复习信息

#### 4. 数据持久化
- [ ] 重启插件
- [ ] 验证卡片数据正确加载
- [ ] 验证复习队列正确恢复
- [ ] 验证调度器配置正确加载

**预期结果**：
- 所有数据正确持久化
- 重启后功能正常

## Phase 8.2: 性能测试 - 无性能回退

### 测试目标
验证 FSRS v6 升级后没有性能下降。

### 测试步骤

#### 1. 大量卡片测试
- [ ] 准备 1000+ 张卡片的测试数据
- [ ] 测量插件启动时间
- [ ] 测量队列加载时间
- [ ] 测量单张卡片复习响应时间

**性能基准**：
- 启动时间：< 2 秒
- 队列加载（1000 卡片）：< 1 秒
- 单卡复习响应：< 100ms

#### 2. 迁移性能测试
- [ ] 准备包含旧格式数据的配置文件
- [ ] 测量配置迁移时间
- [ ] 测量卡片数据迁移时间
- [ ] 验证迁移后数据正确性

**性能基准**：
- 配置迁移：< 100ms
- 卡片迁移（1000 卡片）：< 2 秒

#### 3. 内存使用监控
- [ ] 使用开发者工具监控内存使用
- [ ] 长时间运行插件（30 分钟）
- [ ] 检查是否有内存泄漏
- [ ] 验证内存使用在合理范围

**内存基准**：
- 初始内存：< 50MB
- 稳定运行内存：< 100MB
- 无明显内存泄漏
