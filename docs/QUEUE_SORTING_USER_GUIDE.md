# 队列排序功能使用指南

## 功能概述

队列排序功能允许你自定义复习卡片的顺序。在浏览器中应用的排序会自动同步到复习界面，确保你按照期望的顺序复习卡片。

## 支持的队列类型

### 动态队列（临时排序）
- **提取练习** (Retrieval Practice)
- **渐进学习** (Incremental Learning)
- **分组队列** (Filter Group)

排序存储在内存中，重启插件后恢复默认顺序。

### 静态队列（持久化排序）
- **最终训练** (Final Drill)
- **神经漫游** (Neural Roam)

排序持久化到本地存储，重启插件后保持自定义顺序。

## 使用方法

### 1. 在浏览器中应用排序

#### 方法 A: 点击列头排序
1. 打开 SRS 浏览器 (快捷键: `Alt+B`)
2. 选择要排序的队列（如"提取练习"）
3. 点击列头（如"标题"、"到期时间"、"难度"）
4. 再次点击可切换升序/降序

#### 方法 B: 右键菜单排序
1. 在浏览器中右键点击列头
2. 选择"排序方式"
3. 选择排序字段和顺序

### 2. 在复习界面中查看

1. 打开复习界面 (快捷键: `Alt+R`)
2. 复习界面会自动应用浏览器中的排序
3. 卡片按照自定义顺序依次显示

### 3. 清除自定义排序

#### 方法 A: 在浏览器中清除
1. 在浏览器中右键点击列头
2. 选择"清除排序"

#### 方法 B: 重启插件（仅动态队列）
- 动态队列的排序会在重启后自动清除
- 静态队列的排序会保持

## 使用场景

### 场景 1: 按难度复习
```
1. 在浏览器中选择"提取练习"队列
2. 点击"难度"列头，按难度升序排序
3. 打开复习界面，从最简单的卡片开始复习
```

### 场景 2: 按到期时间复习
```
1. 在浏览器中选择"提取练习"队列
2. 点击"到期时间"列头，按到期时间升序排序
3. 打开复习界面，优先复习最早到期的卡片
```

### 场景 3: 按标题字母顺序复习
```
1. 在浏览器中选择"提取练习"队列
2. 点击"标题"列头，按标题升序排序
3. 打开复习界面，按字母顺序复习卡片
```

### 场景 4: 自定义复习顺序
```
1. 在浏览器中选择"最终训练"队列
2. 手动拖拽卡片调整顺序（如果支持）
3. 或使用多次排序组合出期望的顺序
4. 打开复习界面，按自定义顺序复习
5. 排序会持久化，下次打开仍然有效
```

## 技术说明

### 排序同步机制

1. **队列实例共享**
   - 浏览器和复习界面使用同一个队列实例
   - 通过 `UnifiedDataSourceManager` 单例管理

2. **观察者模式**
   - 排序操作触发 `queue-changed` 事件
   - 复习界面监听事件并自动刷新

3. **缓存失效**
   - 排序后自动失效缓存
   - 下次获取卡片时应用新排序

### 排序持久化

#### 动态队列
- 排序存储在 `customOrder` 属性（内存）
- 重启插件后恢复默认顺序（按到期时间）

#### 静态队列
- 排序存储在 localStorage
- 重启插件后保持自定义顺序
- 可以手动清除排序恢复默认

## 常见问题

### Q: 为什么我的排序在重启后消失了？
A: 如果你使用的是动态队列（提取练习、渐进学习、分组队列），排序是临时的，重启后会恢复默认顺序。如果需要持久化排序，请使用静态队列（最终训练、神经漫游）。

### Q: 如何恢复默认排序？
A: 
- 动态队列：重启插件或在浏览器中右键点击列头选择"清除排序"
- 静态队列：在浏览器中右键点击列头选择"清除排序"

### Q: 排序会影响卡片的调度算法吗？
A: 不会。排序只影响卡片的显示顺序，不会改变卡片的到期时间、难度等调度参数。

### Q: 我可以同时对多个字段排序吗？
A: 目前只支持单字段排序。如果需要多字段排序，可以先按次要字段排序，再按主要字段排序。

### Q: 排序后评分会影响顺序吗？
A: 评分后卡片会从队列中移除（根据评分结果重新调度），不会影响剩余卡片的排序顺序。
