## 基础问题

### Q1: 什么是 Riff 集成？

**A**: Riff 集成是本插件提供的功能，允许您将 Riff（思源笔记的官方间隔重复系统）中的卡片同步到本地，并在本地进行复习。

**核心功能**：
- 📥 从 Riff 导入卡片
- 🔄 双向同步数据
- 🎯 灵活选择使用模式
- 🚀 优化性能

### Q2: 高阶模式和简单模式有什么区别？

**A**: 

| 特性 | 高阶模式 | 简单模式 |
|------|---------|---------|
| 调度器 | 本地调度器（FSRS/SM-15/A-Factor） | Riff 原生调度器 |
| 数据存储 | 本地 + Riff 同步 | Riff 云端 |
| 离线使用 | ✅ 支持 | ❌ 不支持 |
| 性能 | ⚡ 极快 | 🌐 依赖网络 |
| 配置 | 中等复杂度 | 简单 |

**选择建议**：
- 追求性能和离线使用 → 高阶模式
- 追求简单和开箱即用 → 简单模式

### Q3: 我应该选择哪种模式？

**A**: 

**选择高阶模式，如果您：**
- ✅ 想使用高级调度算法（FSRS、SM-15、A-Factor）
- ✅ 需要离线复习功能
- ✅ 追求极致的性能体验
- ✅ 愿意了解和配置同步策略

**选择简单模式，如果您：**
- ✅ 刚开始使用间隔重复
- ✅ 不想了解复杂的配置
- ✅ 主要在线使用
- ✅ 信任 Riff 的原生调度算法

### Q4: 两种模式可以随时切换吗？

**A**: 可以，但需要注意：

**从高阶模式切换到简单模式**：
- ⚠️ 本地的复习记录不会同步到 Riff
- ⚠️ 本地的调度数据会丢失
- ✅ 卡片数据会保留

**从简单模式切换到高阶模式**：
- ⚠️ Riff 的复习记录不会同步到本地
- ✅ 会从 Riff 重新同步所有卡片
- ✅ 可以开始使用本地调度器

**建议**：选择一种模式后长期使用，避免频繁切换。

### Q5: Riff 集成会影响我现有的卡片吗？

**A**: 不会！

- ✅ 现有的本地卡片完全保留
- ✅ 现有的复习记录完全保留
- ✅ Riff 中的卡片不受影响
- ✅ 同步是增量的，不会覆盖现有数据

## 同步问题

### Q6: 什么是增量同步？

**A**: 增量同步是一种快速同步方式，只获取自上次同步以来的新卡片。

**特点**：
- ⚡ 速度快（只获取新卡片）
- 🛡️ 保护本地数据（不覆盖已有卡片）
- 🚫 使用黑名单过滤已删除卡片

**触发时机**：
- 插件启动时
- 打开 SRS 浏览器时
- 打开复习界面时
- 手动点击"同步"按钮

### Q7: 什么是全量同步？

**A**: 全量同步是一种完整同步方式，对比 Riff 和本地的所有卡片，检测差异。

**特点**：
- 🔍 检测双向删除
- 🧹 自动清理黑名单
- ✅ 确保数据一致性

**触发时机**：
- 每 24 小时自动触发（可配置）
- 手动点击"全量同步"按钮

### Q8: 增量同步和全量同步有什么区别？

**A**: 

| 特性 | 增量同步 | 全量同步 |
|------|---------|---------|
| 速度 | ⚡ 快 | 🐢 慢 |
| 数据量 | 只获取新卡片 | 获取所有卡片 |
| 检测删除 | ❌ 不检测 | ✅ 检测 |
| 清理黑名单 | ❌ 不清理 | ✅ 清理 |
| 适用场景 | 日常使用 | 定期维护 |

**建议**：
- 日常使用增量同步（快速）
- 定期执行全量同步（确保一致性）

### Q9: 同步失败怎么办？

**A**: 

**步骤 1：检查网络连接**
- 确保网络正常
- 尝试访问其他网站

**步骤 2：检查 Riff 服务**
- 确保 Riff 服务可访问
- 检查 Riff 配置是否正确

**步骤 3：查看错误提示**
- 查看同步状态指示器的错误信息
- 根据提示排查问题

**步骤 4：手动重试**
- 点击"重试"按钮
- 或手动触发同步

**步骤 5：查看日志**
- 打开浏览器控制台（F12）
- 搜索 `[HybridSync]` 查看详细日志

**常见错误**：
- `网络错误`：检查网络连接
- `Riff 服务不可用`：检查 Riff 服务状态
- `配置不完整`：检查 Riff 配置

### Q10: 同步会覆盖我的本地数据吗？

**A**: 不会！

**增量同步**：
- ✅ 只添加本地不存在的卡片
- ✅ 不覆盖已有卡片
- ✅ 保护本地复习记录

**全量同步**：
- ✅ Riff 有但本地没有 → 添加到本地
- ✅ 本地有但 Riff 没有 → 从本地删除
- ✅ 本地和 Riff 都有 → 保留本地数据（不覆盖）

### Q11: 同步频率可以调整吗？

**A**: 可以！

**增量同步**：
- 可以选择触发时机（插件启动、浏览器打开、复习打开）
- 可以完全禁用自动同步
- 仍可使用手动同步

**全量同步**：
- 可以设置同步间隔（12小时、24小时、48小时、7天）
- 可以禁用自动全量同步
- 仍可使用手动全量同步

**建议**：
- 保持默认配置（适合大多数用户）
- 如果网络不稳定，可以减少触发时机
- 如果卡片变化频繁，可以缩短全量同步间隔

### Q12: 同步会消耗很多流量吗？

**A**: 不会！

**增量同步**：
- 只传输新卡片数据
- 数据量很小（通常 < 100KB）
- 使用黑名单过滤，减少无效传输

**全量同步**：
- 只传输卡片 ID 列表
- 数据量较小（通常 < 1MB）
- 不传输卡片内容

**估算**：
- 1000 张卡片的增量同步：约 50KB
- 1000 张卡片的全量同步：约 500KB
- 每天总流量：约 1MB

## 删除问题

### Q13: 删除卡片后 Riff 中还有怎么办？

**A**: 这可能是删除同步失败导致的。

**原因**：
- 网络断开
- Riff 服务异常
- 删除同步被禁用

**解决方法**：

**步骤 1：检查同步状态**
- 查看同步状态指示器
- 确认是否显示删除失败提示

**步骤 2：检查黑名单**
- 卡片应该已加入黑名单
- 黑名单会防止卡片重新出现

**步骤 3：执行全量同步**
- 点击"全量同步"按钮
- 全量同步会清理黑名单

**步骤 4：手动删除**
- 如果问题仍然存在
- 手动在 Riff 中删除卡片

### Q14: 在 Riff 中删除卡片后，本地还有怎么办？

**A**: 这是正常的！本地卡片会在下次全量同步时删除。

**原因**：
- 增量同步不检测删除
- 只有全量同步才检测删除

**解决方法**：

**方法 1：等待自动全量同步**
- 默认每 24 小时自动执行
- 自动删除本地卡片

**方法 2：手动触发全量同步**
- 点击"全量同步"按钮
- 立即删除本地卡片

**方法 3：手动删除**
- 在 SRS 浏览器中手动删除
- 立即生效

### Q15: 删除同步失败会怎样？

**A**: 插件会自动处理！

**处理流程**：
1. 卡片从本地删除（成功）
2. 尝试从 Riff 删除（失败）
3. 卡片加入黑名单（防止重新出现）
4. 显示友好的错误提示
5. 下次全量同步时清理黑名单

**用户提示**：
```
⚠️ 删除同步失败

无法从 Riff 删除卡片（网络错误）
卡片已加入黑名单，下次全量同步时会自动清理

[查看详情] [重试]
```

**您无需手动处理**，插件会自动管理！

### Q16: 可以批量删除卡片吗？

**A**: 可以！

**方法 1：在 SRS 浏览器中批量删除**
- 选择多张卡片
- 点击删除按钮
- 插件会自动处理删除同步

**方法 2：在 Riff 中批量删除**
- 在 Riff 管理界面批量删除
- 下次全量同步时本地也会删除

**注意**：
- 批量删除可能需要较长时间
- 删除失败的卡片会加入黑名单
- 建议删除后执行全量同步

## 黑名单问题

### Q17: 什么是黑名单？

**A**: 黑名单是一个特殊的 ID 列表，用于记录已删除但 Riff 删除失败的卡片。

**作用**：
- 🚫 防止已删除卡片重新出现
- 🛡️ 作为删除失败的后备方案
- 🧹 定期自动清理

**生命周期**：
```
删除卡片 → Riff 删除失败 → 加入黑名单
    ↓
增量同步时过滤黑名单中的卡片
    ↓
全量同步时清理黑名单（Riff 中已不存在的 ID）
```

### Q18: 黑名单会无限增长吗？

**A**: 不会！

**自动清理机制**：
- 全量同步时自动清理
- 清理条件：黑名单中的 ID 在 Riff 中已不存在
- 默认每 24 小时清理一次

**手动清理**：
- 点击"全量同步"按钮
- 立即清理黑名单

**清理结果**：
```
🔄 全量同步完成 | 新增 3 张，删除 2 张，清理黑名单 5 个
```

### Q19: 如何查看黑名单中的卡片？

**A**: 

**方法 1：查看日志**
- 打开浏览器控制台（F12）
- 搜索 `[HybridSync]` 或 `blacklist`
- 查看黑名单相关日志

**方法 2：查看数据文件**
- 位置：`工作空间/data/storage/petal/siyuan-plugin-fsrs/riff-blacklist.json`
- 使用文本编辑器打开
- 查看 ID 列表

**方法 3：查看同步统计**
- 执行全量同步
- 查看"清理黑名单"数量

### Q20: 可以手动清空黑名单吗？

**A**: 可以，但不建议！

**风险**：
- ⚠️ 已删除的卡片可能重新出现
- ⚠️ 可能导致数据不一致

**安全方法**：
- ✅ 执行全量同步（自动清理）
- ✅ 让插件自动管理黑名单

**如果确实需要手动清空**：
1. 关闭思源笔记
2. 删除 `riff-blacklist.json` 文件
3. 重启思源笔记
4. 执行全量同步

### Q21: 黑名单中的卡片还能恢复吗？

**A**: 可以！

**方法 1：从 Riff 恢复**
- 如果卡片在 Riff 中还存在
- 从黑名单移除该 ID
- 执行增量同步
- 卡片会重新出现

**方法 2：手动恢复**
- 在思源笔记中重新创建卡片
- 卡片会作为新卡片添加

**注意**：
- 恢复后的卡片是新卡片
- 原来的复习记录不会恢复

## 模式切换问题

### Q22: 如何切换模式？

**A**: 

**步骤**：
1. 打开插件设置面板
2. 找到"Riff 集成"部分
3. 选择新的模式（Advanced / Simple）
4. 保存设置
5. 重启思源笔记（建议）

**注意事项**：
- ⚠️ 切换模式会影响数据同步
- ⚠️ 建议切换前备份数据
- ⚠️ 建议切换后执行全量同步

### Q23: 切换模式会丢失数据吗？

**A**: 不会丢失卡片数据，但可能丢失复习记录！

**从高阶模式切换到简单模式**：
- ✅ 卡片数据保留
- ⚠️ 本地复习记录不会同步到 Riff
- ⚠️ 本地调度数据会丢失

**从简单模式切换到高阶模式**：
- ✅ 卡片数据保留
- ⚠️ Riff 复习记录不会同步到本地
- ✅ 会从 Riff 重新同步所有卡片

**建议**：
- 选择一种模式后长期使用
- 切换前备份数据
- 切换后执行全量同步

### Q24: 切换模式后需要重新配置吗？

**A**: 

**切换到简单模式**：
- ✅ 无需配置
- ✅ 开箱即用

**切换到高阶模式**：
- ⚠️ 需要配置同步策略（可选）
- ✅ 默认配置适合大多数用户
- ✅ 可以根据需求调整

## 性能问题

### Q25: 同步会阻塞 UI 吗？

**A**: 不会！

**设计原则**：
- ✅ 所有同步操作在后台执行
- ✅ 不阻塞 UI 线程
- ✅ 用户可以继续使用其他功能

**同步进度**：
- 显示同步状态指示器
- 实时更新同步进度
- 完成后显示结果

### Q26: 高阶模式真的更快吗？

**A**: 是的！

**性能对比**：

| 操作 | 高阶模式 | 简单模式 |
|------|---------|---------|
| 打开 SRS 浏览器 | < 100ms | 取决于网络 |
| 加载卡片列表 | 极快（本地读取） | 需要网络请求 |
| 复习卡片 | 极快（本地计算） | 需要网络请求 |
| 离线使用 | ✅ 完全支持 | ❌ 不支持 |

**原因**：
- 高阶模式直接从本地读取数据
- 无需网络请求
- 无需等待 Riff 响应

### Q27: 大量卡片会影响性能吗？

**A**: 不会！

**性能测试**：

| 卡片数量 | 增量同步 | 全量同步 | 打开浏览器 |
|---------|---------|---------|-----------|
| 100 | < 0.1s | < 0.5s | < 50ms |
| 1000 | < 0.5s | < 2s | < 100ms |
| 5000 | < 1s | < 5s | < 200ms |

**优化措施**：
- 增量同步只获取新卡片
- 全量同步使用批量 API
- 本地读取使用索引优化

### Q28: 如何优化同步性能？

**A**: 

**方法 1：调整同步频率**
- 减少触发时机
- 延长全量同步间隔
- 使用手动同步

**方法 2：优化网络**
- 使用稳定的网络连接
- 避免在网络不稳定时同步
- 考虑使用代理

**方法 3：清理数据**
- 删除不需要的卡片
- 清理黑名单
- 定期执行全量同步

## 故障排除

### Q29: 插件无法加载怎么办？

**A**: 

**步骤 1：检查插件状态**
- 打开设置 → 集市 → 已下载
- 确认插件已启用

**步骤 2：查看错误日志**
- 打开浏览器控制台（F12）
- 查看错误信息

**步骤 3：重启思源笔记**
- 完全关闭思源笔记
- 重新启动

**步骤 4：重新安装插件**
- 卸载插件
- 重新安装
- 恢复配置

### Q30: 配置丢失怎么办？

**A**: 

**原因**：
- 配置文件损坏
- 配置文件被删除
- 升级失败

**解决方法**：

**方法 1：从备份恢复**
- 如果有备份，直接恢复
- 位置：`工作空间/data/storage/petal/siyuan-plugin-fsrs/settings.json`

**方法 2：重新配置**
- 打开设置面板
- 重新配置 Riff 集成
- 保存设置

**方法 3：使用默认配置**
- 删除配置文件
- 重启插件
- 使用默认配置

### Q31: 数据不一致怎么办？

**A**: 

**症状**：
- 本地和 Riff 的卡片数量不一致
- 删除的卡片重新出现
- 新卡片没有同步

**解决方法**：

**步骤 1：执行全量同步**
- 点击"全量同步"按钮
- 等待同步完成
- 检查同步结果

**步骤 2：检查黑名单**
- 查看黑名单中的卡片数量
- 确认黑名单已清理

**步骤 3：对比数据**
- 对比 Riff 和本地的卡片列表
- 找出差异
- 手动修复

**步骤 4：重置数据**
- 如果问题严重
- 备份数据
- 删除本地数据
- 重新同步

### Q32: 如何重置插件？

**A**: 

**警告**：重置会删除所有本地数据！

**步骤**：

**步骤 1：备份数据**
- 备份配置文件
- 备份卡片数据
- 备份黑名单

**步骤 2：删除数据**
- 位置：`工作空间/data/storage/petal/siyuan-plugin-fsrs/`
- 删除所有文件

**步骤 3：重启插件**
- 禁用插件
- 重新启用插件
- 使用默认配置

**步骤 4：重新同步**
- 配置 Riff 集成
- 执行全量同步
- 恢复数据
