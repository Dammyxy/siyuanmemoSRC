# 清空手动添加的卡片列表

## 问题

检索练习队列显示 79 张卡片，但只有 45 张有效，说明 localStorage 中保存的手动添加卡片列表包含了 34 张已删除的卡片。

## 解决方案

在浏览器控制台执行以下命令清空手动添加的卡片列表：

```javascript
localStorage.removeItem('retrieval-practice-manual-cards');
console.log('✅ 已清空手动添加的卡片列表');
```

## 执行步骤

1. 打开思源笔记
2. 按 F12 打开开发者工具
3. 切换到 Console 标签
4. 粘贴上面的代码并回车
5. 刷新页面或重新打开检索练习队列浏览器

## 预期结果

- 浏览器应该只显示 45 张有效卡片（当天到期的 item 卡）
- 不再有空白行

## 根本原因

检索练习队列支持手动添加卡片功能，这些手动添加的卡片 ID 会保存在 localStorage 中。当这些卡片被删除后，localStorage 中的 ID 仍然存在，导致队列尝试加载不存在的卡片。

虽然代码已经添加了自动清理逻辑，但需要先手动清空一次 localStorage 才能生效。
