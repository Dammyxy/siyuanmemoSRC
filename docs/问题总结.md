📋 问题总结
背景
您在 Card Browser 中实现了【渐进学习】队列显示 Riff 卡片，但发现操作同步有问题。

核心问题
问题 1：删除操作不同步

在 Card Browser 中删除 Riff 卡片
刷新后又出现（因为 Riff 数据库没有更新）
原因：removeItems() 只从本地 buffer 移除，没有调用 removeRiffCards() API
问题 2：时间调整会被覆盖

您通过系统调整了卡片的复习时间
但下次加载时，Riff API 返回的是旧的 nextDues
原因：_ensureRiffLoaded() → getRiffDueCards() 直接读取 Riff 数据库
根本原因：Riff 的双重角色
