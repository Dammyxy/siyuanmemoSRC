# 快速制卡符号系统 - 用户文档

## 概述

快速制卡符号系统让你可以通过简单的符号快速创建闪卡，无需打断写作流程。只需在编辑块时输入特定符号，系统会自动检测并创建对应类型的卡片。

## 支持的符号类型

### 1. 基础卡片

#### 正向卡片 `>>`
**用途**：创建从问题到答案的单向卡片

**示例**：
```
法国的首都是哪里？ >> 巴黎
```

**复习时**：
- 正面：法国的首都是哪里？
- 反面：巴黎

#### 反向卡片 `<<`
**用途**：创建从答案到问题的单向卡片

**示例**：
```
Paris << What is the capital of France?
```

**复习时**：
- 正面：Paris
- 反面：What is the capital of France?

#### 双向卡片 `<>`
**用途**：创建双向卡片，可以从两个方向复习

**示例**：
```
FSRS算法 <> 一种基于记忆曲线的间隔重复算法
```

**复习时**：
- 方向1：FSRS算法 → 一种基于记忆曲线的间隔重复算法
- 方向2：一种基于记忆曲线的间隔重复算法 → FSRS算法

### 2. 概念卡片 `::`

**用途**：创建概念定义卡片，自动标记为 Topic 类型

**示例**：
```
细胞 :: 生物体结构和功能的基本单位
WebSocket :: 一种在单个TCP连接上进行全双工通信的协议
```

**特点**：
- 自动标记为 Topic 类型
- 默认双向复习
- 概念名称在复习时加粗显示
- 使用 A-Factor 算法调度

### 3. 描述符卡片 `;;`

**用途**：为概念添加属性描述，系统化学习概念的各个方面

**示例**：
```
线粒体 :: 细胞的能量工厂
  ├─ 起源 ;; 被认为是通过内共生起源的
  ├─ 功能 ;; 为细胞生成ATP
  └─ 结构 ;; 具有双层膜结构
```

**特点**：
- 如果父块是概念（使用 `::`），使用 Xiuyuan 模版创建
- 如果父块不是概念，降级为普通正向卡片
- 复习时显示父概念作为上下文

### 4. 填空卡片 `{{}}`

**用途**：创建填空卡片，进行主动回忆练习

**示例**：
```
{{线粒体}}是细胞的{{能量工厂}}，负责生成{{ATP}}。
```

**复习时**：
- 填空位置会被隐藏
- 支持多个填空
- 可以逐个显示或全部显示

### 5. 列表模版 `>>>`

**用途**：创建列表模版卡片，渐进式学习多个要点

**基础示例**：
```
线粒体的主要功能有哪些？ >>>
  - 生成ATP
  - 调节细胞代谢
  - 控制细胞凋亡
```

**带提示的示例**：
```
线粒体的主要功能有哪些？ >>>
  - 能量生成 -> 通过氧化磷酸化生成ATP
  - 代谢调节 -> 调节细胞代谢过程
  - 细胞凋亡 -> 控制程序性细胞死亡
```

**特点**：
- 使用 Xiuyuan `builtin-list-item` 模版
- 支持渐进式显示（已学过的答案 + 当前提示）
- 至少需要 2 个子列表项
- 可以使用 `->` 分隔提示和答案

## 符号检测优先级

系统按以下顺序检测符号（长符号优先，避免误匹配）：

1. `>>>` - 列表模版
2. `::` - 概念卡片
3. `;;` - 描述符卡片
4. `<>` - 双向卡片
5. `>>` - 正向卡片
6. `<<` - 反向卡片
7. `{{}}` - 填空卡片

## 配置选项

### 启用快速制卡

在设置面板中，你可以：

1. **启用/禁用快速制卡**：总开关
2. **选择启用的符号类型**：
   - 基础卡片 (`>>` `<<` `<>`)
   - 概念卡片 (`::`)
   - 描述符卡片 (`;;`)
   - 填空卡片 (`{{}}`)
   - 列表模版 (`>>>`)

3. **调整防抖时间**：
   - 快速符号防抖时间（默认 300ms）
   - 列表模版防抖时间（默认 2000ms）

4. **描述符使用 Xiuyuan**：当父块是概念时，是否使用 Xiuyuan 模版

### 防抖机制

为了避免频繁触发检测，系统使用防抖机制：

- **快速符号**（`>>`, `::`, `;;`, `{{}}`）：默认 300ms
  - 编辑后 300ms 内没有新的编辑操作，才会触发检测
  
- **列表模版**（`>>>`）：默认 2000ms
  - 需要更长的时间，因为用户可能需要添加多个子列表项

## 使用技巧

### 1. 快速创建基础卡片

最简单的方式是使用 `>>` 符号：

```
问题 >> 答案
```

### 2. 系统化学习概念

使用概念和描述符组合：

```
概念名称 :: 概念定义
  - 属性1 ;; 描述1
  - 属性2 ;; 描述2
  - 属性3 ;; 描述3
```

### 3. 渐进式学习列表

使用列表模版：

```
问题 >>>
  - 提示1 -> 答案1
  - 提示2 -> 答案2
  - 提示3 -> 答案3
```

### 4. 主动回忆练习

使用填空卡片：

```
{{关键词1}}是{{关键词2}}的{{关键词3}}。
```

## 常见问题

### Q: 为什么我的卡片没有自动创建？

A: 请检查：
1. 快速制卡是否已启用
2. 对应的符号类型是否已启用
3. 符号格式是否正确
4. 是否已经为该块创建过卡片

### Q: 如何撤销自动创建的卡片？

A: 在卡片浏览器中找到该卡片，点击删除即可。

### Q: 防抖时间太长/太短怎么办？

A: 在设置面板中调整防抖时间：
- 如果觉得响应太慢，减小防抖时间
- 如果觉得触发太频繁，增加防抖时间

### Q: 描述符卡片为什么降级为普通卡片？

A: 描述符卡片（`;;`）只有在父块是概念（使用 `::`）时，才会使用 Xiuyuan 模版。如果父块不是概念，会自动降级为普通正向卡片。

### Q: 列表模版需要多少个子项？

A: 至少需要 2 个子列表项。如果子项少于 2 个，不会创建卡片。

## 性能指标

- 符号检测延迟：< 100ms
- 卡片创建时间：< 200ms
- 内存占用：< 10MB
- WebSocket 重连：< 5秒

## 技术细节

### WebSocket 连接

快速制卡系统使用 WebSocket 实时监听块的编辑操作：

- 连接地址：`ws://localhost:6806/ws?app=siyuanmemo&type=main`
- 监听事件：`transactions`
- 自动重连：连接断开后 3 秒自动重连

### 防抖队列

系统维护两个独立的防抖队列：

1. **快速符号队列**（300ms）：处理 `>>`, `::`, `;;`, `{{}}`
2. **列表模版队列**（2000ms）：处理 `>>>`

### 卡片创建流程

```
用户编辑块
    ↓
WebSocket 接收 transactions 事件
    ↓
检测 insert/update 操作
    ↓
加入检测队列（防抖）
    ↓
批量处理队列
    ↓
逐个检测符号类型
    ↓
创建对应类型的卡片
    ↓
添加到 Riff 卡组
    ↓
显示创建成功提示
```
