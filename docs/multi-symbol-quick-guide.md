# 多符号制卡快速指南

## 快速开始

现在你可以在一个块里使用多个符号制作多张卡片了！

### 基本用法

1. **在一个块里输入多个符号**
   ```markdown
   概念1 :: 定义1
   概念2 :: 定义2
   概念3 :: 定义3
   ```

2. **切换到其他块或等待 1 秒**
   - 系统会自动检测所有符号
   - 批量创建多张卡片

3. **查看创建结果**
   - 右上角会显示成功提示
   - 卡片已添加到 Riff 卡组

## 支持的符号

| 符号 | 用途 | 示例 |
|------|------|------|
| `::` | 概念卡片 | `细胞 :: 生物体的基本单位` |
| `>>` | 正向卡片 | `问题 >> 答案` |
| `<<` | 反向卡片 | `答案 << 问题` |
| `<>` | 双向卡片 | `术语 <> 定义` |
| `;;` | 描述符卡片 | `属性 ;; 描述` |
| `{{}}` | 填空卡片 | `文本{{填空}}` |

## 使用场景

### 场景 1：批量创建概念卡片

适合：整理笔记时批量创建术语定义

```markdown
细胞 :: 生物体结构和功能的基本单位
线粒体 :: 细胞的能量工厂
细胞核 :: 包含遗传物质的细胞器
细胞膜 :: 控制物质进出的屏障
```

**结果**：自动创建 4 张概念卡片

### 场景 2：混合使用不同符号

适合：创建不同类型的相关卡片

```markdown
FSRS :: Free Spaced Repetition Scheduler
算法优势 >> 基于记忆曲线，自动调整复习间隔
使用场景 <> 适合长期记忆和知识积累
```

**结果**：创建 1 张概念卡片 + 1 张正向卡片 + 1 张双向卡片

### 场景 3：概念 + 描述符

适合：系统化学习一个概念的多个方面

```markdown
线粒体 :: 细胞的能量工厂
  起源 ;; 被认为是通过内共生起源的
  功能 ;; 为细胞生成ATP
  结构 ;; 具有双层膜结构
```

**结果**：创建 1 张概念卡片 + 3 张描述符卡片

## 工作原理

### 触发时机

系统会在以下情况下自动制卡：

1. **停止输入 1 秒后**
   - 防抖机制，避免频繁触发
   - 给你足够时间输入多个符号

2. **切换到其他块时**
   - 自动检测前一个块的所有符号
   - 立即批量创建卡片

### 检测流程

```
输入符号 → 继续输入 → 切换块/等待 1 秒
                              ↓
                        检测所有符号
                              ↓
                        批量创建卡片
                              ↓
                        显示成功提示
```

## 配置选项

### 调整防抖时间

如果你打字速度较慢，可以延长防抖时间：

1. 打开插件设置
2. 找到"快速制卡"部分
3. 调整"防抖延迟"（默认 1000ms）

### 启用/禁用符号类型

可以选择性启用需要的符号：

1. 打开插件设置
2. 找到"启用的符号类型"
3. 勾选/取消勾选对应的符号

## 常见问题

### Q: 为什么没有自动创建卡片？

A: 检查以下几点：
- 快速制卡功能是否启用
- 对应的符号类型是否启用
- 块是否已经有卡片（不会重复创建）
- 是否等待了足够的时间或切换了块

### Q: 可以在一个块里混合使用不同符号吗？

A: 可以！系统会检测所有符号类型，但会按优先级创建：
1. 双向卡片 `<>`
2. 正向卡片 `>>`
3. 反向卡片 `<<`
4. 概念卡片 `::`
5. 描述符卡片 `;;`
6. 填空卡片 `{{}}`

### Q: 如何撤销批量创建的卡片？

A: 目前需要手动删除：
1. 在 Riff 卡组中找到对应的卡片
2. 删除卡片
3. 或者删除块的 FSRS 属性

### Q: 防抖时间太长/太短怎么办？

A: 在插件设置中调整"防抖延迟"：
- 打字快：可以缩短到 500ms
- 打字慢：可以延长到 2000ms

## 最佳实践

### ✅ 推荐做法

1. **批量整理笔记**
   - 一次性输入多个相关概念
   - 切换块后自动创建

2. **使用一致的格式**
   - 每个符号占一行
   - 保持格式清晰

3. **及时检查**
   - 创建后检查卡片是否正确
   - 必要时手动调整

### ❌ 避免做法

1. **不要在一行里使用多个符号**
   ```markdown
   ❌ 概念1 :: 定义1 概念2 :: 定义2
   ✅ 概念1 :: 定义1
      概念2 :: 定义2
   ```

2. **不要混用 `>>` 和 `>>>`**
   ```markdown
   ❌ 问题 >> 答案 >>>
   ✅ 问题 >> 答案
   或
   ✅ 问题 >>>
      - 答案1
      - 答案2
   ```
