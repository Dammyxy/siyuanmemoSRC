# SRS 浏览器功能增强建议

基于对 SuperMemo 浏览器菜单功能的分析，以下是针对我们 SRS 浏览器的功能增强建议：

## 1. 学习相关功能

### 1.1 Learn (Ctrl+L)
- **功能描述**: 对浏览器中的元素执行突出重复
- **实现建议**: 添加"开始复习"按钮，按浏览器当前排序顺序执行复习
- **技术实现**: 复用现有的复习队列逻辑，按当前表格排序执行复习

### 1.2 Go neural (Ctrl+F2)
- **功能描述**: 以浏览器为起点进行神经漫游
- **实现建议**: 已有神经漫游功能，可添加快捷入口到浏览器
- **技术实现**: 集成现有 `NeuralRoamQueue`，将选中卡片作为漫游起点

## 2. 子浏览器功能 (Child Browser)

### 2.1 Priority Filter
- **功能描述**: 打开一个包含优先级超过设定值的元素的新浏览器
- **实现建议**: 添加优先级筛选功能，支持按优先级阈值过滤
- **技术实现**: 在筛选器中添加优先级范围选择

### 2.2 Selected/Unselected
- **功能描述**: 打开包含已选/未选元素的新浏览器
- **实现建议**: 已有选中功能，可扩展为独立视图
- **技术实现**: 添加"仅显示选中"和"仅显示未选中"视图

### 2.3 Sources
- **功能描述**: 包含摘录和填空的源元素
- **实现建议**: 添加"显示来源"功能，可追溯卡片来源
- **技术实现**: 基于思源的双向链接关系，显示父级块

### 2.4 Content Type Filters
- **功能描述**: 按内容类型过滤（文章、摘录、主题等）
- **实现建议**: 添加内容类型筛选器（话题、提取、填空等）
- **技术实现**: 扩展现有的筛选器，支持按内容类型分类

### 2.5 Status Filters
- **功能描述**: 按状态过滤（突出、记忆、挂起等）
- **实现建议**: 扩展现有的状态筛选功能
- **技术实现**: 已有状态筛选，可优化为更直观的界面

## 3. 选择功能 (Select)

### 3.1 批量选择增强
- **功能描述**: 选择范围、反转选择等
- **实现建议**: 已有基础选择功能，可增强批量操作
- **技术实现**: 扩展AG-Grid的选择功能，添加范围选择

### 3.2 保存选择
- **功能描述**: 将选定元素保存为子集
- **实现建议**: 添加"保存为过滤器"功能
- **技术实现**: 将当前筛选条件和选中项保存为可复用的过滤器

## 4. 子集功能 (Subset)

### 4.1 子集操作
- **功能描述**: 保存、添加、减去、交集等子集操作
- **实现建议**: 扩展现有的过滤器功能，支持子集管理
- **技术实现**: 实现子集的保存、加载和组合操作

### 4.2 Intersperse Subset
- **功能描述**: 按比例混合不同子集
- **实现建议**: 添加队列混合功能，支持按权重混合不同队列
- **技术实现**: 实现队列合并算法，支持按比例混合

## 5. 搜索功能 (Search)

### 5.1 浏览器内搜索
- **功能描述**: 在浏览器元素中搜索文本
- **实现建议**: 已有搜索功能，可优化为实时高亮
- **技术实现**: 扩展现有搜索，支持高亮匹配文本

### 5.2 高级搜索
- **功能描述**: 按标题、内容、标签等搜索
- **实现建议**: 已有SQL搜索功能，可添加更友好的搜索语法
- **技术实现**: 扩展查询解析器，支持多种搜索语法

## 6. 排序功能 (Sort)

### 6.1 按复习参数排序
- **功能描述**: 按间隔、稳定性、可提取性、难度等排序
- **实现建议**: 扩展表格列，添加复习参数排序
- **技术实现**: 已有部分排序功能，可添加FSRS参数列：
  - 间隔 (Interval)
  - 稳定性 (Stability) 
  - 可提取性 (Retrievability)
  - 难度 (Difficulty)
  - 记忆遗漏次数 (Lapses)
  - 重复次数 (Reps)

### 6.2 按时间排序
- **功能描述**: 按复习日期、创建日期等排序
- **实现建议**: 扩展时间相关列的排序
- **技术实现**: 添加时间戳列，支持按各种时间维度排序

### 6.3 随机化
- **功能描述**: 随机打乱浏览器内容
- **实现建议**: 添加随机排序选项
- **技术实现**: 实现随机排序算法

## 7. 导出功能 (Export)

### 7.1 多种导出格式
- **功能描述**: 导出为文档、Q&A文本、XML等
- **实现建议**: 添加导出功能，支持多种格式
- **技术实现**: 实现数据导出器，支持HTML、TXT、CSV等格式

### 7.2 重复历史导出
- **功能描述**: 导出复习历史数据
- **实现建议**: 添加复习历史导出功能
- **技术实现**: 从Riff数据库导出复习记录

## 8. 随机功能 (Random)

### 8.1 随机复习
- **功能描述**: 随机跳转到浏览器中的元素
- **实现建议**: 添加随机抽卡功能
- **技术实现**: 从当前筛选结果中随机选择一张卡片

### 8.2 随机测试
- **功能描述**: 对浏览器内容进行随机测试
- **实现建议**: 添加模拟测试模式
- **技术实现**: 创建临时队列进行无影响的测试

## 9. 工具功能 (Tools)

### 9.1 保存到队列
- **功能描述**: 将浏览器元素保存到各种队列
- **实现建议**: 已有此功能，可通过"添加到队列"菜单实现
- **技术实现**: 扩展现有的"添加到队列"功能

### 9.2 数据分析工具
- **功能描述**: 计算知识总量、重复图表等
- **实现建议**: 添加数据分析面板
- **技术实现**: 基于FSRS数据生成统计图表

## 10. 实施优先级建议

### 高优先级
1. 按复习参数排序（间隔、稳定性、难度等）
2. 随机抽卡功能
3. 保存选择为过滤器
4. 优先级筛选

### 中优先级
1. 内容类型筛选（话题、提取、填空等）
2. 高级搜索语法
3. 子集操作功能
4. 数据分析工具

### 低优先级
1. 多种导出格式
2. 队列混合功能
3. 随机测试模式
4. 完整的子浏览器功能

## 11. 与现有功能的整合

### 11.1 现有优势
- 已有DataSource架构，便于扩展新功能
- 已有丰富的队列类型（神经漫游、刻意练习等）
- 已有SQL查询功能
- 已有性能优化（缓存、批量查询等）

### 11.2 扩展建议
- 利用现有DataSource接口实现新功能
- 集成到现有的右键菜单系统
- 保持与现有筛选系统的兼容性
- 遵循现有的UI/UX设计规范

这些功能增强将使我们的SRS浏览器更加完善，提供类似SuperMemo的专业级功能，同时保持与思源笔记生态的良好集成。
