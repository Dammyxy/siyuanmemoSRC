## 什么是 Riff 集成

Riff 是思源笔记的官方间隔重复系统（Spaced Repetition System），提供了强大的卡片管理和复习调度功能。本插件的 Riff 集成功能允许您：

- 📥 **从 Riff 导入卡片**：将 Riff 中的卡片同步到本地
- 🔄 **双向同步**：保持本地和 Riff 的数据一致性
- 🎯 **灵活选择**：根据需求选择不同的使用模式
- 🚀 **高性能**：通过混合同步方案优化性能

### 核心优势

✅ **数据一致性**：通过增量同步和全量同步，确保本地和 Riff 数据保持一致  
✅ **高性能**：增量同步快速获取新卡片，全量同步定期维护数据  
✅ **双向删除**：删除操作在本地和 Riff 之间自动同步  
✅ **离线可用**：高阶模式支持离线复习（数据已同步到本地）  
✅ **灵活配置**：根据使用习惯自定义同步策略

## 两种模式对比

本插件提供两种 Riff 集成模式，满足不同用户的需求：

### 模式对比表

| 特性 | 高阶模式（Advanced） | 简单模式（Simple） |
|------|---------------------|-------------------|
| **调度器** | 本地调度器（FSRS/SM-15/A-Factor） | Riff 原生调度器 |
| **数据存储** | 本地存储 + Riff 同步 | Riff 云端存储 |
| **离线使用** | ✅ 完全支持 | ❌ 需要网络 |
| **同步方式** | 混合同步（增量 + 全量） | 实时获取 |
| **性能** | ⚡ 极快（本地读取） | 🌐 依赖网络 |
| **配置复杂度** | 中等（可自定义） | 简单（开箱即用） |
| **适合人群** | 高阶用户、追求性能 | 普通用户、追求简单 |

### 如何选择？

**选择高阶模式，如果您：**
- 想使用高级调度算法（FSRS、SM-15、A-Factor）
- 需要离线复习功能
- 追求极致的性能体验
- 愿意了解和配置同步策略

**选择简单模式，如果您：**
- 刚开始使用间隔重复
- 不想了解复杂的配置
- 主要在线使用
- 信任 Riff 的原生调度算法

## 高阶模式详解

### 什么是高阶模式？

高阶模式使用**混合同步方案**，结合了增量同步（日常使用）和全量同步（定期维护），在性能和数据一致性之间取得完美平衡。

### 架构原理

```
Riff 系统（数据源）
    ↓ 后台混合同步
本地存储（主数据）
    ↓ 直接读取（极快）
SRS 浏览器 / 复习界面
```

### 三种同步机制

#### 1. 增量同步（Incremental Sync）

**作用**：快速获取 Riff 中的新卡片

**触发时机**：
- 插件启动时
- 打开 SRS 浏览器时
- 打开复习界面时
- 手动点击"同步"按钮

**工作流程**：
1. 从 Riff 获取自上次同步以来的新卡片
2. 使用黑名单过滤已删除的卡片
3. 只添加本地不存在的卡片（保护本地数据）
4. 更新同步时间戳

**特点**：
- ⚡ 速度快（只获取新卡片）
- 🛡️ 保护本地数据（不覆盖已有卡片）
- 🚫 使用黑名单防止已删除卡片重新出现

#### 2. 全量同步（Full Sync）

**作用**：检测双向删除，清理黑名单，确保数据一致性

**触发时机**：
- 每 24 小时自动触发（可配置）
- 手动点击"全量同步"按钮

**工作流程**：
1. 获取 Riff 和本地的所有卡片 ID
2. 对比差异：
   - Riff 有但本地没有 → 添加到本地
   - 本地有但 Riff 没有 → 从本地删除
3. 清理黑名单中 Riff 已不存在的 ID
4. 更新全量同步时间戳

**特点**：
- 🔍 检测双向删除
- 🧹 自动清理黑名单
- ✅ 确保数据一致性

#### 3. 删除同步（Delete Sync）

**作用**：删除操作在本地和 Riff 之间双向同步

**工作流程**：

**场景 A：在插件中删除卡片**
1. 从本地存储删除卡片
2. 尝试从 Riff 删除卡片
3. 成功 → 完成双向删除
4. 失败 → 加入黑名单（防止下次同步时重新出现）

**场景 B：在 Riff 中删除卡片**
1. 下次全量同步时检测到（Riff 没有但本地有）
2. 从本地存储删除
3. 从黑名单移除（如果存在）

**特点**：
- 🔄 真正的双向删除
- 🛡️ 黑名单作为删除失败的后备方案
- 🧹 全量同步时自动清理

### 黑名单机制

**什么是黑名单？**

黑名单是一个特殊的 ID 列表，用于记录已删除但 Riff 删除失败的卡片。

**为什么需要黑名单？**

当您在插件中删除卡片时，插件会尝试同时从 Riff 删除。但如果网络断开或 Riff 服务异常，删除可能失败。此时，黑名单可以防止这些卡片在下次同步时重新出现。

**黑名单的生命周期**：

```
删除卡片 → Riff 删除失败 → 加入黑名单
    ↓
增量同步时过滤黑名单中的卡片
    ↓
全量同步时清理黑名单（Riff 中已不存在的 ID）
```

**黑名单会无限增长吗？**

不会！全量同步会自动清理黑名单中 Riff 已不存在的 ID，确保黑名单不会无限增长。

### 使用步骤

#### 1. 启用高阶模式

1. 打开插件设置面板
2. 找到"Riff 集成"部分
3. 选择"高阶模式（Advanced Mode）"
4. 保存设置

#### 2. 配置同步策略（可选）

根据您的需求，可以自定义以下配置：

**增量同步配置**：
- 启用/禁用增量同步
- 选择触发时机（插件启动、浏览器打开、复习打开）
- 启用/禁用黑名单过滤

**全量同步配置**：
- 启用/禁用全量同步
- 设置同步间隔（12小时、24小时、48小时、7天）
- 启用/禁用黑名单清理

**删除同步配置**：
- 启用/禁用双向删除同步
- 启用/禁用黑名单后备

#### 3. 开始使用

配置完成后，插件会自动处理同步：

- **日常使用**：增量同步在后台自动运行，快速获取新卡片
- **定期维护**：全量同步定期运行，确保数据一致性
- **删除操作**：删除卡片时自动同步到 Riff

您也可以随时手动触发同步：

- 点击"手动同步"按钮 → 触发增量同步
- 点击"全量同步"按钮 → 触发全量同步

### 同步状态指示器

在 SRS 浏览器顶部，您可以看到同步状态指示器：

**状态类型**：

- ✅ **同步成功**：显示上次同步时间和统计信息
  ```
  ✅ 上次同步：2分钟前 | 新增 5 张卡片
  ```

- ⏳ **同步中**：显示同步进度
  ```
  ⏳ 正在同步... 已获取 10/50 张卡片
  ```

- ❌ **同步失败**：显示错误信息和重试按钮
  ```
  ❌ 同步失败：网络错误 | [重试]
  ```

- 🔄 **全量同步**：显示详细统计
  ```
  🔄 全量同步完成 | 新增 3 张，删除 2 张，清理黑名单 1 个
  ```

### 性能优势

高阶模式的性能优势：

| 操作 | 高阶模式 | 简单模式 |
|------|---------|---------|
| 打开 SRS 浏览器 | < 100ms | 取决于网络 |
| 加载卡片列表 | 极快（本地读取） | 需要网络请求 |
| 复习卡片 | 极快（本地计算） | 需要网络请求 |
| 离线使用 | ✅ 完全支持 | ❌ 不支持 |

## 简单模式详解

### 什么是简单模式？

简单模式直接使用 Riff 的原生调度器，所有数据和调度都在 Riff 中完成，插件只负责显示和交互。

### 架构原理

```
Riff 系统（数据源 + 调度器）
    ↓ 实时获取
SRS 浏览器 / 复习界面
```

### 特点

✅ **开箱即用**：无需配置，启用即可使用  
✅ **简单直观**：所有操作都在 Riff 中完成  
✅ **自动管理**：Riff 自动管理卡片和调度  
❌ **需要网络**：必须在线使用  
❌ **性能依赖网络**：加载速度取决于网络状况

### 使用步骤

#### 1. 启用简单模式

1. 打开插件设置面板
2. 找到"Riff 集成"部分
3. 选择"简单模式（Simple Mode）"
4. 保存设置

#### 2. 开始使用

启用后，您可以：

- 打开 SRS 浏览器查看 Riff 中的卡片
- 进行复习（使用 Riff 调度器）
- 所有操作自动同步到 Riff

### 适用场景

简单模式适合：

- 🆕 刚开始使用间隔重复的新用户
- 🌐 主要在线使用的用户
- 🎯 不想了解复杂配置的用户
- 🤝 信任 Riff 原生调度算法的用户

## 使用场景和最佳实践

### 场景 1：日常复习（高阶模式）

**使用流程**：

1. 打开思源笔记（自动触发增量同步）
2. 打开 SRS 浏览器（查看卡片列表）
3. 开始复习（使用本地调度器）
4. 复习结果自动保存到本地

**最佳实践**：

- ✅ 保持增量同步启用
- ✅ 启用所有触发时机
- ✅ 定期检查同步状态
- ✅ 网络断开时仍可正常复习

### 场景 2：批量删除卡片（高阶模式）

**使用流程**：

1. 在 SRS 浏览器中选择要删除的卡片
2. 点击删除按钮
3. 插件自动尝试从 Riff 删除
4. 如果删除失败，卡片自动加入黑名单

**最佳实践**：

- ✅ 启用删除同步
- ✅ 启用黑名单后备
- ✅ 删除后检查同步状态
- ✅ 定期执行全量同步清理黑名单

### 场景 3：离线使用（高阶模式）

**使用流程**：

1. 在有网络时完成一次同步
2. 断开网络
3. 正常使用 SRS 浏览器和复习功能
4. 恢复网络后自动同步

**最佳实践**：

- ✅ 出门前确保完成一次同步
- ✅ 离线时正常复习
- ✅ 恢复网络后检查同步状态
- ✅ 如有删除操作，注意黑名单提示

### 场景 4：多设备同步（高阶模式）

**使用流程**：

1. 设备 A：复习卡片，数据保存到本地
2. 设备 A：全量同步（将删除操作同步到 Riff）
3. 设备 B：打开插件，自动增量同步
4. 设备 B：获取设备 A 的新卡片

**最佳实践**：

- ✅ 切换设备前执行全量同步
- ✅ 新设备启动时等待同步完成
- ✅ 定期执行全量同步确保一致性
- ⚠️ 注意：复习记录不会同步（本地调度器）

### 场景 5：简单使用（简单模式）

**使用流程**：

1. 启用简单模式
2. 打开 SRS 浏览器（自动从 Riff 获取卡片）
3. 开始复习（使用 Riff 调度器）
4. 复习结果自动同步到 Riff

**最佳实践**：

- ✅ 确保网络连接稳定
- ✅ 信任 Riff 的调度算法
- ✅ 不需要关心同步问题
- ⚠️ 注意：离线时无法使用

## 常见问题

### Q1: 高阶模式和简单模式可以随时切换吗？

**A**: 可以，但需要注意：

- 从高阶模式切换到简单模式：本地的复习记录不会同步到 Riff
- 从简单模式切换到高阶模式：会从 Riff 重新同步所有卡片

建议：选择一种模式后长期使用，避免频繁切换。

### Q2: 增量同步和全量同步有什么区别？

**A**: 

- **增量同步**：只获取新卡片，速度快，适合日常使用
- **全量同步**：对比所有卡片，检测删除，清理黑名单，适合定期维护

建议：日常使用增量同步，定期（24小时）执行全量同步。

### Q3: 黑名单是什么？会无限增长吗？

**A**: 

黑名单用于记录删除失败的卡片 ID，防止它们在下次同步时重新出现。

不会无限增长！全量同步会自动清理黑名单中 Riff 已不存在的 ID。

### Q4: 同步失败怎么办？

**A**: 

1. **检查网络连接**：确保网络正常
2. **检查 Riff 服务**：确保 Riff 服务可访问
3. **查看错误提示**：根据提示排查问题
4. **手动重试**：点击"重试"按钮
5. **查看日志**：打开浏览器控制台查看详细日志

### Q5: 删除卡片后 Riff 中还有怎么办？

**A**: 

这可能是删除同步失败导致的：

1. 检查同步状态指示器的提示
2. 卡片应该已加入黑名单
3. 执行一次全量同步
4. 如果问题仍然存在，手动在 Riff 中删除

### Q6: 高阶模式下，复习记录会同步到 Riff 吗？

**A**: 

不会。高阶模式使用本地调度器，复习记录保存在本地，不会同步到 Riff。

如果需要在多设备间同步复习记录，建议使用简单模式。

### Q7: 如何查看同步日志？

**A**: 

1. 打开浏览器控制台（F12）
2. 切换到 Console 标签
3. 搜索 `[HybridSync]` 查看同步日志
4. 搜索 `[RiffDataSource]` 查看数据源日志

### Q8: 全量同步会覆盖本地数据吗？

**A**: 

不会！全量同步遵循以下原则：

- Riff 有但本地没有 → 添加到本地
- 本地有但 Riff 没有 → 从本地删除
- 本地和 Riff 都有 → 保留本地数据（不覆盖）

### Q9: 可以禁用自动同步吗？

**A**: 

可以。在设置面板中：

- 禁用增量同步 → 不会自动同步
- 禁用全量同步 → 不会定期同步
- 仍可使用手动同步按钮

但不建议完全禁用，这会影响数据一致性。

### Q10: 简单模式下可以离线使用吗？

**A**: 

不可以。简单模式需要实时从 Riff 获取数据，必须在线使用。

如果需要离线使用，请切换到高阶模式。
