# 文档块菜单状态说明

## 当前实现

块菜单（`handleBlockIconClick`）已经集成了三个复习入口，可以正常显示和使用。

## 功能说明

当右键点击任何块（包括文档块、标题块、段落块等）时：

1. **自动收集卡片**: 收集当前块及其所有子块的卡片
2. **显示三种复习模式**:
   - 提取练习（到期/全部）
   - 渐进学习（到期/全部）
   - 刻意练习（全部）
3. **实时统计**: 显示到期数量和总数量

## 菜单结构

```
SiyuanMemo
  ├─ 提取练习 - 到期 (X/Y)
  ├─ 提取练习 - 全部 (Y)
  ├─ ──────────────
  ├─ 渐进学习 - 到期 (X/Y)
  ├─ 渐进学习 - 全部 (Y)
  ├─ ──────────────
  ├─ 刻意练习 (Y)
  ├─ ──────────────
  ├─ 神经漫游
  ├─ ──────────────
  ├─ 编辑SRS数据
  ├─ 选中制卡
  └─ 取消闪卡
```

## 使用场景

### 场景 1: 复习文档块

1. 在文档树或编辑器中右键点击文档块
2. 选择 "SiyuanMemo" → "提取练习 - 到期"
3. 系统会加载该文档块及其所有子块中的到期卡片

### 场景 2: 复习特定章节

1. 在编辑器中右键点击某个标题块
2. 选择 "SiyuanMemo" → "提取练习 - 到期"
3. 系统只会加载该标题及其子块中的到期卡片

### 场景 3: 复习选中的多个块

1. 选中多个块（Ctrl+点击）
2. 右键选择 "SiyuanMemo" → "刻意练习"
3. 系统会加载所有选中块及其子块的卡片

## 实现方式

使用 `ReviewEntryBase.createMenuItems()` 方法：

```typescript
// 为每个复习入口生成菜单项
for (let i = 0; i < this.reviewEntries.length; i++) {
  const entry = this.reviewEntries[i];
  const items = entry.createMenuItems(blockElements);
  submenu.push(...items);
  
  // 添加分隔符
  if (i < this.reviewEntries.length - 1) {
    submenu.push({ type: 'separator' });
  }
}
```

`createMenuItems()` 方法会：
1. 从 DOM 中收集当前块及所有子块
2. 从本地存储查询对应的卡片
3. 应用卡片类型过滤（Item-only 或 All）
4. 计算到期数量和总数量
5. 生成菜单项

## 与其他菜单的区别

### 块菜单（当前实现）
- **触发**: 右键点击任何块
- **范围**: 当前块及其子块（DOM可见范围）
- **性能**: 快速（只查询DOM中的块）
- **适用**: 局部复习

### 文档标题菜单
- **触发**: 点击文档标题图标
- **范围**: 整个文档树（所有块）
- **性能**: 较慢（需要查询数据库）
- **适用**: 文档级复习

### 面包屑菜单
- **触发**: 点击面包屑"更多"按钮
- **范围**: 整个文档树（所有块）
- **性能**: 较慢（需要查询数据库）
- **适用**: 文档级复习

## 技术限制

由于思源的事件处理机制，块菜单必须是同步的，无法在菜单显示前执行异步数据库查询。因此：

- ✅ 可以收集DOM中可见的块
- ❌ 无法查询整个文档树（需要异步数据库查询）

如果需要复习整个文档，请使用：
- 文档标题图标菜单
- 面包屑"更多"菜单
