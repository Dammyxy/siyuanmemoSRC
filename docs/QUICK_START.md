# Riff 集成快速开始指南

> **5 分钟快速上手 Riff 集成功能**

---

## 🚀 快速开始

### 步骤 1：选择模式（30 秒）

打开插件设置 → Riff 集成

**两种模式，简单选择**：

```
┌─────────────────────────────────────┐
│ ( ) 高阶模式（Advanced Mode）        │
│     ✓ 极致性能                       │
│     ✓ 离线可用                       │
│     ✓ 本地调度器                     │
│                                     │
│ ( ) 简单模式（Simple Mode）          │
│     ✓ 开箱即用                       │
│     ✓ 无需配置                       │
│     ✓ Riff 调度器                    │
└─────────────────────────────────────┘
```

**如何选择？**

- 🎯 **追求性能** → 高阶模式
- 🎯 **追求简单** → 简单模式

### 步骤 2：保存设置（10 秒）

点击"保存"按钮，完成！

### 步骤 3：开始使用（1 分钟）

1. 打开 SRS 浏览器
2. 查看从 Riff 同步的卡片
3. 开始复习

**就这么简单！** 🎉

## 📖 高阶模式详细配置（可选）

如果您选择了高阶模式，可以进一步自定义同步策略：

### 增量同步配置

```
[✓] 启用增量同步

触发时机：
[✓] 插件启动时
[✓] SRS 浏览器打开时
[✓] 复习界面打开时

[✓] 使用黑名单过滤已删除卡片
```

**建议**：保持默认配置（全部启用）

### 全量同步配置

```
[✓] 启用全量同步

同步间隔：[24小时 ▼]

[✓] 全量同步后清理黑名单
```

**建议**：保持默认配置（24 小时）

### 删除同步配置

```
[✓] 启用双向删除同步

[✓] 删除失败时使用黑名单作为后备
```

**建议**：保持默认配置（全部启用）

## 🎯 常见使用场景

### 场景 1：日常复习

```
1. 打开思源笔记
   ↓ 自动增量同步
2. 打开 SRS 浏览器
   ↓ 查看卡片列表
3. 开始复习
   ↓ 使用本地调度器
4. 完成复习
   ↓ 数据自动保存
```

### 场景 2：离线使用（高阶模式）

```
1. 在有网络时打开插件
   ↓ 完成一次同步
2. 断开网络
   ↓ 仍可正常使用
3. 复习卡片
   ↓ 数据保存到本地
4. 恢复网络
   ↓ 自动同步
```

### 场景 3：删除卡片

```
1. 在 SRS 浏览器中选择卡片
   ↓
2. 点击删除按钮
   ↓ 从本地删除
   ↓ 尝试从 Riff 删除
3. 删除成功
   ↓ 完成双向删除
   
   或
   
3. 删除失败
   ↓ 加入黑名单
   ↓ 防止重新出现
```

## 🔍 同步状态查看

在 SRS 浏览器顶部，您可以看到同步状态：

```
┌─────────────────────────────────────┐
│ ✅ 上次同步：2分钟前 | 新增 5 张卡片  │
│ [手动同步] [全量同步]                │
└─────────────────────────────────────┘
```

**状态说明**：

- ✅ **同步成功**：显示上次同步时间和统计
- ⏳ **同步中**：显示同步进度
- ❌ **同步失败**：显示错误和重试按钮

## 🛠️ 手动同步

### 增量同步

点击"手动同步"按钮 → 快速获取新卡片

**适用场景**：
- 想立即获取 Riff 中的新卡片
- 刚在 Riff 中添加了卡片
- 同步失败后重试

### 全量同步

点击"全量同步"按钮 → 完整对比和清理

**适用场景**：
- 删除了很多卡片
- 怀疑数据不一致
- 想清理黑名单

## ❓ 常见问题

### Q1: 同步会覆盖我的本地数据吗？

**A**: 不会！同步只添加新卡片，不覆盖已有卡片。

### Q2: 我可以离线使用吗？

**A**: 
- 高阶模式：✅ 可以（数据在本地）
- 简单模式：❌ 不可以（需要网络）

### Q3: 删除卡片后 Riff 中还有怎么办？

**A**: 
1. 检查同步状态（可能删除失败）
2. 卡片应该已加入黑名单
3. 执行全量同步清理

### Q4: 同步失败怎么办？

**A**: 
1. 检查网络连接
2. 检查 Riff 服务状态
3. 点击"重试"按钮
4. 查看错误日志

### Q5: 如何切换模式？

**A**: 
1. 打开设置面板
2. 选择新模式
3. 保存设置
4. 重启思源笔记（建议）
