Example: Deducting Discriminant Information Given a Constant Term and Vertex of a Quadratic Function ?

抛物线 y = ax² + bx + c 的顶点在点 (4, 2) 处。如果 c < 0，则以下哪个陈述是正确的？

I. Δ > 0
II. Δ = 0
III. Δ < 0


EXPLANATION

我们知道顶点的坐标，并且我们还知道 y 截距位于 x 轴下方。因此，根据我们所知，我们可以绘制抛物线草图。

由于顶点 (4, 2) 在 x 轴上方，且不在 x 轴上，所以曲线要么没有根，要么有两个不同的根。因此，我们必须有 Δ ≠ 0。另一方面，由于 c < 0，y 截距在 x 轴下方。因此，曲线在从 x 轴下方的 y 截距移动到 x 轴上方的顶点时，必须至少在一点处与 x 轴相交。因此，Δ > 0。因此，Δ > 0，只有陈述 I 是正确的。

数学知识点：

  1. 二次函数: 形如 y = ax² + bx + c (a ≠ 0) 的函数。
  2. 抛物线: 二次函数的图像。
  3. 顶点: 抛物线的最高点或最低点。顶点的 x 坐标是 −b/(2a)。
  4. 判别式 (Δ): 二次方程 ax² + bx + c = 0 的判别式定义为 Δ = b² − 4ac。它决定了二次方程根的性质以及抛物线与 x 轴的交点情况。
    • Δ > 0: 方程有两个不同的实根，抛物线与 x 轴有两个不同的交点。
    • Δ = 0: 方程有两个相等的实根 (重根)，抛物线与 x 轴只有一个交点 (顶点在 x 轴上)。
    • Δ < 0: 方程没有实根，抛物线与 x 轴没有交点。
  5. y 截距: 抛物线与 y 轴的交点。当 x = 0 时，y = c，所以 y 截距的坐标是 (0, c)。
  6. 根: 二次函数图像与 x 轴的交点的 x 坐标，即方程 ax² + bx + c = 0 的解。

解题逻辑和思路：

  1. 分析已知信息: 题目给出了抛物线的顶点坐标 (4, 2) 和 y 截距的符号 (c < 0，意味着 y 截距在 x 轴下方)。
  2. 利用顶点位置: 顶点 (4, 2) 在 x 轴上方。根据判别式的定义，抛物线与 x 轴的交点个数由判别式决定。如果顶点在 x 轴上方，抛物线与 x 轴要么有两个交点 (Δ > 0)，要么没有交点 (Δ < 0)。顶点不在 x 轴上，因此排除 Δ = 0 的情况。所以 Δ ≠ 0。
  3. 利用 y 截距位置: y 截距 (0, c) 在 x 轴下方，因为 c < 0。这意味着当 x = 0 时，函数值 y 是负的。
  4. 结合顶点和 y 截距: 抛物线从 x 轴下方的 y 截距 (0, c) 出发，经过顶点的最高点 (4, 2)，而顶点在 x 轴上方。要从下方到达上方，曲线必须向上穿过 x 轴。由于这是一个连续的函数，并且它从 x 轴下方的一个点 (y 截距) 上升到 x 轴上方的一个点 (顶点)，它必须在两者之间穿过 x 轴。
  5. 推断交点数量: 曲线穿过 x 轴意味着有实根。因为顶点在 x 轴上方，且 y 截距在 x 轴下方，曲线必须向上开口 (a > 0) 才能从下方经过最高点。如果是向上开口，曲线在顶点左侧上升，经过 y 截距，然后继续上升；在顶点右侧下降，必然会再次穿过 x 轴。所以会有两个交点。
  6. 确定判别式符号: 抛物线与 x 轴有两个不同的交点，这对应于判别式 Δ > 0 的情况。
  7. 验证选项: 根据推论，Δ > 0，因此只有陈述 I 是正确的。
