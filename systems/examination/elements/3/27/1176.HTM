因式分解步骤与技巧 (十字相乘法)

图片中将方程从 0 = 9x² − 200x + 400 转换为 0 = (9x − 20)(x − 20) 使用的是因式分解方法，具体来说，是十字相乘法。这里没有使用配方法。下面解释如何使用十字相乘法进行分解：

待分解表达式：


9x² − 200x + 400
我们需要找到两个一次因式 (px + q) 和 (rx + s)，使得它们的乘积等于原二次三项式：
(px + q)(rx + s) = prx² + (ps + qr)x + qs
对比系数，我们需要找到整数 p, r, q, s 满足：
  • pr = 9 (二次项系数)
  • qs = 400 (常数项)
  • ps + qr = −200 (一次项系数)

使用十字相乘法寻找组合：

1. 分解二次项系数 (9): 可能的因数对有 (1, 9) 和 (3, 3)。

2. 分解常数项 (400): 可能的因数对有很多。由于一次项系数是负数 (-200)，而常数项是正数 (400)，这表示分解 400 的两个因数 q 和 s 必须同号，且都为负数。我们尝试一些可能的负数因数对，例如 (-1, -400), (-2, -200), (-4, -100), (-5, -80), (-8, -50), (-10, -40), (-16, -25), (-20, -20) 等等。

3. 尝试组合并计算“十字相乘积之和”: 将二次项系数的一对因数放在左边一列，常数项的一对因数放在右边一列，然后交叉相乘，并将乘积相加。目标是使这个和等于一次项系数 -200。 我们尝试使用二次项因数对 (9, 1) 和常数项因数对 (-20, -20)：

9x −20
x −20
进行“十字相乘”：
  • 9x 乘以 −20 得到 −180x
  • x 乘以 −20 得到 −20x
将这两个乘积相加：
−180x + (−20x) = −200x
这个结果等于原二次三项式的一次项系数 (-200x)。这表明我们找到了正确的因数组合。

分解结果：

根据找到的组合，因式分解结果为：
9x² − 200x + 400 = (9x − 20)(x − 20)

因式分解的技巧总结 (十字相乘法)：

  • 观察符号: 根据常数项和一次项的符号，判断因式中常数项的符号组合。如果常数项为正，两个因数的常数项同号；如果常数项为负，两个因数的常数项异号。如果一次项为负，且常数项为正，则两个因数的常数项都为负。
  • 分解系数: 列出二次项系数和常数项的所有因数对。
  • 系统尝试: 从较小的因数对开始尝试组合。将二次项因数对放在左边，常数项因数对放在右边。
  • 计算并核对中间项: 进行“十字相乘”，将交叉乘积相加，看是否等于原二次三项式的一次项系数。如果不对，尝试更换因数对的组合或同一对因数的顺序。
  • 熟能生巧: 多练习不同类型的题目是提高因式分解速度和准确性的关键。对于某些二次三项式，可能需要多尝试几次才能找到正确的组合。
