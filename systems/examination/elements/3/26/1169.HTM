为什么 x = −1 会混进来？

  • 当你对方程 A = B 两边平方时，你得到 A^2 = B^2。
  • 这个新方程 A^2 = B^2 其实是两个可能情况的并集：A = B 或者 A = -B。
  • 在我们的例子中，原方程是 sqrt(x + 2) = x。
  • 两边平方后得到的方程 x + 2 = x^2，实际上是下面两个方程的解的集合：
    1. sqrt(x + 2) = x (我们原来的方程)
    2. sqrt(x + 2) = -x (一个我们不想要，但被平方操作“混入”的方程)
  • 我们的真根 x = 2 是第一个方程的解。
  • 而增根 x = -1 其实是第二个方程的解：sqrt(-1+2) = -(-1)，即 1 = 1，成立。

总结

解根式方程时，两边平方是一个不等价的变形，它会扩大解的范围。就好比你为了抓一个特定的嫌疑人（真根），撒下了一张大网，结果把长得很像的路人（增根）也一起网进来了。因此，“检验”这个步骤至关重要，它是你识别并剔除增根的唯一可靠方法。检验是解根式方程必不可少的一步。

好的，我们来为这个概念制作一些解释卡。

【目标材料】 解根式方程时，两边平方是一个不等价的变形，它会扩大解的范围。

【问/答卡片】

卡片 1

  • 问： 为什么说“对等式两边平方”是一个不等价的变形？
  • 答： 因为这个操作可能会引入原方程没有的解（即“增根”）。平方后的新方程的解集，会包含原方程的解集。

卡片 2

  • 问： 从代数角度看，为什么“两边平方”会扩大解的范围？
  • 答： 因为将方程 A = B 两边平方得到 A² = B²，而 A² = B² 等价于 (A-B)(A+B) = 0，它的解是 A = B 或 A = -B。因此，新方程包含了 A = -B 这个额外情况的解。

卡片 3

  • 问： 在解根式方程时，两边平方的操作会丢失什么关键信息，从而可能导致增根？
  • 答： 会丢失符号信息。例如，x = 3 和 x = -3 在平方后都变成了 x² = 9。解平方后的方程时，我们找的是所有满足 x²=9 的解，但这其中可能包含了不满足原方程的解。
