要解方程：
√
−8x + 45
 
 = 2x
我们将方程两边平方。这样做可以去掉根号，得到一个更容易求解的二次方程：
(
√

 )2 = (2x)2

−8x + 45 = 4x2

4x2 + 8x − 45 = 0

(4x2 + 18x) + (−10x − 45) = 0

2x(2x + 9) − 5(2x + 9) = 0

(2x − 5)(2x + 9) = 0

x = −9⁄2, 5⁄2
请记住，在求解平方根方程时，我们应该始终检查求得的值是否是原方程的实际解。
  • 首先，我们检查求得的值 x = −9⁄2 是否是原方程的解：

数学知识点：

  1. 平方根方程: 包含未知数的平方根的方程。
  2. 二次方程: 形如 ax² + bx + c = 0 (a ≠ 0) 的方程。
  3. 将方程两边平方: 一种消除平方根，将平方根方程转化为非根号方程的方法。
  4. 因式分解: 将多项式分解为几个因式乘积的方法。
  5. 求解二次方程: 通过因式分解、配方法或公式法等方法求解二次方程的根。
  6. 验根: 这是求解平方根方程的关键步骤。 由于平方过程可能引入不满足原方程的解（称为增根），因此必须将求得的每一个解代入原方程进行检验。只有满足原方程的解才是原平方根方程的解。
  7. 确定最终解: 根据验根结果，得出原平方根方程的有效解。

解题逻辑和思路：

  1. 识别方程类型: 这是一个包含平方根的方程。
  2. 去根号: 为了方便求解，通过将方程两边平方来消去平方根。
  3. 转化方程: 平方后，方程转化为一个二次方程。
  4. 整理方程: 将二次方程整理成标准形式 ax² + bx + c = 0。
  5. 求解二次方程: 对整理后的二次方程进行因式分解 (或使用其他方法) 求出方程的根。
  6. 验根: 由于平方过程可能引入不满足原方程的解，必须将求得的每一个解代入原方程进行检验，排除增根。
  7. 确定最终解: 根据验根结果，得出原平方根方程的有效解。
