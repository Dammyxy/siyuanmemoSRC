回顾Title: 抛物线的顶点式是

y = a(x - h)² + k,

其中 (h, k) 是抛物线顶点的坐标。

如果给定抛物线的标准方程，我们可以通过配方法得到它的顶点式。

例如，考虑抛物线

y = x² + 6x + 16。

为了将这个抛物线的方程表示成顶点式，我们进行配方，如下所示：

y = x² + 6x + 16

= x² + 2 ⋅ 3 ⋅ x + 16

= x² + 2 ⋅ 3 ⋅ x + 3² - 3² + 16

= (x² + 2 ⋅ 3 ⋅ x + 3²) - 3² + 16

= (x + 3)² - 9 + 16

= (x + 3)² + 7

用顶点式表示，抛物线的方程是

y = (x - (-3))² + 7。

因此，抛物线的顶点位于点 (-3, 7)。

 

数学知识点：

  • 抛物线的顶点式：y = a(x - h)² + k，其中 (h, k) 为顶点坐标。
  • 配方法：将二次多项式转化为完全平方形式的方法。

解题逻辑和思路：

  1. 理解目标是将给定的标准形式抛物线方程 y = x² + 6x + 16 转化为顶点式 y = a(x - h)² + k。
  2. 知道转化方法是使用配方法。
  3. 从方程 y = x² + 6x + 16 开始。
  4. 关注包含 x 的项：x² + 6x。
  5. 进行配方：找到常数项，使其与 x² + 6x 构成一个完全平方三项式。这个常数项是 x 项系数一半的平方，即 (6/2)² = 3² = 9。
  6. 在原方程中加上和减去这个常数项，保持方程的等价性：y = x² + 6x + 9 - 9 + 16。
  7. 将前三项 x² + 6x + 9 组合成一个完全平方：(x + 3)²。
  8. 合并剩余的常数项：-9 + 16 = 7。
  9. 得到顶点式：y = (x + 3)² + 7。
  10. 为了更清晰地看出 h 和 k 的值，将 y = (x + 3)² + 7 改写成 y = (x - (-3))² + 7。
  11. 对照顶点式 y = a(x - h)² + k，确定 h = -3，k = 7。
  12. 得出抛物线的顶点坐标为 (-3, 7)。
