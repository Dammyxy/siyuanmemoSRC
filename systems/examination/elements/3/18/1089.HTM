示例：含多个变量的二项式与三项式相乘

乘积 (a+b)(a2+ab+b2) 中 a2b 的系数是多少？

解释

我们将第一个括号中的二项式的两项都分配到第二个括号中的三项式中。然后，我们进行化简。

(a+b)(a2+ab+b2) =

a(a2+ab+b2)+b(a2+ab+b2) =

a3+a2b+ab2+a2b+ab2+b3 =

a3+2a2b+2ab2+b3因此，a2b 的系数是 2。

数学知识点

  • 多项式乘法： 将一个多项式中的每一项与另一个多项式中的每一项相乘，然后将结果相加。这是基于分配律的应用。
  • 分配律： x(y+z) = xy + xz 。在多项式乘法中，我们将一个括号中的每一项“分配”到另一个括号中的每一项上。
  • 同类项： 具有相同变量和相同指数的项。例如，a2b  和 a2b 是同类项，而 a3 和a2b 不是。
  • 合并同类项： 将同类项的系数相加或相减来简化表达式。例如，a2b + a2b = (1+1)a2b = 2a2b。
  • 系数： 在一个单项式中，变量前面的数字因子。例如，在 2a2b 中，a2b 的系数是 2。

解题逻辑和思路

这道题的逻辑是直接进行多项式乘法，然后找到特定项 (a2b) 并确定其系数。这是一个直接应用多项式乘法规则的过程。

解题思路：

  1. 识别要相乘的多项式： 一个是二项式 \((a+b)\)，另一个是三项式 \((a^2+ab+b^2)\)。
  2. 应用分配律进行乘法： 将第一个二项式中的每一项分别乘以第二个三项式中的每一项。
    • 将 \(a\) 乘以 \((a^2+ab+b^2)\)：\(a \cdot a^2 + a \cdot ab + a \cdot b^2 = a^3 + a^2b + ab^2\)。
    • 将 \(b\) 乘以 \((a^2+ab+b^2)\)：\(b \cdot a^2 + b \cdot ab + b \cdot b^2 = a^2b + ab^2 + b^3\)。
  3. 将所有乘积相加： 将上面两个步骤得到的乘积相加。 \[ (a^3 + a^2b + ab^2) + (a^2b + ab^2 + b^3) = a^3 + a^2b + ab^2 + a^2b + ab^2 + b^3 \]
  4. 合并同类项： 找到表达式中的同类项并将它们的系数相加。
    • \(a^3\) 没有同类项，保持不变。
    • \(a^2b\) 的同类项是 \(a^2b\)。合并后是 \(a^2b + a^2b = 2a^2b\)。
    • \(ab^2\) 的同类项是 \(ab^2\)。合并后是 \(ab^2 + ab^2 = 2ab^2\)。
    • \(b^3\) 没有同类项，保持不变。
    合并后的表达式是 \(a^3 + 2a^2b + 2ab^2 + b^3\)。
  5. 确定指定项的系数： 题目要求找到 \(a^2b\) 的系数。在合并后的表达式 \(a^3 + 2a^2b + 2ab^2 + b^3\) 中，\(a^2b\) 的项是 \(2a^2b\)。
  6. 得出系数： \(2a^2b\) 中的系数是 2。

因此，乘积 \((a+b)(a^2+ab+b^2)\) 中 \(a^2b\) 的系数是 2。
