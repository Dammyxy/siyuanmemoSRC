Title: 证明线对垂直定理(Proving the Linear Pair Perpendicular Theorem)

假设角 ∠BAC 和 ∠CAD 是全等的。

我们希望证明以下陈述：

直线 l 和 m 是垂直的。

我们证明这个结果的策略如下：根据邻补角公设，这两个角是互补的。但因为它们也相等，所以两个角都必须等于 90°。因此，这两条线是垂直的。

现在让我们构建我们的分步证明：

  • 步骤 1: 给定条件是 ∠BAC ≅ ∠CAD。
  • 步骤 2: 根据全等角的定义，我们有 m∠BAC = m∠CAD。
  • 步骤 3: 根据邻补角公设，∠BAC 和 ∠CAD 是互补的。
  • 步骤 4: 根据补角的定义，可以得出 m∠BAC + m∠CAD = 180°。
  • 步骤 5: 在步骤 2 和 4 中，我们分别证明了

    m∠BAC = m∠CAD 和 m∠BAC + m∠CAD = 180°。

    因此，使用代换法，我们得到

    m∠CAD + m∠CAD = 180°

  • 步骤 6: 使用步骤 5 的结果，我们求解 m∠CAD：

    m∠CAD + m∠CAD = 180°

    2m∠CAD = 180°

    m∠CAD = 90°

  • 步骤 7: 最后，根据垂直线的定义，我们得出结论，l 和 m 是垂直的，证明完毕。

数学知识点

  • 邻补角 (Linear Pair): 两个角共享一条公共边，并且它们的非公共边是两条相反的射线，形成一条直线。
  • 邻补角公设 (Linear Pair Postulate): 如果两个角形成一个邻补角，那么它们是互补的。
  • 全等角 (Congruent Angles): 度数相等的角。记作 ∠A ≅ ∠B。
  • 补角 (Supplementary Angles): 两个角之和为 180°。
  • 垂直线 (Perpendicular Lines): 两条相交的直线，如果它们形成的任意一个角是直角 (90°)，则这两条直线互相垂直。
  • 代换属性 (Substitution Property): 在一个等式中，一个量可以用一个相等的量来替换。
  • 公设 vs. 定理 (Postulate vs. Theorem):
    • 公设 (或公理 Axiom): 一个被接受为真理而无需证明的基本陈述，是逻辑推演的起点。
    • 定理: 一个可以通过公设、定义以及其他已被证明的定理来证明为真的陈述。本例中证明的“线对垂直定理”就是一个定理。

解题逻辑和思路

这个证明的目的是要从一个基本事实（邻补角公设）出发，通过严密的逻辑推理，得出一个新的、可以被反复使用的结论（定理）。整个过程如同搭积木，每一步都必须稳固地建立在前一步的基础上。

  1. 起点 (Given - 已知条件): 证明始于一个明确的已知条件：有两个角 ∠BAC 和 ∠CAD，它们形成一条直线（所以是邻补角），并且它们是全等的（∠BAC ≅ ∠CAD）。
  2. 应用定义和公设:
    • 从“全等”这个条件，根据其定义，直接转化为代数关系：m∠BAC = m∠CAD (步骤 2)。
    • 从“邻补角”这个图形特征，根据邻补角公设，得出它们“互补” (步骤 3)。
    • 再根据“互补”的定义，将其转化为代数关系：m∠BAC + m∠CAD = 180° (步骤 4)。
    此时，我们已经把几何问题成功地转化为了代数问题。我们现在有两个代数等式。
  3. 代数求解 (Solve using Algebra):
    • 利用“代换法”，将等式 `m∠BAC = m∠CAD` 代入到 `m∠BAC + m∠CAD = 180°` 中。
    • 这样就得到了一个只含有一个未知数 `m∠CAD` 的方程：`m∠CAD + m∠CAD = 180°` (步骤 5)。
    • 解这个简单的代数方程，得到 `m∠CAD = 90°` (步骤 6)。
  4. 回归几何，得出结论:
    • 我们得到了一个角的度数是 90°。
    • 根据“垂直线”的定义（形成 90° 角的线），我们得出结论：直线 l 和 m 是垂直的 (步骤 7)。

这个过程展示了如何将一个直观的几何观察，分解为一系列基于公设和定义的、不可辩驳的逻辑步骤，最终得出一个坚实的数学定理。
