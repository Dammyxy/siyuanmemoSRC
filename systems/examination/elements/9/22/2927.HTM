翻译

介绍

要解一个两边具有相同底数的对数方程，我们可以对等式两边以该底数进行取幂运算。例如，考虑以下方程

log3(2x − 4) = log3(x + 3).

由于方程两边都表示为以相同底数 (3) 的对数，我们可以对等式两边以 3 进行取幂运算。这得到

3log3(2x−4) = 3log3(x+3)

2x − 4 = x + 3.

现在，我们求解 x：

2x − 4 = x + 3

x = 7

因此，x = 7 是解。

注意：请记住，在解对数方程时，有时可能会得到实际上不满足原方程的增根。我们不能对零或负数取对数。

所以，一旦我们找到了解，就需要将它们代回原方程，并检查对数的真数是否为正。将 x = 7 代回原方程，我们得到

?
log3(2x − 4)  =  log3(x + 3)
?
log3(2 ⋅ 7 − 4)  =  log3(7 + 3)

log3(10) = log3(10). ✓

因此，x = 7 是一个有效的解。

数学知识点

  • 对数方程的基本性质：如果一个方程的形式为 logb(A) = logb(B)，那么可以推导出 A = B。这利用了对数函数是一对一函数的性质。文中的“取幂运算”就是应用此性质的具体方法，即 blogb(A) = A。
  • 对数函数的定义域：对数的真数（括号内的部分）必须是正数。例如，在 logb(A) 中，A 必须大于 0。
  • 增根（Extraneous Solutions）：在解对数方程的过程中，通过代数变换得到的解，可能不满足原始对数方程的定义域要求（即导致真数为零或负数）。这种解被称为增根，必须舍弃。
  • 验根：解出对数方程后，必须将解代回原方程进行检验，确保所有对数的真数都为正值，以排除增根。

解题逻辑和思路

解决形如 logb(f(x)) = logb(g(x)) 的对数方程的策略如下：

  1. 求解方程：
    • 利用对数性质，将方程两边的对数去掉，使得它们的真数相等。这可以通过对等式两边同时以底数 `b` 进行取幂来实现，得到 f(x) = g(x)。
    • 解这个新的（通常是代数）方程 f(x) = g(x)，求出 x 的一个或多个潜在解。
  2. 检验解的有效性（验根）：
    • 将第一步中求出的每个 x 值代回到原始对数方程中。
    • 检查方程中每个对数的真数（即 f(x) 和 g(x)）的值是否都大于零。
    • 如果一个解使得任何一个真数小于或等于零，那么这个解就是增根，必须舍弃。
    • 只有那些使所有真数都为正的解才是方程的有效解。
