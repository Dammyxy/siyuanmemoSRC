Title: 计算 P(A' ∪ B') 的整个过程。

这个计算分为三个核心步骤：

第一步：补全信息，求出 P(B)

题目给出了 P(A), P(A ∩ B) 和 P(A ∪ B)，但为了完整地画出维恩图，我们需要先求出 P(B)。

  • 使用公式：P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
  • 代入数值：2/3 = 1/2 + P(B) - 1/6
  • 解出结果：P(B) = 1/3

第二步：画出维恩图，填入各区域的概率

这是最关键的一步，它把抽象的概率变成了直观的区域。维恩图被分为四个独立的部分：

  1. 中间重叠部分 (A和B都发生)：

    • 概率就是 P(A ∩ B) = 1/6 (已知)。

  2. 左边月牙部分 (只发生A，不发生B)：

    • 用A的总概率减去中间重叠部分的概率。
    • P(A) - P(A ∩ B) = 1/2 - 1/6 = 1/3。

  3. 右边月牙部分 (只发生B，不发生A)：

    • 用B的总概率减去中间重叠部分的概率。
    • P(B) - P(A ∩ B) = 1/3 - 1/6 = 1/6。

  4. 方框内、圆圈外的部分 (A和B都不发生)：

    • 用总概率1减去A和B至少发生一个的概率 (P(A ∪ B))。
    • 1 - P(A ∪ B) = 1 - 2/3 = 1/3。

第三步：确定目标区域并求和

  • 理解目标：P(A' ∪ B') 的意思是 “A不发生” 或 “B不发生” 的概率。
  • 对应区域：在维恩图上，这包括了除了中间重叠部分之外的所有区域。
  • 加总概率：把这三个区域的概率相加。
    • P(A' ∪ B') = (只发生A的概率) + (只发生B的概率) + (A和B都不发生的概率)
    • P(A' ∪ B') = 1/3 + 1/6 + 1/3 = 5/6

Title: 计算 P(A' ∪ B') 的整个过程 : 更快捷的计算方法 (德摩根定律)

“A不发生 或 B不发生” 等价于 “不是A和B都发生”。所以，可以直接用总概率1减去“A和B都发生”的概率。

  • P(A' ∪ B') = 1 - P(A ∩ B)
  • P(A' ∪ B') = 1 - 1/6 = 5/6

这个方法更快，但理解起来需要熟悉德摩根定律。图片中的方法虽然步骤多，但非常直观。
