Title: 三角形中位线定理 : 如何用相似三角形来证明中位线定理？

这个证明过程非常经典，而且能很好地帮助你理解为什么这个定理成立。我们来看一下具体的步骤：

已知：在 △ABC 中，D 是 BC 的中点，E 是 AC 的中点。 求证：DE || AB 且 DE = ½ AB。

证明过程：

  1. 找出两个可能相似的三角形：观察图形，我们可以看到一个“大”三角形 △ABC 和一个“小”三角形 △EDC。我们的目标就是证明这两个三角形相似。

  2. 寻找证明相似的条件 (SAS 相似判定)：要证明两个三角形相似，我们可以用“角角(AA)”，“边角边(SAS)”，或“边边边(SSS)”。这里用“边角边(SAS)”最直接。

    • 边 (Side): 因为 D 是 BC 的中点，所以 CD = ½ BC。可以写成比例式：CD / BC = 1/2。
    • 角 (Angle): 角 C 是 △ABC 和 △EDC 共有的角。所以 ∠ECD = ∠ACB。
    • 边 (Side): 因为 E 是 AC 的中点，所以 CE = ½ AC。可以写成比例式：CE / AC = 1/2。

  3. 得出相似结论：我们现在有了：

    • 两条边的比例相等：CD / BC = CE / AC = 1/2
    • 这两条边的夹角相等：∠C = ∠C

    根据“两边成比例且夹角相等”的相似三角形判定定理 (SAS Similarity)，我们可以得出结论： △EDC ~ △ABC (注意顶点的对应顺序：E对应A，D对应B，C对应C)

  4. 利用相似性质推导出定理：一旦我们证明了两个三角形相似，我们就可以利用相似三角形的性质了：

    • 对应角相等：∠CED = ∠CAB (也就是∠A)。
      • 因为这两个同位角相等，所以根据平行线的判定定理，我们可以得出 DE || AB。 (这是定理的第一个部分)：注意同位角只是个位置关系，不要求平行
    • 对应边成比例：相似三角形的对应边比例等于相似比。
      • DE / AB = CD / BC = CE / AC = 1/2
      • 从 DE / AB = 1/2，我们可以直接得到 DE = ½ AB。 (这是定理的第二个部分)

证明完毕！

通过这个证明，你就能清楚地看到，中位线定理的两个性质（平行和减半）都是从“小三角形与大三角形相似，且相似比为1:2”这个核心事实中自然推导出来的。这也就是图片中括号里那句话“它本身就是用相似三角形证明的”的含义。
