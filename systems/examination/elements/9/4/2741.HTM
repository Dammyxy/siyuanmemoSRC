问题 2

该图代表函数 y =
a
x − b
+ k。a + b + k 的值是多少？

  • a. 6
  • b. −1.5
  • c. 2
  • d. 1.5
  • e. 3.5

✓ 正确

解释

首先，注意图中水平渐近线是 y = 2，而垂直渐近线是 x = 1。这意味着 k = 2 且 b = 1，我们可以将函数重写为：


y =
a
x − 1
 + 2

此外，我们已知点 (2, 5) 在图像上。将其坐标代入上述方程，我们得到：


y =
a
x − 1
 + 2

5 =
a
2 − 1
 + 2

3 =
a
1

a = 3。

最后，a + b + k = 3 + 1 + 2 = 6。

数学知识点

  • 有理函数 (Rational Function): 特指形式为 y =
    a
    x − b
    + k 的函数图像，这是一个双曲线。
  • 水平渐近线 (Horizontal Asymptote): 当 x 趋向于正无穷或负无穷时，函数图像无限接近的一条水平线。对于 y =
    a
    x − b
    + k 的形式，水平渐近线是 y = k。
  • 垂直渐近线 (Vertical Asymptote): 当函数值趋向于正无穷或负无穷时，函数图像无限接近的一条垂直线。它发生在分母为零的位置。对于 y =
    a
    x − b
    + k 的形式，垂直渐近线是 x = b。
  • 代入法 (Substitution): 将已知点的坐标 (x, y) 代入函数方程，以求解未知参数。
  • 解一元一次方程 (Solving a Linear Equation): 通过代数运算（如移项、合并同类项）来求出方程中未知数的值。

解题逻辑和思路

本题的解题策略是Title: 利用函数图像的特征来确定函数表达式中的未知参数，然后进行计算。

  1. 从图中识别渐近线:
    • 观察图像，找到虚线表示的渐近线。
    • 水平渐近线是 y = 2。
    • 垂直渐近线是 x = 1。
  2. 关联渐近线与函数参数:
    • 根据有理函数 y =
      a
      x − b
      + k 的性质，将渐近线方程与参数对应起来。
    • 水平渐近线 y = k 对应 y = 2，因此得出 k = 2。
    • 垂直渐近线 x = b 对应 x = 1，因此得出 b = 1。
  3. 利用已知点求解剩余参数:
    • 图像上标明了一个点 (2, 5)，这个点满足函数方程。
    • 将已求出的 b = 1 和 k = 2 以及点的坐标 x = 2, y = 5 代入函数方程 y =
      a
      x − b
      + k。
    • 得到方程 5 =
      a
      2 − 1
      + 2。
    • 解这个关于 a 的方程，得到 a = 3。
  4. 计算最终结果:
    • 将求出的所有参数值 a = 3, b = 1, k = 2 相加。
    • 计算 a + b + k = 3 + 1 + 2 = 6。
