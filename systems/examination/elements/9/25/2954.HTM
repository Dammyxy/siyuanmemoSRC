问题 1

回答本题需要使用计算器。

在一家咖啡店里，随机选择了50名顾客，并就他们在咖啡馆消费的主要饮品进行了调查。调查结果如下：

  • 12名顾客喝茶
  • 17名顾客喝卡布奇诺
  • 22名顾客喝水果冰沙
  • 4名顾客喝茶和卡布奇诺
  • 5名顾客喝茶和水果冰沙
  • 5名顾客喝卡布奇诺和水果冰沙
  • 3名顾客喝茶、卡布奇诺和水果冰沙

从参与调查的50名顾客中随机选择一名。该顾客Title: 不喝茶、不喝卡布奇诺、也不喝水果冰沙的概率是多少？请将你的答案保留到小数点后两位。

a 0.19

b 0.29

c 0.20

d 0.16

e 0.32

✓ 正确
解释

在为3个事件构建韦恩图时，我们从中间开始，然后向外推展。

首先，注意到有3名顾客同时喝茶、卡布奇诺和水果冰沙。

  • 因为有4名顾客喝茶和卡布奇诺，所以有 4 − 3 = 1 名顾客喝茶和卡布奇诺，但不喝水果冰沙。
  • 因为有5名顾客喝茶和水果冰沙，所以有 5 − 3 = 2 名顾客喝茶和水果冰沙，但不喝卡布奇诺。
  • 因为有5名顾客喝卡布奇诺和水果冰沙，所以有 5 − 3 = 2 名顾客喝卡布奇诺和水果冰沙，但不喝茶。

设 T 为事件“顾客喝茶”，C 为事件“顾客喝卡布奇诺”，F 为事件“顾客喝水果冰沙”。那么我们的韦恩图如下：

我们通过减去适当的数量来找出剩余区域的数字。

  • 因为有12名顾客喝茶，所以有 12 − 1 − 3 − 2 = 6 名顾客只喝茶，而不喝卡布奇诺和水果冰沙。
  • 因为有17名顾客喝卡布奇诺，所以有 17 − 1 − 3 − 2 = 11 名顾客只喝卡布奇诺，而不喝茶和水果冰沙。
  • 因为有22名顾客喝水果冰沙，所以有 22 − 2 − 3 − 2 = 15 名顾客只喝水果冰沙，而不喝茶和卡布奇诺。

数学知识点

  • 集合论 (Set Theory): 问题涉及到将不同类型的顾客分组，这在数学上是用集合来表示的。每个饮品种类（茶、卡布奇诺、水果冰沙）都可以看作一个集合。
  • 集合运算 (Set Operations):
    • 交集 (Intersection, ∩): 例如，“喝茶和卡布奇诺的顾客”代表集合T和集合C的交集，记作 T ∩ C。
    • 并集 (Union, ∪): “至少喝一种饮品的顾客”代表三个集合的并集，记作 T ∪ C ∪ F。
    • 补集 (Complement, '): “不喝茶的顾客”代表集合T的补集，记作 T' 或 Tc。题目所求的“三种都不喝的顾客”是并集 (T ∪ C ∪ F) 的补集。根据德摩根定律 (De Morgan's Laws)，(T ∪ C ∪ F)' = T' ∩ C' ∩ F'。
  • 韦恩图 (Venn Diagram): 一种用图形表示集合之间关系的工具，特别适用于解决涉及2个或3个集合的交集和并集问题。
  • 容斥原理 (Principle of Inclusion-Exclusion): 用于计算多个集合并集大小的公式。对于三个集合，公式为：|T ∪ C ∪ F| = |T| + |C| + |F| − |T ∩ C| − |T ∩ F| − |C ∩ F| + |T ∩ C ∩ F|。  概率 (Probability): 基本概率的计算，即“目标事件发生的数量”除以“所有可能结果的总数”。

解题逻辑和思路

这个问题的目标是找出在50名顾客中，完全不喝茶、不喝卡布奇诺、也不喝水果冰沙的人数，并计算其概率。有两种主要的解题策略：

策略一：使用韦恩图（题目解析中使用的方法）

这是一种“由内向外”的可视化方法，非常直观。

  1. 定义集合: 设 T = {喝茶的顾客}, C = {喝卡布奇诺的顾客}, F = {喝水果冰沙的顾客}。总样本空间 S 的大小为 50。
  2. 从最核心的交集开始: 找到所有三个集合的交集，即同时喝三种饮品的顾客人数。
    • 喝茶、卡布奇诺和水果冰沙的人数 = 3。这是韦恩图最中心的区域。
  3. 计算“只喝两种”的区域: 用两个集合的交集总数减去三个集合的交集数。
    • 只喝茶和卡布奇诺 (不喝冰沙) = (喝茶和卡布奇诺总数) − (喝三种饮品人数) = 4 − 3 = 1。
    • 只喝茶和水果冰沙 (不喝卡布奇诺) = (喝茶和冰沙总数) − (喝三种饮品人数) = 5 − 3 = 2。
    • 只喝卡布奇诺和水果冰沙 (不喝茶) = (喝卡布奇诺和冰沙总数) − (喝三种饮品人数) = 5 − 3 = 2。
  4. 计算“只喝一种”的区域: 用每个集合的总数减去所有与之相关的交集区域人数。
    • 只喝茶 = (喝茶总数) − (只喝茶和卡布奇诺) − (只喝茶和冰沙) − (喝三种) = 12 − 1 − 2 − 3 = 6。
    • 只喝卡布奇诺 = (喝卡布奇诺总数) − (只喝茶和卡布奇诺) − (只喝卡布奇诺和冰沙) − (喝三种) = 17 − 1 − 2 − 3 = 11。
    • 只喝水果冰沙 = (喝冰沙总数) − (只喝茶和冰沙) − (只喝卡布奇诺和冰沙) − (喝三种) = 22 − 2 − 2 − 3 = 15。
  5. 计算三种都不喝的人数: 从总人数中减去所有喝饮品的顾客人数（即韦恩图中所有区域数字的总和）。
    • 三种都不喝的人数 = 50 − (6 + 11 + 15 + 1 + 2 + 2 + 3) = 50 − 40 = 10。
  6. 计算概率: 用三种都不喝的人数除以总人数。
    • 概率 = 10 / 50 = 0.20。

策略二：使用集合运算（容斥原理）

这是你提到的不画图，直接用公式计算的方法。核心是先计算出“至少喝一种饮品”的总人数，然后用总人数减去这个数值。

  1. 目标: 计算至少喝一种饮品的人数，即 |T ∪ C ∪ F|。
  2. 应用容斥原理公式:

    |T ∪ C ∪ F| = |T| + |C| + |F| − |T ∩ C| − |T ∩ F| − |C ∩ F| + |T ∩ C ∩ F|

  3. 代入已知数据:
    • |T| = 12
    • |C| = 17
    • |F| = 22
    • |T ∩ C| = 4
    • |T ∩ F| = 5
    • |C ∩ F| = 5
    • |T ∩ C ∩ F| = 3
  4. 计算并集大小:

    |T ∪ C ∪ F| = 12 + 17 + 22 − 4 − 5 − 5 + 3

    |T ∪ C ∪ F| = 51 − 14 + 3 = 40

    这40人代表至少喝了三种饮品中的一种。

  5. 计算补集大小（三种都不喝的人）:

    三种都不喝的人数 = 总人数 − 至少喝一种的人数

    | (T ∪ C ∪ F)' | = |S| − |T ∪ C ∪ F| = 50 − 40 = 10

  6. 计算概率:

    所求概率 P(T' ∩ C' ∩ F') = P((T ∪ C ∪ F)') = 10 / 50 = 0.20。

结论: 两种方法都得到了相同的结果。韦恩图法更直观，适合理解各部分的人数构成；容斥原理法更抽象，依赖公式，计算更直接，尤其在集合数量更多时更显优势。
