#### 6.1.2 作为缩写引入的符号

\[
\phi  \vee  \psi  \triangleq   \sim  \phi  \rightarrow  \psi
\]

\[
\phi  \land  \psi  \triangleq   \sim  \left( {\phi  \rightarrow   \sim  \psi }\right)  \tag{6.1}
\]

\[
\phi  \leftrightarrow  \psi  \triangleq  \left( {\phi  \rightarrow  \psi }\right)  \land  \left( {\psi  \rightarrow  \phi }\right)

### 6.4 真实性和重言性的保存,可靠性定理

这一节里, 我们讨论推演规则对真实性的保存和对重言性的保存, 进而建立命题演算的可靠性定理。我们在引言里说过, 在演绎中, 规则的使用从真命题只能得到真命题。我们把使用于任何真命题都只能得到真命题的规则称为保存真实性的 (truth-preserving) 规则。易见, $ \mathrm{{mp}} $ 是保存真实性的,因为很容易证明: 对任何公式 $ \phi $ 和 $ \psi ,\phi ,\phi  \rightarrow  \psi { \vDash  }_{0}\psi $ (见习题 3.3)。

我们在 $ {\mathbf{H}}_{0} $ 的演绎中除 $ \mathrm{{mp}} $ 外唯一可用的规则是 $ \mathrm{{sub}} $ 本身并不保存真实性: 将 sub 用于 $ p $ 可以得到 $ \sim  p $ ,而 “ $ p{ \vDash  }_{0} \sim  p $ ” 显然是不成立的。

不过, sub 有一种性质, 即从重言式只能得到重言式。我们把使用于任何重言式都只能得到重言式的规则称为保存重言性的 (tautology-preserving, validity-preserving) 规则。由于 $ \mathrm{{sub}} $ 在 $ {\mathbf{H}}_{0} $ 演绎中只能用于公理, 而公理又都是重言式 (见习题 3.4),所以在 $ {\mathbf{H}}_{0} $ 的演绎中,虽然一些命题可以是用 sub 得到的, 但这些命题却只能是真的。这就是说, 我们这两章谈到的演绎, 都不会从真命题演绎出假命题。

在 $ §{3.6} $ 中,我们讨论过代入的某些语义性质,而正是这些性质使 sub 保存重言性。假设我们的对象语言是 $ {\mathcal{L}}_{0} $ 。

$ {}^{6} $ 以下讨论的基本思想来自 Machover [1996]。不过, Machover [1996] 中的讨论要求可演绎关系满足 $ \mathrm{{mp}},\mathrm{{DT}},\mathrm{{IE}},{\mathrm{{SRAA}}}^{ * } $ 和 $ \mathrm{{SRAA}} $ ,而我们知道 (参见命题 313), $ \mathrm{{SRAA}} $ 不是必要的。

$ {}^{7} $ 一旦有了这个假定,可以证明 $ {\mathbf{H}}^{ * } $ 中不会演绎出比 $ {\mathbf{H}}_{0},\ldots ,{\mathbf{H}}_{4} $ 更多的东西,即 $ {\mathbf{H}}^{ * } $ 与 $ {\mathbf{H}}_{0},\ldots ,{\mathbf{H}}_{4} $ 都等价。

证明 根据上面的假设,定理 321 对 $ {\mathbf{H}}^{ * } $ 成立。如果 $ {\mathbf{H}}^{ * } $ 不一致,则存在公式 $ \phi $ 使得 $ { \vdash  }^{ * }\phi $ 且 $ { \vdash  }^{ * } \sim  \phi $ ,再由定理 321 得到 $ \phi $ 和 $ \sim  \phi $ 都是重言式,而这是不可能的。

上面讨论的一致性是公理系统本身的一致性。下面讨论的是公式集 (理论、信念)的一致性。

定义 325 对每个公式集 $ \Gamma ,\Gamma $ 是一致的当且仅当不存在公式 $ \phi $ 使得 $ \Gamma { \vdash  }^{ * }\phi $ 并且 $ \Gamma { \vdash  }^{ * } \sim  \phi $ 。

定义 326 对每个公式集 $ \Gamma ,\Gamma $ 是不一致的当且仅当 $ \Gamma $ 不是一致的,即存在公式 $ \phi $ 使得 $ \Gamma { \vdash  }^{ * }\phi $ 并且 $ \Gamma { \vdash  }^{ * } \sim  \phi $ 。

从演绎和一致性的定义, 可以直接得到下述定理。整个定理的证明很简单, 我们把它留作习题。

定理 327 对每个公式集 $ \Gamma ,\Gamma $ 不一致当且仅当 $ \Gamma $ 的某个有穷子集不一致 ( $ \Gamma $ 是一致的当且仅当 $ \Gamma $ 的所有有穷子集都是一致的)。

对任意公式集 $ \Gamma $ ,我们称 $ \left\{  {\phi  : \Gamma { \vdash  }^{ * }\phi }\right\} $ 为 $ \Gamma $ 的演绎后承集。

定理 328 对每个公式集 $ \Gamma $ ,如果 $ \Gamma $ 是一致的,那么它的演绎后承集也是一致的。

证明 令 $ \Delta  = \left\{  {\phi  : \Gamma { \vdash  }^{ * }\phi }\right\} $ 并设 $ \Delta $ 不一致。根据定义 325,存在 $ \phi $ 使得 $ \Delta { \vdash  }^{ * }\phi $ 并且 $ \Delta { \vdash  }^{ * } \sim  \phi $ 。由定理 327 易见存在 $ {\psi }_{0},\ldots ,{\psi }_{n} \in  \Delta $ 使得 $ {\psi }_{0},\ldots ,{\psi }_{n}{ \vdash  }^{ * }\phi $ 并且 $ {\psi }_{0},\ldots ,{\psi }_{n}{ \vdash  }^{ * } \sim  \phi $ 。根据演绎后承集的定义,对每个 $ i \leq  n,\Gamma { \vdash  }^{ * }{\psi }_{i} $ ,所以由 Cut 得到 $ \Gamma { \vdash  }^{ * }\phi $ 且 $ \Gamma { \vdash  }^{ * } \sim  \phi $ ,于是 $ \Gamma $ 不一致。

由于我们假设了 $ {\mathbf{H}}^{ * } $ 的可靠性定理,可满足的公式集都是一致的。

定理 329 对每个公式集 $ \Gamma $ ,如果 $ \Gamma $ 可满足,那么 $ \Gamma $ 是一致的。

证明 设 $ \Gamma $ 不一致,即存在 $ \phi $ 使得 $ \Gamma { \vdash  }^{ * }\phi $ 且 $ \Gamma { \vdash  }^{ * } \sim  \phi $ 。根据可靠性定理, $ \Gamma { \vDash  }_{0}\phi $ 且 $ \Gamma { \vDash  }_{0} \sim  \phi $ 。假如 $ \Gamma $ 可满足,即有真值指派 $ \sigma $ 使得 $ \sigma  \vDash  \Gamma $ ,那么由重言蕴涵定义知 $ \sigma  \vDash  \phi $ 且 $ \sigma  \mathrel{\text{\vDash \not{} }} \phi $ ,而这是不可能的。所以 $ \Gamma $ 不可满足。

下述定理说的是: 一公式集不一致的充分必要条件是从它可以演绎出所有的公式。这就是说, 一公式集是一致的当且仅当从它不能演绎出所有公式。8 这个定理和 IE 事实上是等价的 (见习题 6.23)。

定理 330 对任何公式集 $ \Gamma ,\Gamma $ 不一致当且仅当对所有公式 $ \phi ,\Gamma { \vdash  }^{ * }\phi $ 。

证明 如果对所有公式 $ \phi $ 都有 $ \Gamma { \vdash  }^{ * }\phi $ ,那么根据一致性的定义, $ \Gamma $ 不一致。 如果 $ \Gamma $ 不一致,即存在公式 $ \psi $ 使得 $ \Gamma { \vdash  }^{ * }\psi $ 并且 $ \Gamma { \vdash  }^{ * } \sim  \psi $ ,那么对每个公式 $ \phi $ ,根据 IE 得知 $ \Gamma { \vdash  }^{ * }\phi $ 。

当我们说 $ {\phi }_{0},\ldots ,{\phi }_{n} $ 是 (不) 一致的,我们的意思是说 $ \left\{  {{\phi }_{0},\ldots ,{\phi }_{n}}\right\} $ 是 (不) 一致的。当我们说 $ \Delta $ 与 $ \phi $ 是 (不) 一致的,我们的意思是说 $ \Delta  \cup  \{ \phi \} $ 是 (不) 一致的。

定理 331 对任何公式集 $ \Gamma $ 和任何公式 $ \phi ,\Gamma { \vdash  }^{ * }\phi $ 当且仅当 $ \Gamma $ 与 $ \sim  \phi $ 不一致。

证明 如果 $ \Gamma { \vdash  }^{ * }\phi $ ,那么显然, $ \Gamma , \sim  \phi { \vdash  }^{ * }\phi $ 并且 $ \Gamma , \sim  \phi { \vdash  }^{ * } \sim  \phi $ ,即 $ \Gamma  \cup  \{  \sim  \phi \} $ 不一致。如果 $ \Gamma $ 与 $ \sim  \phi $ 不一致,那么根据定理 $ {330},\Gamma , \sim  \phi { \vdash  }^{ * }\phi $ ,再由 $ {\mathrm{{SRAA}}}^{ * } $ 得到 $ \Gamma { \vdash  }^{ * }\phi $ 。

定理 332 对任何公式集 $ \Gamma $ 和任何公式 $ \phi ,\Gamma { \vdash  }^{ * } \sim  \phi $ 当且仅当 $ \Gamma $ 与 $ \phi $ 不一致。

证明 如果 $ \Gamma { \vdash  }^{ * } \sim  \phi $ ,那么显然, $ \Gamma ,\phi { \vdash  }^{ * } \sim  \phi $ 并且 $ \Gamma ,\phi { \vdash  }^{ * }\phi $ ,即 $ \Gamma  \cup  \{ \phi \} $ 不一致。如果 $ \Gamma $ 与 $ \phi $ 不一致,那么根据定理 $ {330},\Gamma ,\phi { \vdash  }^{ * } \sim  \phi $ ,再由 SRAA 得到 $ \Gamma { \vdash  }^{ * } \sim  \phi $ 。■

定理 333 对每个非空公式集 $ \Gamma ,\Gamma $ 不一致当且仅当对任何公式 $ \phi  \in $ $ \Gamma ,\Gamma  - \{ \phi \} { \vdash  }^{ * } \sim  \phi $ 。

证明 证明: 如果 $ \phi  \in  \Gamma $ 且 $ \Gamma  - \{ \phi \} { \vdash  }^{ * } \sim  \phi $ ,那么显然有 $ \Gamma { \vdash  }^{ * } \sim  \phi $ 且 $ \Gamma { \vdash  }^{ * }\phi $ , 即 $ \Gamma $ 不一致。如果 $ \Gamma $ 不一致,那么根据定理 330,对每个 $ \phi  \in  \Gamma ,\Gamma { \vdash  }^{ * } \sim  \phi $ , 亦即 $ \Gamma  - \{ \phi \} ,\phi { \vdash  }^{ * } \sim  \phi $ ,从而由 SRAA 得到 $ \Gamma  - \{ \phi \} { \vdash  }^{ * } \sim  \phi $ 。 ∎

上述定理中 $ \Gamma  \neq  \varnothing $ 的条件不可少,因为不足道地,对每个 $ \phi  \in  \varnothing $ 都有 $ \varnothing  - \{ \phi \}  \vdash   \sim  \phi $ ,但由可靠性定理知 $ \varnothing $ 是一致的。

### 6.6 范式

在 $ §{3.8} $ 中,我们讨论过合取范式和析取范式,也了解到每个公式都有其合取范式和析取范式。根据定义, 一个公式的合取范式和析取范式分别是与该公式重言等值的合取范式和析取范式。这是运用语义概念 (重言等值) 来下的定义。在说明每个公式都有其合取范式和析取范式时, 我们是根据其真值表中命题变号的可能取值组合来构造它的合取范式和析取范式。这就是说, 我们用的也是语义的方法。

由可靠性定理,我们知道在 $ {\mathbf{H}}_{0} $ 中可证等值的公式一定也是重言等值的。因此,如果每个公式都在 $ {\mathbf{H}}_{0} $ 中与一个合取范式和一个析取范式可证等值, 那么对求任意公式的范式, 我们就有了一个纯语法的方法。事实上, 这种方法是有的。

定理 338 (范式存在定理) 对每个公式 $ \phi $ ,存在一合取范式 $ {\phi }^{ * } $ 使得 $ { \vdash  }_{0}\phi  \leftrightarrow  {\phi }^{ * } $ ; 并且存在一析取范式 $ {\phi }^{ * } $ 使得 $ { \vdash  }_{0}\phi  \leftrightarrow  {\phi }^{ * } $ 。

### 6.7 独立性问题

前面讨论了诸多系统中的演绎和证明。虽然我们后来证明了, 那些不同系统中的可演绎性和可证明性都是重合的; 但在讨论每个系统中的演绎和证明时, 我们毕竟要从该系统的公理和规则出发, 而不能从其他系统的公理或规则出发。概括地说, 演绎是相对于一定的初始条件来说的, 比如公理、推演规则甚至语言中的初始符号等等。这一点读者应该已经熟悉了。不过这里要强调一点: 演绎对某些初始条件的依赖, 绝非 “逻辑人” 的嗜好, 更不是什么“习惯”、“文化” 乃至 “话语霸权”。之所以演绎不能脱离初始条件来说, 是因为相对于某些初始条件可演绎的,相对于另一些初始条件却不可演绎。

#### 6.7.1 不可演绎性和不可证明性

给定某一公理系统 $ \mathbf{S} $ 和其中的可演绎关系 $ { \vdash  }_{\mathbf{S}} $ 。如果 $ \Gamma { \nvdash  }_{\mathbf{S}}\phi $ ,我们就说 $ \phi $ 是 (相对于 $ \mathbf{S} $ 的公理和推演规则) 独立于 $ \Gamma $ 的; 如果 $ {F}_{\mathbf{S}}\phi $ ,我们也会说 $ \phi $ 是 (相对于 $ \mathbf{S} $ 的推演规则) 独立于 $ \mathbf{S} $ 的公理的。显然,我们没能证明 $ \Gamma { \vdash  }_{\mathbf{S}}\phi $ (或 $ { \vdash  }_{\mathbf{S}}\phi $ ) 并不等于 $ \Gamma { \nvdash  }_{\mathbf{S}}\phi $ (或 $ { \nvdash  }_{\mathbf{S}}\phi $ ) 就成立。要确立命题 $ \Gamma { \nvdash  }_{\mathbf{S}}\phi $ 或命题 $ {Y}_{\mathbf{S}}\phi $ ,唯一的办法是用数学方法证明不存在 $ \mathbf{S} $ 中从 $ \Gamma $ (或 $ \varnothing $ ) 到 $ \phi $ 的演绎。对具体的公式 $ \phi $ 和公式集 $ \Gamma $ ,对命题 $ \Gamma  \nvdash  \phi $ 的证明往往被称作 “独立性证明”。独立性证明是不可演绎性或不可证明性的证明。 $ {}^{10} $

#### 6.7.2 公理的独立性、有穷数值解释和一般解释结构

对每个公理系统 $ \mathbf{S} $ ,我们用 $ \mathcal{A}\left( \mathbf{S}\right) $ 表示 $ \mathbf{S} $ 所有公理的集合。

定义 344 设 $ \mathbf{S} $ 为任意公理系统,并设 $ \phi  \in  \mathcal{A}\left( \mathbf{S}\right) $ 。我们用 $ {\mathbf{S}}^{-\phi } $ 表示从 $ \mathcal{A}\left( \mathbf{S}\right) $ 中剔除 $ \phi $ 而得到的公理系统,亦即 $ \mathcal{A}\left( {\mathbf{S}}^{-\phi }\right)  = \mathcal{A}\left( \mathbf{S}\right)  - \{ \phi \} ,{\mathbf{S}}^{-\phi } $ 的推演规则与 $ \mathbf{S} $ 相同,而 $ {\mathbf{S}}^{-\phi } $ 中的演绎和证明也与 $ \mathbf{S} $ 中的定义相同,只是公理仅限于 $ \mathcal{A}\left( \mathbf{S}\right)  - \{ \phi \} $ 中公式。

定义 345 设 $ \mathbf{S} $ 为任意公理系统,并设 $ \phi $ 为 $ \mathbf{S} $ 的任意公理。 $ \phi $ 独立于 $ \mathbf{S} $ 的其他公理 (独立于 $ \mathcal{A}\left( S\right)  - \{ \phi \} $ ) 当且仅当 $ \phi $ 在 $ {\mathbf{S}}^{-\phi } $ 中不可证。

定义 346 设 $ \mathbf{S} $ 是任意公理系统。 $ \mathcal{A}\left( \mathbf{S}\right) $ 是独立的 (或 $ \mathbf{S} $ 的公理都是独立的) 当且仅当对每个 $ \phi  \in  \mathcal{A}\left( \mathbf{S}\right) ,\phi $ 独立于 $ \mathbf{S} $ 的其他公理 (独立于 $ \mathcal{A}\left( \mathbf{S}\right)  - \{ \phi \} $ )。

通常,当人们说一公理系统 $ \mathbf{S} $ 的某一条公理 $ \phi $ (不) 是独立的,意思是说, $ \phi $ (不) 是独立于 $ \mathbf{S} $ 的其他公理的。当人们说某公式从 $ \mathbf{S} $ 中 $ \phi $ 以外的公理 (不) 可证,意思是说它在 $ {\mathbf{S}}^{-\phi } $ 中 (不) 可证。 $ {}^{11} $

公理的独立性, 虽说只是不可演绎性或不可证明性的一种形式, 但它有特殊的意义。人们希望一个公理系统的公理都是独立的, 直观地说就是希望作为证明出发点的公理缺一不可。当然, 公理的独立性问题不仅仅是逻辑公理的独立性问题。当我们考察非逻辑公理时, 独立性研究往往带来对具体学科理论研究的突破, 带来对这些学科理论的更深的理解。欧式几何第五公设、选择公理和连续统假设等的独立性就是几个著名的例子。

在这种思路引领下的独立性证明中,如果公理系统 $ \mathbf{S} $ 有代入规则,那么我们需要这个规则保存所谓 $ \mathfrak{T} - Y $ -重言性。我们先把 $ {\mathcal{L}}_{{ \odot  }_{0},\ldots ,{ \odot  }_{m}} $ -公式的代入讲清楚。类似于 $ §{3.5.2} $ 中的定义,代入是从命题变号集合到 $ {\mathcal{L}}_{{ \odot  }_{0},\ldots ,{ \odot  }_{m}} $ -公式集合的函数,对每个这样的函数 $ \mathfrak{s} $ ,对 $ {\mathcal{L}}_{{ \odot  }_{0},\ldots ,{ \odot  }_{m}} $ -公式 $ \phi $ 做代入 $ \mathfrak{s} $ 的结果 $ \phi \left( \mathfrak{s}\right) $ 递归地定义如下 (其中 $ p $ 是任意命题变号, $ \odot $ 是 $ {\mathcal{L}}_{{ \odot  }_{0},\ldots ,{ \odot  }_{m}} $ 中任意的 $ k $ 元联结词, $ {\psi }_{1},\ldots ,{\psi }_{k} $ 是任意 $ {\mathcal{L}}_{{ \odot  }_{0},\ldots ,{ \odot  }_{m}} $ -公式):

\[
p\left( \mathfrak{s}\right)  = \mathfrak{s}\left( p\right)
\]

\[
\left( {\odot \left( {{\psi }_{1},\ldots ,{\psi }_{k}}\right) }\right) \left( \mathfrak{s}\right)  =  \odot  \left( {{\psi }_{1}\left( \mathfrak{s}\right) ,\ldots ,{\psi }_{k}\left( \mathfrak{s}\right) }\right)  \tag{6.3}
\]

我们继续使用 $ {\psi }_{0}/{q}_{0},\ldots ,{\psi }_{n}/{q}_{n} $ 的记法表示下述有穷代入 $ \mathfrak{s} $ :

\[
\mathfrak{s}\left( p\right)  = \left\{  \begin{array}{ll} {\psi }_{i} & \text{ 如果 }p = {q}_{i}\left( {i \leq  n}\right) \\  p & \text{ 如果 }p \neq  {q}_{0},\ldots ,{q}_{n} \end{array}\right.
\]

下面两个命题的证明思路与定理 90 和定理 320 的证明思路完全一样。 我们把命题 347 的证明留作习题 (见习题 6.29)。

命题 347 设 $ \mathfrak{T} = \left\langle  {X,{g}_{{ \odot  }_{0}},\ldots ,{g}_{{ \odot  }_{m}}}\right\rangle $ 为 $ {\mathcal{L}}_{{ \odot  }_{0},\ldots ,{ \odot  }_{m}} $ 的任意解释结构,并设 $ \mu $ 和 $ \nu $ 为 $ \mathfrak{T} $ 上的任意解释,满足 $ {\psi }_{0}^{\mu } = \nu \left( {q}_{0}\right) ,\ldots ,{\psi }_{n}^{\mu } = \nu \left( {q}_{n}\right) $ 。对所有 $ {\mathcal{L}}_{{ \odot  }_{0},\ldots ,{ \odot  }_{m}} $ -公式 $ \phi $ ,如果 $ \phi $ 中出现的命题变号都在 $ {q}_{0},\ldots ,{q}_{n} $ 之中,并且如果 $ \mathfrak{s}\left( {q}_{0}\right)  = {\psi }_{0},\ldots ,\mathfrak{s}\left( {q}_{n}\right)  = {\psi }_{n} $ ,那么 $ {\left( \phi \left( \mathfrak{s}\right) \right) }^{\mu } = {\phi }^{\nu } $ 。

下述定理是个很有普遍性的命题 ——定理 320 只是它的非常特殊的情况。这个命题说的是: 对 $ {\mathcal{L}}_{{ \odot  }_{0},\ldots ,{ \odot  }_{m}} $ 的任何解释结构 $ \mathfrak{T} = \left\langle  {X,{g}_{{ \odot  }_{0}},\ldots ,{g}_{{ \odot  }_{m}}}\right\rangle $ 以及 $ X $ 的任何子集 $ Y $ ,代入规则都保存 $ \mathfrak{T} - Y $ -重言性。

定理 348 设 $ \mathfrak{T} = \langle X,{g}_{{ \odot  }_{0}},...,{g}_{{ \odot  }_{m}}\rangle $ 为 $ {\mathcal{L}}_{{ \odot  }_{0},...,{ \odot  }_{m}} $ 的任意解释结构,并设 $ \varnothing  \neq  Y \subseteq  X $ 。对每个 $ {\mathcal{L}}_{{ \odot  }_{0},\ldots ,{ \odot  }_{m}} $ -公式 $ \phi $ 和每个代入 $ \mathfrak{s}, $ 如果 $ \phi $ 是 $ \mathfrak{T} $ -Y-重言式,那么 $ \phi \left( \mathfrak{s}\right) $ 也是 $ \mathfrak{T} $ -重言式。

证明 假设存在某个代入 $ \mathfrak{s} $ 使得 $ \phi \left( \mathfrak{s}\right) $ 不是 $ \mathfrak{T} - Y $ -重言式,亦即有 $ \mathfrak{T} $ 上的解释 $ \mu $ 使得 $ {\left( \phi \left( \mathfrak{s}\right) \right) }^{\mu } \notin  Y $ 。设 $ \phi $ 中出现的命题变号为 $ {q}_{0},\ldots ,{q}_{k} $ ,并令 $ \nu $ 为 $ \mathfrak{T} $ 上的任意解释,满足对每个 $ i \leq  k,\nu \left( {q}_{i}\right)  = {\left( \mathfrak{s}\left( {q}_{i}\right) \right) }^{\mu } $ 。根据命题 347,我们知道 $ {\phi }^{\nu } = {\left( \phi \left( \mathfrak{s}\right) \right) }^{\mu } $ ,从而 $ {\phi }^{\nu } \notin  Y $ ,亦即 $ \phi $ 不是 $ \mathfrak{T} - Y $ -重言式。

除了上述解释结构的方法, 独立性证明还有其他方法, 这里不可能一一介绍。读者在以后的学习过程中可以多加留意。
