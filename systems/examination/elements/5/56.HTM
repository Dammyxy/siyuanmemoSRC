根据独立性定义: 由 I(A, B) 和独立性定义，我们可以推导出 P(A|B) = P(A) ∧ P(B|A) = P(B) ∧ P(A) > 0 ∧ P(B) >0. 这里使用的是 modus ponens（肯定前件）推理规则：

  •  解释:
    •  我们知道独立性的定义是: I(A, B) ↔ (P(A|B) = P(A) ∧ P(B|A) = P(B) ∧ P(A) > 0 ∧ P(B) >0) (这是我们之前定义的) 
    •  我们又假设了 I(A, B) 是真的。 
    •  “肯定前件”规则说的是：如果 X → Y 是真的，并且 X 是真的，那么 Y 一定是真的。   把 I(A, B) 看作 X，把 (P(A|B) = P(A) ∧ P(B|A) = P(B) ∧ P(A) > 0 ∧ P(B) >0) 看作 Y。 因为 I(A, B) ↔ (P(A|B) = P(A) ∧ P(B|A) = P(B) ∧ P(A) > 0 ∧ P(B) >0) 为真(根据定义)，且I(A,B)为真，那么我们可以推出 P(A|B) = P(A) ∧ P(B|A) = P(B) ∧ P(A) > 0 ∧ P(B) >0 为真。
