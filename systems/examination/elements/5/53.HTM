证明过程：
1. 换底公式：

logan bn = loga bn
loga an

- 分子部分：loga bn 可以使用对数的幂规则 loga bn = n loga b。 - 分母部分：loga an 可以直接计算，因为 loga an = n（因为 an = an）。
因此，表达式可以简化为：
logan bn = n loga b

分子和分母中的 n 可以约去：
