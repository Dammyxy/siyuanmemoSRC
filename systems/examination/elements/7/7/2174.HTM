2. 对称性 (Symmetric Property of Equality)

  • 定义：如果一个量等于另一个量，那么第二个量也等于第一个量。简单来说，等式的左右两边可以互换位置。
  • 形式化表示：如果 a = b，那么 b = a。
  • 含义：这个性质表明了等价关系是“双向”的。如果你从 A 到 B 的关系是“等于”，那么从 B 到 A 的关系也是“等于”。
  • 应用场景：在代数运算和几何证明中，对称性是经常被隐含或明确使用的。它允许你为了方便或满足后续步骤的需求，翻转等式的两边。例如，如果你解出一个变量的值，通常会把变量放在等号的左边，尽管你最初解出的可能是右边。
  • 举例：
    • 如果 x + 3 = 7，那么 7 = x + 3。
    • 如果 ∡A = ∡B，那么 ∡B = ∡A。
    • 在几何证明中，如果你证明了 AB = CD，那么你也可以直接说 CD = AB。
