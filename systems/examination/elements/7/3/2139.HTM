Recall that profit function P(x) is equal to the revenue function R(x) minus the cost function C(x):
回顾利润函数 P(x) 等于收入函数 R(x) 减去成本函数 C(x):


P(x) = R(x) − C(x)

So, to calculate the profit function, we first need to construct R(x) and C(x).
因此, 要计算利润函数, 我们首先需要构建 R(x) 和 C(x)。

  • We're given the price function p(x), so the revenue function is
    已知价格函数 p(x) , , 故收入函数为

R(x) = (number of units) ⋅ (price per unit)

= x ⋅ p(x)

= x(60 − 0.01x)

= 60x − 0.01x2.
  • We're also given that the fixed costs are $8 800 per month and that each unit costs $25 to make. Therefore, the cost function is
    我们还已知每月固定成本为 $8 800 , 每单位产品的制造成本为 $25。 因此, 成本函数为

C(x) = (fixed cost) + (number of units) ⋅ (cost per unit)

= 8 800 + x ⋅ 25

= 8 800 + 25x.

Finally, we can now calculate the profit function:
最后, 我们现在可以计算利润函数:


P(x) = R(x) − C(x)

= (60x − 0.01x2) − (8 800 + 25x)

= 60x − 0.01x2 − 8 800 − 25x

= −0.01x2 + 35x − 8 800

数学知识点：

  • 利润函数 (Profit Function) P(x)：
    • 定义：表示企业销售 x 单位产品所获得的净利润。
    • 基本公式：P(x) = 收益函数 R(x) − 成本函数 C(x)
  • 收益函数 (Revenue Function) R(x)：
    • 定义：销售 x 单位产品所获得的总收入。
    • 公式：R(x) = (销售单位数量) ⋅ (每单位价格) = x ⋅ p(x)，其中 p(x) 是价格函数。
  • 成本函数 (Cost Function) C(x)：
    • 定义：生产 x 单位产品所需的总成本。
    • 公式：C(x) = 固定成本 + (生产单位数量) ⋅ (每单位可变成本)
  • 价格函数 (Price Function) p(x)：
    • 表示销售 x 单位产品时的每单位价格。此处给定 p(x) = 60 − 0.01x。
  • 固定成本 (Fixed Cost)：
    • 不随生产量变化而变化的成本。此处为 $8800。
  • 每单位可变成本 (Cost Per Unit)：
    • 生产一个单位产品所需的可变成本。此处为 $25。
  • 多项式运算：
    • 涉及多项式的乘法（展开），以及多项式的减法（注意符号变化）。
    • 合并同类项以简化表达式。

解题逻辑和思路：

本例的目的是计算企业的利润函数 P(x)。其核心逻辑是按照利润 = 收入 − 成本的基本关系，分步构建收入函数 R(x) 和成本函数 C(x)，然后进行减法运算。

  1. 明确目标：计算利润函数 P(x)。
  2. 建立利润函数的基本关系：
    • P(x) = R(x) − C(x)。这表明需要先求出 R(x) 和 C(x)。
  3. 构建收益函数 R(x)：
    • 已知价格函数 p(x) = 60 − 0.01x。
    • 收益函数 R(x) = 销售单位数量 ⋅ 每单位价格 = x ⋅ p(x)。
    • 代入 p(x) 得到：R(x) = x(60 − 0.01x) = 60x − 0.01x2。
  4. 构建成本函数 C(x)：
    • 已知固定成本 = $8800。
    • 已知每单位产品的制造成本（可变成本） = $25。
    • 成本函数 C(x) = 固定成本 + 销售单位数量 ⋅ 每单位可变成本。
    • 代入数值得到：C(x) = 8800 + x ⋅ 25 = 8800 + 25x。
  5. 计算利润函数 P(x)：
    • 将已求得的 R(x) 和 C(x) 代入 P(x) = R(x) − C(x)。
    • P(x) = (60x − 0.01x2) − (8800 + 25x)。
    • 执行多项式减法，注意括号前的负号要变号：= 60x − 0.01x2 − 8800 − 25x。
    • 合并同类项，通常按 x 的降幂排列：= −0.01x2 + (60x − 25x) − 8800。
    • 最终结果：P(x) = −0.01x2 + 35x − 8800。

整个过程是一个标准的商业数学建模问题，要求理解并正确运用利润、收入和成本的基本定义及公式，并进行准确的代数运算。
