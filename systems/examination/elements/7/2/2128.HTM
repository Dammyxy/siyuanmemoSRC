解题逻辑和思路 (三角形内角和定理证明思路)：

这个双栏证明展示了证明三角形内角和为 180 度的标准方法之一。思路如下：

  1. 辅助线的作法：通过三角形的一个顶点（这里是 C），作一条平行于对边（AB）的直线（DE）。这是证明的关键辅助线，它利用了平行线的性质。
  2. 利用平行线性质转化内角：
    • 直线 DE || AB，直线 AC 是截线。根据“内错角定理”，∠ACD (在平行线 DE 和 AB 之间，截线 AC 两侧) 与 ∠A (三角形内角) 全等。这意味着它们的度数相等 (m∠ACD = m∠A)。
    • 直线 DE || AB，直线 BC 是截线。根据“内错角定理”，∠BCE (在平行线 DE 和 AB 之间，截线 BC 两侧) 与 ∠B (三角形内角) 全等。这意味着它们的度数相等 (m∠BCE = m∠B)。
  3. 利用平角和角相加公设：顶点 C 处形成的直线 DE 是一个平角，其度数为 180° (m∠DCE = 180°)。根据“角相加公设”，平角 ∠DCE 可以分解为相邻的三个角之和：m∠DCE = m∠ACD + m∠ACB + m∠BCE。
  4. 代入和传递性：
    • 将步骤 2 中得到的等式 (m∠ACD = m∠A 和 m∠BCE = m∠B) 代入步骤 3 的角相加等式中，得到 m∠A + m∠ACB + m∠BCE = m∠DCE。
    • 再将 m∠BCE = m∠B 代入上式，得到 m∠A + m∠ACB + m∠B = m∠DCE。
    • 结合 m∠DCE = 180° (步骤 8) 和 m∠A + m∠ACB + m∠B = m∠DCE (步骤 7)，根据等式的传递性（如果 a = b 且 b = c，则 a = c），可以得出 m∠A + m∠ACB + m∠B = 180°。
  5. 结论：m∠A, m∠ACB, m∠B 正好是三角形 ABC 的三个内角的度数。因此，这三个内角的和等于 180 度，证明了三角形内角和定理。

双栏证明的格式要求每一行包含一个陈述和一个对应的理由，理由必须是已知条件、定义、公设或先前已证明的定理。
