EXPLANATION 解释

数学知识点：

  • 三角形内角和定理 (Triangle Angle Sum Theorem)
  • 平角 (Straight Angle)
  • 角相加公设 (Angle Addition Postulate)
  • 等式的性质 (Properties of Equality):
    • 对称性 (Symmetric property): 如果 a = b，则 b = a。
    • 传递性 (Transitive property): 如果 a = b 且 b = c，则 a = c。
  • 替代 (Substitution)
  • 共线点 (Collinear points)
  • 外角定理 (Exterior Angle Theorem) - 虽然证明过程没有直接引用此定理名称，但最终证明的结论 (m∠YHZ = m∠X + m∠HZX) 是三角形 ΔHZX 的外角定理的表述 (三角形的外角等于不相邻的两个内角之和)。

解题逻辑和思路 (证明 m∠YHZ = m∠X + m∠HZX 的思路)：

这个双栏证明过程旨在证明结论 m∠YHZ = m∠X + m∠HZX。通过分析证明步骤，我们可以看出其主要思路是利用三角形内角和定理和共线点形成的平角性质。

  1. 步骤 1 和 2：分别对三角形 ΔYHZ 和三角形 ΔXZY 应用三角形内角和定理，得出它们各自内角和等于 180° 的等式。
    • ΔYHZ 的内角是 ∠Y, ∠YHZ, ∠HZY。所以 m∠Y + m∠YHZ + m∠HZY = 180°。
    • ΔXZY 的内角是 ∠X, ∠Y, ∠XZY。所以 m∠X + m∠Y + m∠XZY = 180°。
  2. 步骤 3 和 4：利用等式的对称性和传递性，将步骤 1 和 2 的两个等式连接起来。由于两者都等于 180°，根据传递性，m∠Y + m∠YHZ + m∠HZY = m∠X + m∠Y + m∠XZY。
  3. 步骤 5：观察步骤 4 的等式，两边都有 m∠Y。根据等式的性质，可以在两边同时减去 m∠Y (或应用加法原理，加上 -m∠Y)，从而消去 m∠Y，得到 m∠YHZ + m∠HZY = m∠X + m∠XZY。
  4. 步骤 6：观察图示，∠XZY 是由 ∠HZY 和 ∠HZX 两个相邻的角组成的（点 H 在 ∠XZY 的内部）。根据“角相加公设”，∠XZY 的度数等于 ∠HZY 和 ∠HZX 的度数之和：m∠XZY = m∠HZY + m∠HZX。
  5. 步骤 7：将步骤 6 的等式 (m∠XZY = m∠HZY + m∠HZX) 代入步骤 5 的等式的右侧的 m∠XZY 中。这被称为“替代” (Substitution)。代入后得到 m∠YHZ + m∠HZY = m∠X + (m∠HZY + m∠HZX)。
  6. 步骤 8：观察步骤 7 的等式，两边都有 m∠HZY。根据等式的性质，可以在两边同时减去 m∠HZY (或应用加法原理，加上 -m∠HZY)，从而消去 m∠HZY，得到 m∠YHZ = m∠X + m∠HZX。这正是需要证明的结论。

这个证明过程实际上是证明了三角形 ΔHZX 的外角 ∠YHZ 等于其不相邻的两个内角 ∠X 和 ∠HZX 的度数之和，即外角定理。
