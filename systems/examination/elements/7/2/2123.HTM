Which of the following is a root of the polynomial x3 + 2x2 − x − 2?
以下哪项是多项式 x3 + 2x2 − x − 2? 的根？

I. x = −2
II. x = −1
III. x = 0

数学知识点：

  • 多项式 (Polynomial)
  • 根 (Root) / 零点 (Zero)
  • 多项式的求值 (Evaluating a polynomial)

解题逻辑和思路：

求解多项式的根（或零点）意味着找到使得多项式的值等于零的 x 的值。判断给定的值是否是多项式的根，最直接的方法是将给定的 x 值代入多项式，然后计算其值。如果计算结果为零，则该值是多项式的根；否则，不是。

题目给出了多项式 P(x) = x³ + 2x² - x - 2，以及三个待检验的 x 值：-2, -1, 0。我们需要逐一代入检验。

  1. 检验 x = -2：
    将 x = -2 代入多项式 P(x)：
    P(-2) = (-2)³ + 2(-2)² - (-2) - 2
    P(-2) = -8 + 2(4) + 2 - 2
    P(-2) = -8 + 8 + 2 - 2
    P(-2) = 0
    由于 P(-2) = 0，所以 x = -2 是多项式的根。
  2. 检验 x = -1：
    将 x = -1 代入多项式 P(x)：
    P(-1) = (-1)³ + 2(-1)² - (-1) - 2
    P(-1) = -1 + 2(1) + 1 - 2
    P(-1) = -1 + 2 + 1 - 2
    P(-1) = 0
    由于 P(-1) = 0，所以 x = -1 是多项式的根。
  3. 检验 x = 0：
    将 x = 0 代入多项式 P(x)：
    P(0) = (0)³ + 2(0)² - (0) - 2
    P(0) = 0 + 0 - 0 - 2
    P(0) = -2
    由于 P(0) ≠ 0，所以 x = 0 不是多项式的根。

根据检验结果，选项 I (x = -2) 和选项 II (x = -1) 都是该多项式的根。题目应该是多选题或需要根据选项格式作答（例如，如果选项是组合项，如“只有 I 和 II”）。仅凭截图无法确定完整的选项。
