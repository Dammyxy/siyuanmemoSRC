Solving a Quadratic Equation With Complex Roots by Completing the Square
Title: 通过配方法求解具有复数根的二次方程

We can also solve a quadratic equation with complex solutions using the square root method.
我们也可以使用平方根法来求解具有复数解的二次方程。

To demonstrate, let's find the solutions of the equation (x − 2)2 = −16.
为了演示，让我们求解方程 (x − 2)2 = −16.

The left-hand side is a perfect square. Therefore, we can solve the equation as follows:
左侧是一个完全平方。因此，我们可以按如下方式解这个方程:


(x − 2)2 = −16

x − 2 = ±
√
 
−16
 

x − 2 = ±4i

x = 2 ± 4i

Sometimes, we need to complete the square first before applying the square root method. Let's see how.
有时，我们需要先完成平方，然后再应用平方根法。让我们看看具体怎么做。

数学知识点：

  • 二次方程 (Quadratic equation)
  • 复数根 (Complex roots)
  • 配方法 (Completing the square)
  • 平方根法 (Square root method)
  • 虚数单位 i (Imaginary unit i, where i2 = −1)
  • 负数的平方根 (Square root of negative numbers)

解题逻辑和思路：

这部分内容介绍了如何使用平方根法来求解已经化为完全平方形式且右侧为负数的二次方程，从而得到复数解。核心思路是：

  1. 识别方程形式：注意到方程 (x - 2)² = -16 的左侧已经是完全平方形式 (ax + b)² 或 (x - c)²，而右侧是一个负数。
  2. 应用平方根法：对于形式为 u² = d 的方程，其解为 u = ±√d。当 d 是负数时，√d 会涉及虚数。
  3. 计算负数的平方根：根据虚数的定义，√-a = i√a (其中 a > 0)。因此，√-16 = √(-1 * 16) = √-1 * √16 = i * 4 = 4i。
  4. 求解 x：将平方根计算结果代回方程 x - 2 = ±√-16 中，得到 x - 2 = ±4i。
  5. 隔离 x：将常数项移到等号右侧，得到 x = 2 ± 4i。这表示方程有两个复数解：x₁ = 2 + 4i 和 x₂ = 2 - 4i。

这部分还引出了下一部分内容，即当方程不是现成的完全平方形式时，需要先使用“配方法”将其转化为完全平方形式，再应用平方根法求解。
