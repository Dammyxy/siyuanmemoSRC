1. 两个集合的情况 (A ∪ B)

你记得两个集合不需要加，是对的。公式是： |A ∪ B| = |A| + |B| - |A ∩ B|

为什么是减法？

  •  第一步 (加): 我们先把 A 和 B 的元素个数都加起来 |A| + |B|。
  •  问题: 这样做的话，两个集合重叠的部分 (A ∩ B) 被计算了两次（一次在 |A| 里，一次在 |B| 里）。
  •  修正: 为了得到正确的结果，我们必须把多算的一次减掉。所以要 - |A ∩ B|。 

（A+B 会把中间的红色部分算两遍，所以要减掉一次）

2. 三个集合的情况 (T ∪ C ∪ F)

现在来看你图片里的公式： |T ∪ C ∪ F| = |T|+|C|+|F| - |T∩C| - |T∩F| - |C∩F| + |T∩C∩F|

为什么最后是加法？ 我们一步一步来看元素的计数过程：

  •  

    第一步 (加单项): |T| + |C| + |F|

    •  只属于一个集合的元素，被计算了 1 次。 (正确)
    •  同时属于两个集合的元素 (例如 T 和 C，但不在 F)，被计算了 2 次。 (多算了)
    •  同时属于三个集合的元素 (T ∩ C ∩ F)，被计算了 3 次。 (多算了) 
  •  

    第二步 (减两两相交): - |T∩C| - |T∩F| - |C∩F|

    •  现在我们来修正。
    •  对于“同时属于两个集合”的元素：它们在第一步被加了 2 次，现在被减了 1 次，所以总共被计算了 2 - 1 = 1 次。 (正确了)
    •  关键来了！ 对于“同时属于三个集合”的元素：
      •  它们在第一步被加了 3 次 (因为 T, C, F 都包含它)。
      •  它们在第二步被减了 3 次 (因为 T∩C, T∩F, C∩F 也都包含它)。
      •  所以，到目前为止，这部分元素被计算的次数是 3 - 3 = 0 次！它们被完全“排除”掉了。 
       
  •  

    第三步 (加三者相交): + |T∩C∩F|

    •  由于最核心的、三个集合共同拥有的元素在第二步被我们错误地完全减掉了，我们必须把它们加回来。
    •  所以最后要 + |T∩C∩F|，以确保这部分元素被计算了 1 次。 

  •  

总结 

Title: 容斥原理的逻辑就是：

  1.  先全加上 (Inclusion)：把所有单个的都加起来。
  2.  再减去重叠的 (Exclusion)：发现加多了，就把两两重叠的部分减掉。
  3.  再加回被多减的 (Inclusion)：发现因为第二步，把三个（或更多）重叠的部分减过头了，再把它们加回来。 

这个模式会一直持续下去，符号是“加-减-加-减...”交替出现的。

  •  两个集合: 加单项 - 减交集
  •  三个集合: 加单项 - 减两两交集 + 加三者交集
  •  四个集合: 加单项 - 减两两交集 + 加三三交集 - 减四者交集
