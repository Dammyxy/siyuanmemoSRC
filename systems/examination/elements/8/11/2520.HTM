第一步：推导最简单的年复利公式

假设你有一个初始本金 P，年利率为 r，我们来看看每年年底你的钱会变成多少。

  • 初始状态：

    • 本金 = P

  • 第一年结束时：

    • 你获得的利息是：P * r
    • 你的总金额 (A₁) = 本金 + 利息 = P + P * r
    • 为了方便后续计算，我们把 P 提取出来：A₁ = P * (1 + r)
    • 这个 A₁ 就是你第二年的“新本金”。

  • 第二年结束时：

    • 现在，我们是在 A₁ 的基础上计算利息。
    • 你这一年获得的利息是：A₁ * r
    • 你的总金额 (A₂) = 第二年初的本金 + 新利息 = A₁ + A₁ * r
    • 同样，提取 A₁：A₂ = A₁ * (1 + r)
    • 现在，把第一年算出的 A₁ = P * (1 + r) 代入进来：
    • A₂ = [P * (1 + r)] * (1 + r)
    • 整理一下，就得到：A₂ = P * (1 + r)²

  • 第三年结束时：

    • 你的“新本金”是 A₂。
    • 总金额 (A₃) = A₂ * (1 + r)
    • 把 A₂ = P * (1 + r)² 代入：
    • A₃ = [P * (1 + r)²] * (1 + r)
    • 整理得到：A₃ = P * (1 + r)³
