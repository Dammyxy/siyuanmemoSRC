翻译原文：

证明内角和定理

我们希望证明以下陈述：

∆ABC 的内角和等于 180°。

解锁这个证明的关键是构造一条平行于 ―AB 且通过点 C 的直线，然后两次应用内错角定理。

现在我们将逐步进行这个陈述的证明。

  • 步骤 1：我们首先构造一条直线 ―→DE，它通过点 C 并且平行于 ―AB。

  • 步骤 2：由于 ―AB 和 ―→DE 平行，∡ACD 和 ∡A 根据内错角定理全等。

  • 步骤 3：由于 ∡ACD ≅ ∡A，我们有

    m∡ACD = m∡A

    根据全等角的定义。

  • 步骤 4：由于 ―AB 和 ―→DE 平行，∡BCE 和 ∡B 根据内错角定理全等。

  • 步骤 5：由于 ∡BCE ≅ ∡B，我们有

    m∡BCE = m∡B

    根据全等角的定义。

  • 步骤 6：线段 ―AC 和 ―BC 将平角 ∡DCE 分成三个连续的角：∡ACD、∡ACB 和 ∡BCE。因此，根据角的加法公设，我们必须有

    m∡ACD + m∡ACB + m∡BCE = m∡DCE。

  • 步骤 7：在步骤 3 和 5 中，我们证明了 m∡ACD = m∡A 和 m∡BCE = m∡B。因此，通过将这些值代入步骤 6 的等式，我们得到

    m∡A + m∡ACB + m∡B = m∡DCE。

  • 步骤 8：由于 ―→DE 是一条直线，根据平角的定义，m∡DCE = 180°。
  • 步骤 9：在步骤 8 中，我们证明了 m∡DCE = 180°，在步骤 7 中，我们证明了

    m∡A + m∡ACB + m∡B = m∡DCE。

    因此，根据等量的传递性，我们有

    m∡A + m∡ACB + m∡B = 180°，

    即证。

数学知识点：

这个证明的核心在于利用平行线的性质（特别是内错角定理）和平角的定义来推导三角形的内角和。

  • 三角形内角和定理 (Triangle Sum Theorem)：任何三角形的三个内角的度数之和都等于 180°。
  • 内角 (Interior Angles)：三角形内部的角。
  • 辅助线 (Auxiliary Line / Construction)：在几何证明中为了帮助推导而额外添加的线段或直线。这里的辅助线是平行于三角形一边的直线。
  • 平行线 (Parallel Lines)：永不相交的两条直线。
  • 截线 (Transversal)：与两条或多条直线相交的直线。
  • 内错角 (Alternate Interior Angles)：当两条平行线被截线截时，位于两条平行线之间（内部），且在截线两侧的角。如果平行线被截，则内错角全等。
    • 本证明中，∡ACD 和 ∡A 是内错角。
    • ∡BCE 和 ∡B 是内错角。
  • 全等角 (Congruent Angles)：度数相等的角。
  • 平角 (Straight Angle)：度数为 180° 的角。一条直线可以看作一个平角。
  • 角的加法公设 (Angle Addition Postulate)：如果一个角被射线分成几个小角，那么这些小角的度数之和等于大角的度数。这里，平角 ∡DCE 被 ∡ACB 和 ∡BCE 分割。
  • 等量替换 (Substitution Property of Equality)：在代数或几何中，如果 A = B，那么在任何表达式中，A 都可以被 B 替换而不改变表达式的值。
  • 传递性 (Transitive Property of Equality)：如果 A = B 且 B = C，那么 A = C。

解题逻辑和思路：

这个证明的思路非常经典和巧妙，它通过构造辅助线将三角形的内角“转移”到一条直线上，从而利用平角的性质来证明内角和。

  1. 目标明确：证明 ∆ABC 的三个内角 (m∡A, m∡B, m∡ACB) 之和为 180°。
  2. 关键辅助线构造：
    • 在顶点 C 处，构造一条直线 ―→DE，使其通过 C 点且平行于 ∆ABC 的底边 ―AB。这是整个证明的基石。
  3. 利用平行线性质转移角度：
    • 将直线 ―AC 视为截线，因为它截平行线 ―AB 和 ―→DE。根据内错角定理，∡ACD (在辅助线上方) 和 ∡A (三角形左下角) 全等，即 m∡ACD = m∡A。
    • 同理，将直线 ―BC 视为截线。根据内错角定理，∡BCE (在辅助线右方) 和 ∡B (三角形右下角) 全等，即 m∡BCE = m∡B。
  4. 利用平角的定义和角的加法公设：
    • 由于 ―→DE 是一条直线，所以 ∡DCE 是一个平角，其度数为 180° (m∡DCE = 180°)。
    • 观察到 ∡DCE 实际上由三个相邻的角组成：∡ACD、∡ACB (三角形顶点 C 的内角) 和 ∡BCE。根据角的加法公设，这三个角的度数之和等于平角的度数：m∡ACD + m∡ACB + m∡BCE = m∡DCE。
  5. 代入与整合：
    • 将步骤 3 中得到的等量关系 (m∡ACD = m∡A 和 m∡BCE = m∡B) 代入步骤 4 的等式中。

      m∡A + m∡ACB + m∡B = m∡DCE

    • 再将平角的度数 (m∡DCE = 180°) 代入上式。

      m∡A + m∡ACB + m∡B = 180°

  6. 得出结论：最终的等式 (m∡A + m∡ACB + m∡B = 180°) 正是三角形内角和定理的陈述，从而完成了证明。

这个证明的“优美”之处在于它将一个看似复杂的图形性质（三角形内角和）巧妙地转化为一个简单的直线上的角度关系（平角），通过引入一条辅助线和两次应用一个基本定理（内错角定理）实现了完美的逻辑连接。
