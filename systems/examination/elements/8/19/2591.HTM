数学知识点

  1. Title: 抛物线标准方程 (Standard Equation of a Parabola):

    • 开口向上/下 (Vertical): (x − h)² = 4p(y − k)
    • 开口向左/右 (Horizontal): (y − k)² = 4p(x − h) 本题是开口向下，所以选用第一种形式。

  2. 顶点 (Vertex): 抛物线的转折点，坐标为 (h, k)。它是确定抛物线位置的关键。

  3. 参数 p 的意义:

    • p 是从[...] 的有向距离。
    • p 的符号决定了开口方向：
      • 对于 (x − h)² 形式：p > 0 开口向上，p < 0 开口向下。
      • 对于 (y − k)² 形式：p > 0 开口向右，p < 0 开口向左。
    • p 的绝对值 |p| 决定了开口的“宽窄”：|p| 越大，开口越宽。

  4. 代入法求解未知数: 当方程中只有一个未知数时（如此处的 p），可以通过代入一个已知满足方程的点 (x, y) 来求解。
