### 3.1 对象语言里的符号和公式

逻辑学家们常喜欢不把对象语言明明白白地写下来, 而只是用我们熟悉的语言来描述它们。在 $ §{2.4.1} $ 中介绍 $ {\mathcal{L}}_{0} $ -符号时,我们说 $ {\mathcal{L}}_{0} $ -符号有命题变号 $ {p}_{0},{p}_{1},\ldots $ 和联结词 $ \sim  , \vee  , \land  , \rightarrow  , \leftrightarrow $ 等。这并不等于说,对象语言里的命题变号看上去都是某种字体的英文字母表中第 16 个字母的小写形式, 而且还有自然数下标。对象语言的命题变号到底什么样不是我们关心的问题, 而这个语言中是否有表达自然数的符号更不是我们关心的问题一一我们只是用我们的语言符号来表示那些命题变号, 只是在我们的语言中把它们排成这样一个序列。类似地,对象语言中的否定号是否看上去像是 $ \mathrm{S} $ 的镜像转了 90°,蕴涵号是否像是指向右边的箭头,等等,都不是我们关心的问题。我们只是用 $ \sim $ 和 $ \rightarrow $ 等分别表示它们。

虽然我们熟悉的语言都有文字符号, 但毕竟不是所有的语言都一定要有文字符号。我们至少可以想像: 在某个遥远的与世隔绝的地方, 生活着一个非常原始的部落, 这个部落的人们还没有发明文字语言, 他们之间的交流只是通过口头语言、动作和表情等进行。如果我们要学习、谈论或研究他们的语言, 那么我们就是把他们的语言当作对象语言, 因而自然地不能强求对象语言必须有文字符号。明白了这一点, 即使我们使用的所有符号都是元语言符号也没有什么难以理解的。

我们把 $ {\mathcal{L}}_{0} $ 的所有命题变号的集合记作 $ \Pr $ ,并把命题变号依下标排出的序 $ {p}_{0},{p}_{1},{p}_{2},\ldots $ 称为 $ \mathbf{{Pr}} $ 上的 (或命题变号的) “字典顺序” 或 “字母表”。

### 3.2 真值指派和公式的真值

语言 $ {\mathcal{L}}_{0} $ 的解释叫做 “真值指派” (truth valuation, truth assignment)。

定义 44 一个真值指派 (或赋值) 是从 Pr 到 $ \{ \mathrm{T},\mathrm{F}\} $ 的函数 $ \sigma $ ,它对每个命题变号 $ p $ 指派一个真值 $ \sigma \left( p\right) $ 。

定义 45 (真理定义) 对所有的 $ {\mathcal{L}}_{0} $ -公式 $ \phi $ ,我们用 $ {\phi }^{\sigma } $ 表示 $ \underline{\phi } $ 在 $ \sigma $ 下的值。 $ {\phi }^{\sigma } $ 递归地定义如下 (我们用 “iff” 表示 “当且仅当” ):

\[
{p}_{n}^{\sigma } = \mathrm{T}\text{ iff }\sigma \left( {p}_{n}\right)  = \mathrm{T}\left( {n \geq  0}\right)
\]

\[
{\left(  \sim  \psi \right) }^{\sigma } = \mathrm{T}\text{iff}{\psi }^{\sigma } \neq  \mathrm{T}\text{(即}{\psi }^{\sigma } = \mathrm{F}\text{)}
\]

\[
{\left( \psi  \vee  \chi \right) }^{\sigma } = \mathrm{T}\text{iff 或者}{\psi }^{\sigma } = \mathrm{T}\text{或者}{\chi }^{\sigma } = \mathrm{T}
\]

\[
{\left( \psi  \land  \chi \right) }^{\sigma } = \mathrm{T}\text{iff}{\psi }^{\sigma } = \mathrm{T}\text{并且}{\chi }^{\sigma } = \mathrm{T}
\]

\[
{\left( \psi  \rightarrow  \chi \right) }^{\sigma } = \mathrm{T}\text{iff 或者}{\psi }^{\sigma } \neq  \mathrm{T}\text{或者}{\chi }^{\sigma } = \mathrm{T}
\]

\[
{\left( \psi  \leftrightarrow  \chi \right) }^{\sigma } = \mathrm{T}\text{ iff }{\psi }^{\sigma } = {\chi }^{\sigma }
\]

确定公式真值的这类定义通常被称作 “真理定义” (truth definition)。对上述真理定义, 我们有几点说明:

$ {\mu }_{0} $ 关于 $ {\phi }^{\sigma } $ 的另一种等价的说法是把真值指派 $ \sigma $ 扩充成一个满足上述条件的从 $ {\mathcal{L}}_{0} $ -公式集到 $ \{ \mathrm{T},\mathrm{F}\} $ 的函数。

4 由于真值指派就像是被指派为真的命题变号集合的特征函数, $ {}^{1} $ 人们常常把真值指派 $ \sigma $ 直接定义为 $ \Pr $ 的一个子集,亦即 $ \sigma  \subseteq  \Pr $ (或者 $ \sigma  \in  \mathcal{P}\left( \mathbf{{Pr}}\right) {)}^{2} $ ,而把 $ {\phi }^{\sigma } $ 递归定义的第一行也相应地改为 “ $ {p}_{n}^{\sigma } = $ T iff $ {p}_{n} \in  \sigma {\left( n \geq  0\right) }^{n} $ 。

---

$ {}^{1} $ 对任意集合 $ X $ 及其任意子集 $ Y $ ,从 $ X $ 到 $ \{ 0,1\} $ 的函数 $ f $ 是 $ Y $ 的特征函数当且仅当对每个 $ x \in  X $ , 如果 $ x \in  Y $ 则 $ f\left( x\right)  = 1 $ ,并且如果 $ x \notin  Y $ 则 $ f\left( x\right)  = 0 $ 。很多作者喜欢用 1 代替真值 $ \mathrm{T} $ 并且用 0 代替真值 $ \mathrm{F} $ 。在这种情况下,真值指派就成了真命题变号集合的特征函数。

$ {}^{2} $ 对任意集合 $ X,\mathcal{P}\left( X\right) $ 表示 $ X $ 的幂集,即包含 $ X $ 的所有子集的集合 $ \{ Y : Y \subseteq  X\} $ 。

---

4 很多作者喜欢用 “如果 $ {\psi }^{\sigma } = \mathrm{T} $ 那么 $ {\chi }^{\sigma } = {\mathrm{T}}^{n} $ 来替代上述递归定义第五行中的 “或者 $ {\psi }^{\sigma } \neq  \mathrm{T} $ 或者 $ {\chi }^{\sigma } = {\mathrm{T}}^{n} $ 。

对照基本真值表 (2.10) 和定义 45 中第二至第六行, 易见两者在真值计算方面表达的内容是一样的。定义 45 确定了一个真值指派下各个公式的值, 而下述 “满足” 定义说的是一个真值指派满足一个公式集当且仅当它使该集合中所有公式的值为真。

定义 46 令 Γ 为任意 $ {\mathcal{L}}_{0} $ -公式集 (可以是无穷集),并令 $ \sigma $ 为任意真值指派。 $ \sigma $ 满足 $ \Gamma $ (符号表示: $ \sigma  \vDash  \Gamma $ ) $ {}^{3} $ 当且仅当对每个 $ \phi  \in  \Gamma ,{\phi }^{\sigma } = $ T。我们用 $ \sigma  \vDash  \phi $ 表示 $ \sigma  \vDash  \{ \phi \} $ ,并用 $ \sigma  \nvDash  \Gamma $ 和 $ \sigma  \nvDash  \phi $ 分别表示 $ \sigma  \vDash  \Gamma $ 和 $ \sigma  \vDash  \phi $ 不成立。

由上述定义可知下列等值式成立:

4 $ \sigma  \vDash  \phi $ 当且仅当 $ {\phi }^{\sigma } = \mathrm{T} $ ;

凸 $ \sigma  \mathrel{\text{\vDash \not{} }} \phi $ 当且仅当 $ {\phi }^{\sigma } = \mathrm{F} $ ；

$ {\mu }_{0} \in  \Gamma $ 当且仅当对所有 $ \phi  \in  \Gamma ,\sigma  \vDash  \phi $ ;

4 b $ \sigma  \mathrel{\text{\vDash \not{} }} \Gamma $ 当且仅当对某些 $ \phi  \in  \Gamma ,\sigma  \mathrel{\text{\vDash \not{} }} \phi $ 。

插议: 当 $ \Gamma  = \varnothing $ (空集) 时, $ \Gamma $ 是否被一真值指派满足是一种“极限”情况。事实上,对每个真值指派 $ \sigma $ ,都有 $ \sigma  \vDash  \varnothing $ 。这是因为,既然 $ \varnothing $ 是空集,那么就不存在 $ \varnothing $ 中的公式 $ \phi $ 使得 $ \sigma  \mathrel{\text{\vDash \not{} }} \phi $ , 也就是说对每一个 $ \phi  \in  \Gamma ,\sigma  \vDash  \phi $ 。

$ §{2.6} $ 中引入了一些基本语义概念,都是用真值表来刻画的。真值表刻画在某种程度上依赖于读者对图形的直观。下面我们不借助这种直观, 仅仅运用真值指派和满足关系这些概念,对 $ §{2.6} $ 中引入的基本语义概念进行严格的定义。

### 3.3 重言蕴涵、重言等值与可满足性

“逻辑蕴涵”是逻辑学的核心观念之一,我们将在 $ §{8.7} $ 中讨论它,这里先讨论它在命题逻辑中的简单形式——“重言蕴涵”。 定义 47 令 $ \Gamma $ 为任意 $ {\mathcal{L}}_{0} $ -公式集(可以是无穷集)并且 $ \phi $ 为任意 $ {\mathcal{L}}_{0} $ -公式。 $ \Gamma $ 重言蕴涵 $ \phi $ (符号表示: $ \Gamma { \vDash  }_{0}\phi $ ) 当且仅当对每一个真值指派 $ \sigma $ ,如果 $ \sigma  \vDash  \Gamma $ 则 $ \sigma  \vDash  \phi 。\phi $ 是 $ \Gamma $ 的重言后承当且仅当 $ \Gamma { \vDash  }_{0}\phi $ 。

让 真值指派要对所有命题变号给出真值,并且在定义重言蕴涵等语义概念时,定义涉及的真值指派显然有无穷多个；而用真值表刻画这些基本语义概念时, 只需考虑给定公式中出现的有穷多个命题变号的真假,而且这些命题变号的可能取值组合也只有有穷多个。

例 49 对所有公式 $ \phi $ 和 $ \psi ,\phi  \vee  \psi , \sim  \phi { \vDash  }_{0}\psi $ 。

证明 令 $ \sigma $ 为任意真值指派。假设 $ \sigma  \vDash  \phi  \vee  \psi $ 且 $ \sigma  \vDash   \sim  \phi $ 。(以下证明 $ \sigma  \vDash  {\psi }_{ \circ  } $ ) 根据真理定义,由假设 $ \sigma  \vDash  \phi  \vee  \psi $ 得知或者 $ \sigma  \vDash  \phi $ 或者 $ \sigma  \vDash  \psi $ ,再由假设 $ \sigma  \vDash   \sim  \phi $ 得知 $ \sigma  \mathrel{\text{\vDash \not{} }} \phi $ ,从而有 $ \sigma  \vDash  \psi $ 。所以,对每个真值指派 $ \sigma $ ,如果 $ \sigma  \vDash  \phi  \vee  \psi $ 且 $ \sigma  \vDash   \sim  \phi $ ,那么 $ \sigma  \vDash  \psi $ 。根据重言蕴涵的定义, $ \phi  \vee  \psi , \sim  \phi { \vDash  }_{0}\psi $ 。

例 50 对所有公式 $ \phi ,\psi $ 和 $ \chi ,\phi  \rightarrow  \psi ,\psi  \rightarrow  \chi { \vDash  }_{0}\phi  \rightarrow  {\chi }_{ \circ  } $

证明 令 $ \sigma $ 为任意真值指派。假设 (i) $ \sigma  \vDash  \phi  \rightarrow  \psi $ 并且 (ii) $ \sigma  \vDash  \psi  \rightarrow  \chi $ 。(以下证明 $ \sigma  \vDash  \phi  \rightarrow  {\chi }_{ \circ  } $ ) 如果 $ \sigma  \mathrel{\text{\vDash \not{} }} \phi $ ,那么根据真理定义, $ \sigma  \vDash  \phi  \rightarrow  \chi $ 。所以,假设 (iii) $ \sigma  \vDash  \phi $ 。根据真理定义和 (iii),由 (i) 得到 $ \sigma  \vDash  \psi $ ,再由 (ii) 得到 $ \sigma  \vDash  \chi $ , 从而有 $ \sigma  \vDash  \phi  \rightarrow  \chi $ 。由此可知,对每个 $ \sigma $ ,如果 $ \sigma  \vDash  \phi  \rightarrow  \psi $ 且 $ \sigma  \vDash  \psi  \rightarrow  \chi $ , 那么 $ \sigma  \vDash  \phi  \rightarrow  \chi $ 。根据重言蕴涵的定义, $ \phi  \rightarrow  \psi ,\psi  \rightarrow  \chi { \vDash  }_{0}\phi  \rightarrow  \chi $ 。

命题 51 对所有公式集 $ \Gamma $ 和所有公式 $ \phi $ ,如果 $ \phi  \in  \Gamma $ 则 $ \Gamma { \vDash  }_{0}\phi $ 。

证明 设 $ \phi  \in  \Gamma $ 。对每个真值指派 $ \sigma $ ,如果 $ \sigma  \vDash  \Gamma $ ,那么根据定义 46, $ \sigma $ 满足 $ \Gamma $ 中所有公式,进而由 $ \phi  \in  \Gamma $ 得到 $ \sigma  \vDash  \phi $ 。(所以,根据重言蕴涵的定义, $ \Gamma { \vDash  }_{0}{\phi }_{ \circ  } $ )

命题 52 对所有公式集 $ \Gamma $ 和所有公式 $ \phi $ 与 $ \psi ,\Gamma ,\phi { \vDash  }_{0}\psi $ 当且仅当 $ \Gamma { \vDash  }_{0}\phi  \rightarrow  \psi $ 。

证明 假设 $ \Gamma { \mathrel{\text{\vDash \not{} }} }_{0}\phi  \rightarrow  \psi $ 。根据重言蕴涵的定义,存在真值指派 $ \sigma $ 使得 $ \sigma  \vDash  \Gamma $ 并且 $ \sigma  \nvDash  \phi  \rightarrow  \psi $ ,亦即 $ \sigma  \vDash  \phi $ 且 $ \sigma  \mathrel{\text{\vDash \not{} }} \psi $ ,从而得到 $ \sigma  \vDash  \Gamma  \cup  \{ \phi \} $ 且 $ \sigma  \mathrel{\text{\vDash \not{} }} \psi $ 。 (再根据重言蕴涵的定义得知 $ \Gamma ,\phi { \mathrel{\text{\vDash \not{} }} }_{0}{\psi }_{ \circ  } $ )

假设 $ \Gamma { \vDash  }_{0}\phi  \rightarrow  \psi $ 。令 $ \sigma $ 为任意真值指派。如果 $ \sigma  \vDash  \Gamma  \cup  \{ \phi \} $ ,则 $ \sigma  \vDash  \Gamma $ 且 $ \sigma  \vDash  \phi $ ,于是由假设和重言蕴涵的定义得知 $ \sigma  \vDash  \phi  \rightarrow  \psi $ 且 $ \sigma  \vDash  \phi $ ,进而再由真理定义得到 $ \sigma  \vDash  \psi $ 。(所以,根据重言蕴涵的定义, $ \Gamma ,\phi  \vDash  {}_{0}\psi $ 。)

### 3.4 重言式、矛盾式与或然式

定义 65 对任意 $ {\mathcal{L}}_{0} $ -公式 $ \phi ,\phi $ 是重言式当且仅当对每一个真值指派 $ \sigma ,\sigma  \vDash  \phi $ 。

定义 66 对任意 $ {\mathcal{L}}_{0} $ -公式 $ \phi ,\phi $ 是矛盾式(或不可满足式)当且仅当对每一个真值指派 $ \sigma ,\sigma  \mathrel{\text{\vDash \not{} }} \phi $ 。

定义 67 对任意 $ {\mathcal{L}}_{0} $ -公式 $ \phi ,\phi $ 是或然式当且仅当存在一个真值指派 $ \sigma $ 使得 $ \sigma  \vDash  \phi $ ,并且存在一个真值指派 $ {\sigma }^{\prime } $ ,使得 $ {\sigma }^{\prime } \mathrel{\text{\vDash \not{} }} \phi $ 。

注 68 与重言蕴涵、重言等值和可满足性等概念的情况类似,定义 65- 67 有别于 \$2.6.3 中对重言式等概念的真值表刻画:真值指派要对所有命题变号给出真值,并且重言式等的定义涉及的真值指派显然有无穷多个；这些概念的真值表刻画却不同,它们只考虑公式中出现的有穷多个命题变号的真假, 而这些命题变号的可能取值组合也只有有穷多个。

例 72 对任意公式 $ \phi , \sim  \left( {\phi  \rightarrow   \sim  \left( {\phi  \rightarrow   \sim  \phi }\right) }\right) $ 是矛盾式。

证明 令 $ \sigma $ 为任意真值指派。假设 $ \sigma  \vDash   \sim  \left( {\phi  \rightarrow   \sim  \left( {\phi  \rightarrow   \sim  \phi }\right) }\right) $ 。根据真理定义,我们有 $ \sigma  \mathrel{\text{\vDash \not{} }} \phi  \rightarrow   \sim  \left( {\phi  \rightarrow   \sim  \phi }\right) $ ,从而 $ \sigma  \vDash  \phi $ 且 $ \sigma  \mathrel{\text{\vDash \not{} }}  \sim  \left( {\phi  \rightarrow   \sim  \phi }\right) $ ,进而 $ \sigma  \vDash  \phi  \rightarrow   \sim  \phi $ 。易见 $ \sigma  \vDash  \phi $ 并且 $ \sigma  \vDash   \sim  \phi $ ,亦即 $ \sigma  \vDash  \phi $ 并且 $ \sigma  \mathrel{\text{\vDash \not{} }} \phi $ ,但这是不可能的。所以, $ \sigma  \mathrel{\text{\vDash \not{} }}  \sim  \left( {\phi  \rightarrow   \sim  \left( {\phi  \rightarrow   \sim  \phi }\right) }\right) $ 。

(ii) 设 $ \phi $ 或 $ \psi $ 是重言式。第一种情况: $ \phi $ 是重言式。对每个真值指派 $ \sigma $ , 既然 $ \phi $ 是重言式,我们有 $ \sigma  \vDash  \phi $ ,再由真理定义知 $ \sigma  \vDash  \phi  \vee  \psi $ 。所以 $ \phi  \vee  \psi $ 是重言式。第二种情况类似。逆命题不成立: 当 $ \phi  = p $ 且 $ \psi  =  \sim  p $ 时, $ \phi  \vee  \psi $ 是重言式,但 $ \phi $ 和 $ \psi $ 都不是重言式。

(iii) 设 $ \phi  \rightarrow  \psi $ 是重言式。如果 $ \phi $ 是重言式,那么,对每个真值指派 $ \sigma ,\sigma  \vDash  \phi  \rightarrow  \psi $ 并且 $ \sigma  \vDash  \phi $ ,从而由真理定义知 $ \sigma  \vDash  \psi $ 。所以,或者 $ \phi $ 不是重言式或者 $ \psi $ 是重言式。逆命题不成立: 令 $ \phi  = p $ 且 $ \psi  =  \sim  p $ 。显然, $ \phi $ 不是重言式,所以或者 $ \phi $ 不是重言式或者 $ \psi $ 是重言式,但 $ \phi  \rightarrow  \psi $ 却不是重言式。

(iv) 由真理定义易见,如果 $ \phi $ 是矛盾式则 $ \phi  \rightarrow  \psi $ 是重言式,并且如果 $ \psi $ 是重言式则 $ \phi  \rightarrow  \psi $ 也是重言式。所以,如果 $ \phi $ 是矛盾式或者 $ \psi $ 是重言式,那么 $ \phi  \rightarrow  \psi $ 是重言式。逆命题不成立: 令 $ \phi  = \psi  = p $ 。显然, $ \phi  \rightarrow  \psi $ 是重言式,但 $ \phi $ 不是矛盾式, $ \psi $ 也不是重言式。

(v) 设 $ \phi  \leftrightarrow  \psi $ 是重言式。对每个真值指派 $ \sigma $ ,如果 $ \sigma  \vDash  \phi $ ,那么根据假设和真理定义, $ \sigma  \vDash  \psi $ 。所以, $ \phi  \rightarrow  \psi $ 是重言式。同理可证, $ \psi  \rightarrow  \phi $ 也是重言式。设 $ \phi  \rightarrow  \psi $ 和 $ \psi  \rightarrow  \phi $ 都是重言式。令 $ \sigma $ 为任意真值指派。根据假设和真理定义,如果 $ \sigma  \vDash  \phi $ 则 $ \sigma  \vDash  \psi $ ,并且如果 $ \sigma  \mathrel{\text{\vDash \not{} }} \phi $ 则 $ \sigma  \mathrel{\text{\vDash \not{} }} \psi $ ; 于是有 $ {\phi }^{\sigma } = {\psi }^{\sigma } $ , 再由真理定义得到 $ \sigma  \vDash  \phi  \leftrightarrow  \psi $ 。所以, $ \phi  \leftrightarrow  \psi $ 是重言式。

### 3.6 代入的语义性质

这里我们讨论公式的不同代入结果在真值指派下的值,比如说, $ \phi \left( {\psi /p}\right) $ 和 $ \phi \left( {\chi /p}\right) $ 在 $ \sigma $ 下的值。不难猜测: 如果 $ {\psi }^{\sigma } = {p}^{\sigma } $ 则 $ {\phi }^{\sigma } = {\left( \phi \left( \psi /p\right) \right) }^{\sigma } $ ,亦即在 $ \sigma $ 下,如果 $ \psi $ 和 $ p $ 的值相同,那么无论对 $ \phi $ 是否做代入 $ \psi /p $ ,其结果的值应该是一样的。一般地,公式 $ \phi \left( {\psi /p}\right) $ 在 $ \sigma $ 下的值与 $ \psi $ 在 $ \sigma $ 下的值有关,但与 $ \psi $ 具体是哪个公式无关,也就是说,只要 $ \psi $ 和 $ \chi $ 在 $ \sigma $ 下的值相同, 那么无论是对 $ \phi $ 做代入 $ \psi /p $ 还是做代入 $ \chi /p $ ,其结果在 $ \sigma $ 下的值都是一样的 (见推论 91)。下面几个命题说的正是这类事,不过比这更一般。

定理 89 设 $ \phi $ 为任意公式,其中出现的命题变号只有 $ {q}_{0},\ldots ,{q}_{n} $ ,并设 $ \sigma $ 和 $ {\sigma }^{\prime } $ 为任意真值指派,满足 $ {\psi }_{0}^{\sigma } = {\chi }_{0}^{{\sigma }^{\prime }},\ldots ,{\psi }_{n}^{\sigma } = {\chi }_{n}^{{\sigma }^{\prime }} $ 。我们有: $ \sigma  \vDash $ $ \phi \left( {{\psi }_{0}/{q}_{0},\ldots ,{\psi }_{n}/{q}_{n}}\right) $ 当且仅当 $ {\sigma }^{\prime } \vDash  \phi \left( {{\chi }_{0}/{q}_{0},\ldots ,{\chi }_{n}/{q}_{n}}\right) $ 。

证明 令 $ \mathfrak{s} $ 为 $ {\psi }_{0}/{q}_{0},\ldots ,{\psi }_{n}/{q}_{n} $ 且 $ {\mathfrak{s}}^{\prime } $ 为 $ {\chi }_{0}/{q}_{1},\ldots ,{\chi }_{n}/{q}_{n} $ 。施归纳于公式的复杂度。归纳基始: $ \phi  = {q}_{i}\left( {i \leq  n}\right) $ 。显然有 $ \phi \left( \mathfrak{s}\right)  = {\psi }_{i} $ 且 $ \phi \left( {\mathfrak{s}}^{\prime }\right)  = {\chi }_{i} $ , 而根据题设 $ {\psi }_{i}^{\sigma } = {\chi }_{i}^{{\sigma }^{\prime }} $ ,我们有 $ \sigma  \vDash  {\psi }_{i} $ 当且仅当 $ {\sigma }^{\prime } \vDash  {\chi }_{i} $ 。归纳步骤: 设 $ \phi  =  \sim  \theta $ 。根据归纳假设, $ \sigma  \vDash  \theta \left( \mathfrak{s}\right) $ 当且仅当 $ {\sigma }^{\prime } \vDash  \theta \left( {\mathfrak{s}}^{\prime }\right) $ ,因而根据真理定义, $ \sigma  \vDash   \sim  \theta \left( \mathfrak{s}\right) $ 当且仅当 $ {\sigma }^{\prime } \vDash   \sim  \theta \left( {\mathfrak{s}}^{\prime }\right) $ ,再由定义 80 知, $ \sigma  \vDash  \left( { \sim  \theta }\right) \left( \mathfrak{s}\right) $ 当且仅当 $ {\sigma }^{\prime } \vDash  \left( { \sim  \theta }\right) \left( {\mathfrak{s}}^{\prime }\right) $ 。设 $ \phi  = \theta  \odot  \lambda $ ,其中 $ \odot   \in  \{  \vee  , \land  , \rightarrow  , \leftrightarrow  \} $ 。由归纳假设, $ \sigma  \vDash  \theta \left( \mathfrak{s}\right) $ 当且仅当 $ {\sigma }^{\prime } \vDash  \theta \left( {\mathfrak{s}}^{\prime }\right) $ ,并且 $ \sigma  \vDash  \lambda \left( \mathfrak{s}\right) $ 当且仅当 $ {\sigma }^{\prime } \vDash  \lambda \left( {\mathfrak{s}}^{\prime }\right) $ ; 所以根据真理定义, $ \sigma  \vDash  \theta \left( \mathfrak{s}\right)  \odot  \lambda \left( \mathfrak{s}\right) $ 当且仅当 $ {\sigma }^{\prime } \vDash  \theta \left( {\mathfrak{s}}^{\prime }\right)  \odot  \lambda \left( {\mathfrak{s}}^{\prime }\right) $ ,再由定义 80 知, $ \sigma  \vDash  \left( {\theta  \odot  \lambda }\right) \left( \mathfrak{s}\right) $ 当且仅当 $ {\sigma }^{\prime } \vDash  \left( {\theta  \odot  \lambda }\right) \left( {\mathfrak{s}}^{\prime }\right) $ 。■

推论 94 如果 $ \psi $ 与 $ \chi $ 重言等值,那么 $ \phi $ 与它的所有 $ \chi /\psi $ -置换结果都重言等值。

\[

\[

代入和置换有很大不同: 从上面的例子可以看出,

#### 3.7.3 基本语义概念的严格定义和真值表刻画的等价性

重言蕴涵等概念的严格定义和它们的真值表刻画有明显的区别。比如说重言式, 按照它的严格定义, 一公式是否重言式的问题涉及无穷多真值指派, 每个真值指派又涉及无穷多命题变号的真值; 而按照它的真值表刻画, 一公式是否重言式的问题,却只涉及某个有穷的命题变号集合 $ A $ 和有穷多个 $ A $ -赋值。尽管如此,“严格定义” 和 “真值表刻画” 在下述意义上是等价的:满足 “严格定义” 的一定满足 “真值表刻画”,而满足 “真值表刻画” 的也一定满足 “严格定义”。下面我们提供这种等价性的证明。 借助直观, 人们会有以下猜测: 一个公式 $ \phi $ 在一真值指派 $ \sigma $ 下的值,应只与 $ \sigma $ 指派给 $ \phi $ 中出现的命题变号的值有关,或者说,与 $ \sigma $ 指派(3.12)给其他命题变号的值无关。

### 3.9 函数完全性

#### 3.9.1 真值函数在形式语言中的表达

显然, 真值函数有无穷多。在如此多的函数中, 有些明显可以用其他真值函数来合成或复合 (compose)。比如第 93 页例 96 中的 $ {f}_{16} $ 显然可以用 $ {f}_{1} $ 和 $ {f}_{ \sim  } $ 来合成 (亦即 $ {f}_{16}\left( {x, y}\right)  = {f}_{ \sim  }\left( {{f}_{1}\left( {x, y}\right) }\right) $ )。那么,有没有一集真值函数(最好不要太多)可以合成所有的真值函数？如果有,哪些真值函数集可以合成所有的真值函数？简单地说,这就是 “函数完全性” 问题。

这样的问题当然是数学问题。我们寻找数学问题的解, 部分地是因为它们往往有解。但我们关心函数完全性问题决不仅仅是因为它有解或很可能有解。函数完全性问题和形式语言的 “表达力” 有直接关系。

$ {\mathcal{L}}_{0} $ -公式能表达什么? 让我们来看两个例子。先看公式 $ p \vee  q $ 。当考虑公式的值时,命题变号 $ p $ 和 $ q $ 是取值于 $ \{ \mathrm{T},\mathrm{F}\} $ 的变元,而一旦它们的取值确定了, $ p \vee  q $ 的值 (真值) 也就经 $ {f}_{ \vee  } $ 唯一地确定了。在这个意义上,我们说 $ p \vee  q $ 表达了真值函数 $ {f}_{ \vee  } $ 。 $ {}^{16} $

#### 3.9.2 具有函数完全性的几组真值联结词

这一小节里我们讨论具有函数完全性的几个真值联结词的集合。

命题 117 所有真值函数都在 $ {\mathcal{L}}_{ \sim  ,\vee , \land  } $ 中可表达。

证明 令 $ f $ 为任意 $ n $ 元真值函数 $ \left( {n > 0}\right) $ 。我们分两种情况讨论。

情况 I: 对所有的 $ {a}_{0},\ldots ,{a}_{n - 1} \in  \{ \mathrm{T},\mathrm{F}\} $ 都有 $ f\left( {{a}_{0},\ldots ,{a}_{n - 1}}\right)  = \mathrm{F} $ 。令 $ \phi  = {p}_{0} \land   \sim  {p}_{0} \land  {p}_{1} \land  \cdots  \land  {p}_{n - 1} $ 。易见对所有真值指派 $ \sigma $ 都有 $ {\phi }^{\sigma } = \mathrm{F} $ ,所以在情况 I 下, $ f $ 在 $ {\mathcal{L}}_{ \sim  ,\vee , \land  } $ 中可表达。

情况 II: 存在 $ {a}_{0},\ldots ,{a}_{n - 1} \in  \{ \mathrm{T},\mathrm{F}\} $ 使得 $ f\left( {{a}_{0},\ldots ,{a}_{n - 1}}\right)  = \mathrm{T} $ 。设

\[
{b}_{0}^{0},\ldots ,{b}_{n - 1}^{0};\;{b}_{0}^{1},\ldots ,{b}_{n - 1}^{1};\;\ldots ;\;{b}_{0}^{k},\ldots ,{b}_{n - 1}^{k} \tag{3.13}
\]

$ \left( {k < {2}^{n}}\right) $ 为所有的真值序列 $ {a}_{0},\ldots ,{a}_{n - 1} \in  \{ \mathrm{T},\mathrm{F}\} $ 使得 $ f\left( {{a}_{0},\ldots ,{a}_{n - 1}}\right)  = \mathrm{T} $ 。 对每个 $ i \leq  k $ 和 $ j < n $ ,令

## 关于形式系统的简单说明

这一编中说的命题演算, 是指一个或一类旨在以语法方法刻画重言蕴涵关系的形式系统。第四编中说的谓词演算, 是指一个或一类旨在以语法方法刻画一阶语言范围内的逻辑蕴涵关系的形式系统。让我们用 “逻辑演算” 来做它们的统称。具体讨论前,我们先对形式系统做点简单的说明。 $ {}^{1} $

先说说一般的形式系统。形式系统有两个方面, 一是形式化, 二是源于欧氏几何的公理方法; 它是传统的公理方法和形式化的结合点, 或者说是形式化的公理系统。在这样的系统中, 一段 “文字” 是否一个演绎或证明是仅从形式方面就可以机械地判定的, 它不依赖于人们对这段 “文字” 的理解或解释。具体说来, 在这样的系统中, 一小部分公式被选出来做 “公理”, 又有少量 “变形规则” 被选出来对给定公式做变形——每个这样的规则只允许从具有某种特定形式的公式得出某个在形式上与它们相关的公式。这样, 从任意的 “前提” 开始, 反复运用公理和变形规则而生成一个公式序列, 直到得出 “结论” $ \psi $ 。这样的公式序列被称为从该前提到 $ \psi $ 的演绎或推演,而 $ \psi $ 被称为从该前提 “可演绎”。当只用公理和规则就得到了 $ \psi $ 的演绎时, $ \psi $ 的这个演绎就是 $ \psi $ 的一个证明。既然形式系统要求对演绎和证明的可判定性, 那么它自然地要求公理和规则的可判定性。也就是说, 形式系统要求: 任一公式是否系统的公理是可以机械地判定的, 而且任一公式是否从给定公式经系统的变形规则可以得到也是可以机械地判定的。 $ {}^{2} $

下面说说命题演算和谓词演算这类形式系统。

传统逻辑对逻辑后承关系的研究,在一定范围内还是很详细的,比如它给出了三段论式推理中有效推理形式的完整排列；但这种详细研究毕竟是被限制在很小的范围里,对于科学研究,特别是数学研究来说是远远不够的。 从十九世纪中叶开始, 从事逻辑研究的数学家们发现了大量的新的有效推理的形式, 而这些有效形式的数量之多, 形式之复杂, 远不是一个简单的排列就能囊括的。于是, 在以形式系统的方式研究各种数学理论的同时, 数学家们也以同样的方式研究逻辑理论,其结果就包括了逻辑演算这类形式系统。

逻辑演算的设计目标, 从较具体的方面说是要刻画联结词、量词和等词等逻辑常项, 而从较抽象的方面说是要刻画逻辑推理。逻辑演算的公理和规则无不直接或间接地定义逻辑常项且表明它们的用法, 因而在这个意义上, 公理和规则都在刻画这些逻辑常项；而作为结果, 整个系统也就在刻画涉及这些逻辑常项的逻辑推理。

$ {}^{1} $ 这里关于形式系统的简单说明,是结合 Henkin [1967] 和 Wang [1981] (chapter 2) 中相关内容的结果。

$ {}^{2} $ 当然,一个形式系统也可以只有变形规则而没有公理。这并不影响问题的关键——机械地判定任给的一段 “文字” 是否演绎或证明。注意: 凡说到演绎的可判定性时, 我们预设前提的可判定性。

---

恰当地选择系统的公理和变形规则, 可以使逻辑演算准确地刻画逻辑常项, 进而准确地刻画涉及这些逻辑常项的逻辑推理。所谓对逻辑推理的 “准确刻画”, 是说凡是在系统中从前提可演绎的都被前提逻辑蕴涵 (重言蕴涵), 而凡是被前提逻辑蕴涵 (重言蕴涵) 的都在系统中从前提可演绎。特别地, 凡是系统中可证明的都是系统的语言中的逻辑真理 (重言式), 而凡是该语言中的逻辑真理 (重言式) 都在系统中可以证明。前一种性质被称为 “可靠性” (soundness),而后一种性质被称为 “(语义) 完全性” (completeness)。 $ {}^{3} $

就逻辑演算刻画具体的逻辑常项来说, 这类系统只是具体的形式系统, 就像形式算术系统。但是, 因为逻辑演算只刻画逻辑常项, 而不刻画具体谓词、函数和常项等非逻辑符号, 所以逻辑演算具有普遍性: 无论具体的非逻辑符号被解释成什么 (比如算术中的加法和乘法), 逻辑演算提供的含这些符号的公式间的可演绎关系都是正确的逻辑推理, 并且逻辑演算中含这些符号的可证公式都是逻辑真理。正因如此, 古典数学的形式系统和古典逻辑的扩充都会或隐或显地包含逻辑演算作为它们的基础。本书讨论的形式系统只限于逻辑演算 (对形式算术系统的零星讨论并不足道), 目的是为读者学习一阶理论打好基础。

对当代逻辑的完整理解, 依赖于掌握形式和意义两方面的各种观念及其相互关系。这一编和第四编的绝大部分内容, 都是形式方面的。引言中说过, 在构造或寻找从 $ {\phi }_{0},\ldots ,{\phi }_{k} $ 到 $ \psi $ 的演绎时,人们可以完全不考虑 $ {\phi }_{0},\ldots ,{\phi }_{k} $ 和 $ \psi $ 的真假,甚至可以根本没有真和假的观念——人们做的可以仅仅是运用公理和变形规则, 而且这样运用时又仅仅考察公式的形式结构。当这里的 “演绎” 被理解为形式系统中的演绎时, 我们需要把这几个 “可以” 改为 “应该”。根据前面的说明,对形式系统中演绎和证明的判定与符号或符号串的意义无关, 所以, 初学者在学习形式系统时, 应暂时 “忘记” 联结词的意义和公式之间的真值联系, 而只考虑公式在形式或结构方面的联系。

我们介绍两种类型的形式系统:费奇式推演和弗雷格-希尔伯特式演算。 前者通常称为自然演绎 (natural deduction), 是一种没有公理只有变形规则的形式系统；后者又称为公理系统 (axiomatic systems),是既有公理又有变形规则的形式系统。我们先讨论费奇式推演。
