第6步陈述： m∠VTR + m∠SRT = m∠VTR + m∠VTW

回顾前面的步骤：

  • 第2步： m∠VTR + m∠SRT = 180°
  • 第4步： m∠VTR + m∠VTW = 180° （第5步只是用对称性重写了第4步：180° = m∠VTR + m∠VTW）

现在有两个量都等于180°：

  1. (m∠VTR + m∠SRT) 等于 180°（来自第2步）
  2. (m∠VTR + m∠VTW) 等于 180°（来自第4步）

由于这两个表达式都等于同一个值（180°），它们必须彼此相等。因此，(m∠VTR + m∠SRT) = (m∠VTR + m∠VTW)。

这是等式的传递性的应用（如果a = b且b = c，那么a = c）。在这里：

  • a 是 m∠VTR + m∠SRT
  • b 是 180°
  • c 是 m∠VTR + m∠VTW

或者，也可以看作是等式的替换性。从第2步：m∠VTR + m∠SRT = 180° 从第4步：m∠VTR + m∠VTW = 180°。你可以在第2步的等式中用(m∠VTR + m∠VTW)替换180°。

为什么“加法原理”不适用于第6步： “等式的加法性质”指的是如果你有一个等式（例如x = y），你可以在两边加上相同的量，等式仍然成立（例如x + z = y + z）。要使用加法性质得到第6步，你需要从一个像m∠SRT = m∠VTW的等式开始（这实际上是第7步，第6步的结果），然后在两边加上m∠VTR。但证明的逻辑是从第6步流向第7步，而不是反过来。

因此，第6步的理由应该是“等式的传递性”或“等式的替换性”。 在几何的多选题中，当两个量等于同一个第三量时，“等式的传递性”通常是更精确的选择。

关于第7步的说明： 第7步：m∠SRT = m∠VTW 给出的理由是“加法原理”。实际上这是通过在第6步两边减去m∠VTR得到的。等式的减法性质通常被归类为加法性质的一种形式（加上一个负数）。因此，第7步的理由更准确地说是“等式的减法性质”。

错误信息“Oops, that's not quite right”指的是你对第6步的选择。

总结第6步： 你将两个表达式设为相等，因为它们在前面的步骤中都被证明等于180°。这是传递性（或替换性）的应用。
