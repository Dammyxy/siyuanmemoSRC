首先，注意到P(t) 必须包含一个指数增长项。这使我们可以排除以下选项：

4(1.05)−t， (1.05)−t + 4

其中项 4(1.05)−t 和 (1.05)−t 表示指数衰减，因为1.05 > 1 但 −t < 0。

因此，我们剩下以下三个选项：

4(1.05)t， (1.05)t + 4， (1.05)t + 3

让我们排除那些不符合 \(P(t)\) 所需特征的选项：

因为当 \(t = 0\) 时，这个表达式等于 5。

因为当 t → −∞ 时，这个表达式趋近于 3。

因此，我们得出结论：

P(t) = 4(1.05)t。

数学知识点

  • 指数函数： 形如 f(t) = a ·bt 的函数，其中 \(a\) 是初始值，\(b\) 是底数。
  • 指数增长与衰减：
    • 当 b > 1 时，函数表示指数增长。
    • 当0 < b < 1 时，函数表示指数衰减。
  • 负指数： b−t = [1/(bt)] 。如果 \(b > 1\)，那么 \(b^{-t}\) 表示指数衰减，因为 \(\frac{1}{b} < 1\)。
  • 函数的初始值： 当 \(t=0\) 时的函数值 \(P(0)\) 表示初始值。
  • 函数的极限： 当 t 趋向于正无穷或负无穷时，函数值的趋势。特别是当 b > 1 时，bt → 0 当 t → −∞ ，bt → ∞ 当 t → ∞ 。

解题逻辑和思路

这段文字通过排除不符合给定条件的选项来确定正确的函数表达式。整个逻辑基于对指数函数行为的理解以及对图表（尽管图表本身未提供，但描述了其特征）信息的解读。

解题思路：

  1. 初步筛选： 根据 \(P(t)\) 必须包含指数增长项的要求，排除包含指数衰减项的选项。
    • 选项 \(4(1.05)^{-t}\) 和 \((1.05)^{-t} + 4\) 中的 \((1.05)^{-t}\) 等于 \(\left(\frac{1}{1.05}\right)^t\)。由于 \(1.05 > 1\)，则 \(\frac{1}{1.05} < 1\)，所以 \((1.05)^{-t}\) 表示指数衰减。因此排除这两个选项。
  2. 剩余选项： 剩下 \(4(1.05)^{t}\)， \((1.05)^{t} + 4\)， \((1.05)^{t} + 3\) 这三个包含指数增长项的选项。
  3. 利用初始值进行排除： 根据图表特征，要求 \(P(0) = 4\)。计算剩余选项在 \(t=0\) 时的值：
    • 对于 \((1.05)^{t} + 4\)，当 \(t=0\) 时，\((1.05)^0 + 4 = 1 + 4 = 5\)。不等于 4，排除此选项。
    • 对于 \(4(1.05)^{t}\)，当 \(t=0\) 时，\(4(1.05)^0 = 4 \cdot 1 = 4\)。符合要求。
    • 对于 \((1.05)^{t} + 3\)，当 \(t=0\) 时，\((1.05)^0 + 3 = 1 + 3 = 4\)。符合要求。
  4. 利用渐近线特征进行排除： 根据图表特征，要求当 \(t \to -\infty\) 时，\(P \to 0\)。计算剩余符合初始值条件的选项在 \(t \to -\infty\) 时的极限：
    • 对于 \(4(1.05)^{t}\)，当 \(t \to -\infty\) 时，\(1.05^t \to 0\)，所以 \(4(1.05)^t \to 4 \cdot 0 = 0\)。符合要求。
    • 对于 \((1.05)^{t} + 3\)，当 \(t \to -\infty\) 时，\(1.05^t \to 0\)，所以 \((1.05)^{t} + 3 \to 0 + 3 = 3\)。不趋近于 0，排除此选项。
  5. 得出结论： 经过两轮排除，只剩下 \(P(t) = 4(1.05)^{t}\) 符合所有已知条件。
