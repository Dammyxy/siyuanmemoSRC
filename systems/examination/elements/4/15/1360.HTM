  • 考虑第 2 行。从第 1 行我们知道 ―↔KL 和 ―↔MN 是平行的。因此，根据同位角公设，∡MOQ ∝ ∡α。

数学知识点：

这个证明与之前证明三角形内角和定理的思路相似，都是通过构造辅助线将三角形的内角“转移”到一条直线上，然后利用平角的性质来证明。但这次使用的具体角度关系定理略有不同。

  • 三角形内角和定理：任何三角形的三个内角的度数之和都等于 180°。
  • 平行线 (―↔KL || ―↔MN)：永不相交的两条直线。
  • 截线：与两条或多条直线相交的直线。在这个图中，―MK（延长线到P）和 ―OL（延长线到Q）都可以看作截线。
  • 同位角 (Corresponding Angles)：当一条截线截两条直线时，位于截线同侧，且一个在两条直线之间（内部），另一个在两条直线之外（外部）的角。如果两条直线平行，则同位角全等。
    • 本证明中，∡MOQ 和 ∡α 是同位角。
    • ∡PON 和 ∡γ 是同位角。
  • 对顶角 (Vertical Angles)：两条直线相交时，不相邻且相对的两个角。对顶角总是全等的。
    • 本证明中，∡QOP 和 ∡β 是对顶角。β是三角形的一个内角，∡QOP 是由辅助线形成的。
  • 全等角 (Congruent Angles)：度数相等的角。
  • 平角 (Straight Angle)：度数为 180° 的角。直线 ―↔MN 上的 ∡MON 是一个平角。
  • 角的加法公设 (Angle Addition Postulate)：如果一个角被射线分成几个小角，那么这些小角的度数之和等于大角的度数。这里，平角 ∡MON 由 ∡MOQ、∡QOP 和 ∡PON 组成。
    •
  • 代入 (Substitution)：用一个量替换与其相等的另一个量。
  • 等量的传递性 (Transitive Property of Equality)：如果 A = B 且 B = C，那么 A = C。

解题逻辑和思路：

这个证明是三角形内角和定理的另一种常见证明方法，它与你之前看到的证明思路类似，但具体运用了不同的角度关系定理来“转移”角的度数。

为什么这次使用了同位角和对顶角，而上次使用了内错角？有什么忽略的吗？

你没有忽略任何东西，这正是不同证明方法之间的区别和几何学的魅力所在！

上次的证明通过构造辅助线平行于三角形的底边 AB，并在顶点 C 处连接，使辅助线和三角形的两条腰（AC 和 BC）形成内错角。
∡ACD ∝ ∡A (内错角)

∡BCE ∝ ∡B (内错角)

然后结合 ∡ACB，这三个角恰好构成了 C 点处的平角。

这次的证明，辅助线 ―↔MN 也是平行于三角形的底边 KL，但它通过三角形的顶点 O (这里是三角形的另一个顶点，对应图中的 β 角)，并且辅助线是水平放置的。这种构造导致了不同类型的角度关系被利用：

  1. 已知条件：―↔KL || ―↔MN (辅助线平行于三角形的一条边)。
  2. 转移 α 角：
    • 将直线 ―↔LO 看作截线，它截平行线 ―↔KL 和 ―↔MN。
    • ∡α (在三角形 L 点) 和 ∡MOQ (在辅助线下方，截线左侧) 是同位角。根据同位角公设，它们全等：m∡MOQ = mα。
  3. 转移 γ 角：
    • 将直线 ―↔KO 看作截线，它截平行线 ―↔KL 和 ―↔MN。
    • ∡γ (在三角形 K 点) 和 ∡PON (在辅助线下方，截线右侧) 是同位角。根据同位角公设，它们全等：m∡PON = mγ。
  4. 转移 β 角：
    • ∡β (三角形顶点 O 的内角) 和 ∡QOP (由辅助线形成的角) 是对顶角。根据对顶角定理，它们全等：m∡QOP = mβ。
  5. 利用平角：
    • 辅助线 ―↔MN 是一条直线，所以 ∡MON 是一个平角，其度数为 180° (m∡MON = 180°)。
    • 根据角的加法公设，平角 ∡MON 由三个相邻的角组成：∡MOQ + ∡QOP + ∡PON = ∡MON。
  6. 代入与整合：
    • 将步骤 2、3、4 中得到的相等关系代入平角等式中：
      mα + mβ + mγ = m∡MON
    • 再将平角的度数代入：
      mα + mβ + mγ = 180°
  7. 得出结论：成功证明三角形内角和为 180°。

总结： 这两种证明方法都是正确的，它们都巧妙地利用了“辅助线与平行线性质”来把三角形的三个内角“拼”成一个平角。不同之处在于辅助线的具体位置和方向，从而导致在转移角的过程中，有时会用到内错角定理，有时会用到同位角定理，有时还会用到对顶角定理。这体现了几何证明的灵活性和多种路径的可能性。
