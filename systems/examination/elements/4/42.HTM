6. 方向 2 (←) 的证明（详细解释）

方向 2 的证明和方向 1 类似，只是方向相反：

  1.  

    假设: P(AB) = P(A) * P(B) ∧ P(A) > 0 ∧ P(B) >0 为真。

    •  解释: 我们假设 A 和 B 同时发生的概率等于它们各自概率的乘积, 且它们各自发生的概率大于0。 
     
  2.  

     

    条件概率公式: 同方向 1，我们有 P(A|B) = P(AB) / P(B)。

    •  解释: 和之前一样，这是条件概率的定义。 
     
  3.  

    代入: 将假设 P(AB) = P(A) * P(B) 代入条件概率公式： P(A|B) = (P(A) * P(B)) / P(B)。

    •  解释: 同样的替换规则。 
     
  4.  

    化简: 由于我们假设了P(B) > 0，所以可以约去 P(B)，得到 P(A|B) = P(A)。

    •  解释: 简单的代数化简。 
     
  5.  

    同理可证 P(B|A) = P(B) :使用相同逻辑，利用P(B|A) = P(AB) / P(A), 和已知的P(AB) = P(A) * P(B) ∧ P(A) > 0, 我们可以得到P(B|A) = P(B)。

    •  解释: 逻辑过程与第2,3,4步完全类似，只是交换A和B 
     
  6.  

     

    合取: 通过合取引入规则(&I)得到P(A|B) = P(A) ∧ P(B|A) = P(B) ∧ P(A) > 0 ∧ P(B) >0

    •  解释: 合取引入(&I)规则是指： 如果A为真，B也为真，那么A∧B为真 
     
  7.  

    根据定义得出结论： 由独立性定义I(A, B) ↔ (P(A|B) = P(A) ∧ P(B|A) = P(B) ∧ P(A) > 0 ∧ P(B) >0)和上一步结论，利用双向蕴含的定义得到I(A,B)

    •  解释: 因为上一步我们已经得到了等价符号右边的部分，根据双向蕴含的定义，可以直接得出等价符号左边的部分 
     
  8.  

    **条件证明:**由于我们从P(AB) = P(A) * P(B) ∧ P(A) > 0 ∧ P(B) >0推出了I(A,B), 因此得到(P(AB) = P(A) * P(B) ∧ P(A) > 0 ∧ P(B) >0) → I(A, B)

    •  解释: 条件证明的规则是指：为了证明A→B为真，我们只需要假设A为真，并在此假设上推导出B为真即可
