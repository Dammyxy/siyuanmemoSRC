你可能已经知道，对于抛物线 y = ax² + bx + c 且 a ≠ 0，其对称轴由以下公式给出：

x = -b / 2a

我们现在可以推导这个公式了。

由于 a ≠ 0，我们可以从抛物线方程的右侧提取因子 a：

y = a (x² + (b / a)x + c / a)

现在，我们来对括号内的表达式进行配方：

x² + (b / a)x + c / a

首先，我们将线性项的系数重写为以 2 为因子的乘积：

x² + 2 ⋅ (b / 2a)x + c / a

然后，我们加上再减去 (b / 2a)²：

x² + 2 ⋅ (b / 2a)x + (b / 2a)² - (b / 2a)² + c / a

这前三项构成一个完全平方，我们将其因式分解如下：

(x + b / 2a)² - (b / 2a)² + c / a

化简后两项，我们得到

(x + b / 2a)² - b² / 4a² + c / a = (x + b / 2a)² + (4ac - b²) / 4a²。

接下来，我们将这个结果代回到我们原始的表达式中：

a ((x + b / 2a)² + (4ac - b²) / 4a²) = a (x + b / 2a)² + a ⋅ (4ac - b²) / 4a²

= a (x + b / 2a)² + (4ac - b²) / 4a

= a (x - (-b / 2a))² + (4ac - b²) / 4a

通过记

h = -b / 2a, k = (4ac - b²) / 4a

我们得到抛物线的顶点式方程：

y = a(x - h)² + k,

其中顶点由给出：

(h, k) = (-b / 2a, (4ac - b²) / 4a)。

最后，由于抛物线的对称轴是通过顶点的竖直线，所以轴的方程必须是

x = -b / 2a。

数学知识点：

  • 抛物线的标准方程：y = ax² + bx + c (a ≠ 0)。
  • 抛物线的顶点式：y = a(x - h)² + k。
  • 抛物线顶点的坐标：(h, k)。
  • 抛物线的对称轴方程：x = h。
  • 配方法。

解题逻辑和思路：

这段文本的目的是从抛物线的标准方程 y = ax² + bx + c 推导出顶点坐标和对称轴方程的公式。推导过程使用了配方法：

  1. 将标准方程右侧的表达式提取因子 a：y = a(x² + (b/a)x + c/a)。
  2. 对括号内的二次三项式 x² + (b/a)x + c/a 进行配方。
  3. 识别出需要添加和减去的常数项是 x 项系数 (b/a) 的一半 ((b/a)/2 = b/2a) 的平方，即 (b/2a)²。
  4. 在括号内添加和减去 (b/2a)²：x² + (b/a)x + (b/2a)² - (b/2a)² + c/a。
  5. 将前三项组合成一个完全平方：(x + b/2a)²。
  6. 合并后两项常数：- (b/2a)² + c/a = -b²/4a² + c/a = (4ac - b²)/4a²。
  7. 所以括号内的表达式变为 (x + b/2a)² + (4ac - b²)/4a²。
  8. 将这个结果乘回提取出的因子 a：y = a [(x + b/2a)² + (4ac - b²)/4a²] = a(x + b/2a)² + a(4ac - b²)/4a² = a(x + b/2a)² + (4ac - b²)/4a。
  9. 将表达式与顶点式 y = a(x - h)² + k 对照，可以看出 h = -b/2a，k = (4ac - b²)/4a。
  10. 因此，顶点的坐标是 (-b/2a, (4ac - b²)/4a)。
  11. 因为对称轴是经过顶点的竖直线，其方程为 x = h，所以对称轴的方程是 x = -b/2a。
