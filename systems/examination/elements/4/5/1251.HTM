QP = RP

下表给出了该命题的证明。选择表中正确的选项并完成证明。

声明 (Statement) 理由 (Reason)
1.  \(m\angle Q = m\angle R\) 给定 (Given)
2.  \(\angle Q \cong \angle R\) 全等的定义 (Definition of congruent angles)
3.  \(\angle QPS \cong \angle RPS\) 角平分线的定义 (Definition of an angle bisector)
4.  \(\overline{PS} \cong \overline{PS}\) 全等的自反性 (Reflexive property of congruence)

✖ 不正确

解释

正确的证明如下表所示。

声明 (Statement) 理由 (Reason)
1.  \(m\angle Q = m\angle R\) Given
2.  \(\angle Q \cong \angle R\) Definition of congruent angles
3.  \(\angle QPS \cong \angle RPS\) Definition of an angle bisector
4.  \(\overline{PS} \cong \overline{PS}\) Reflexive property of congruence
5.  \(\triangle QPS \cong \triangle RPS\) AAS criterion
6.  \(\overline{QP} \cong \overline{RP}\) CPCTC
7.  \(QP = RP\) Definition of congruent segments

让我们逐行检查。

  1. 我们已知 m∠Q = m∠R 。
  2. 从第 1 行，我们有 m∠Q = m∠R 。因此，根据全等角的定义，∠Q ≅ ∠R 。
  3. 我们已知 ―PS 平分角 ∠QPR 。因此，根据角平分线的定义，∠QPS ≅ ∠RPS 。
  4. 全等的自反性声明任何线段与其自身全等。因此，―PS ≅ ―PS 。
  5. 从第 2、3 和 4 行，我们有
    ∠Q ≅ ∠R， ∠QPS ≅ ∠RPS， ―PS ≅ ―PS 。
    因此，根据 AAS 准则，\(\triangle QPS \cong \triangle RPS\)  。
  6. 从第 5 行，我们有 \(\triangle QPS \cong \triangle RPS\)。因此，根据 CPCTC，\(\overline{QP} \cong \overline{RP}\)。
  7. 从第 6 行，我们有 \(\overline{QP} \cong \overline{RP}\)。因此，根据全等线段的定义，我们得出 \(QP = RP\)。

Title: 数学知识点

  • 角度度量： m∠Q 表示角 Q 的度数。
  • 全等角： 度数相等的角称为全等角 ( ≅ ) 。
  • 角平分线： 一条射线或线段将一个角分成两个全等角。
  • 全等线段： 长度相等的线段称为全等线段 ( ≅ ) 。
  • 全等的自反性 (Reflexive Property of Congruence)： 任何几何图形都与其自身全等。例如，线段 AB 全等于线段 AB (―AB ≅ ―AB) ，角 C 全等于角 C (∠C ≅ ∠C) 。
  • 三角形全等准则： 用于证明两个三角形全等的判定方法。这里使用了 AAS 准则。
    • AAS (Angle-Angle-Side) 准则： 如果一个三角形的两个角以及其中一个角的对边与另一个三角形的两个角以及其中一个角的对边分别全等，那么这两个三角形全等。
    • 其他常见的全等准则包括 SSS (边-边-边)、SAS (边-角-边)、ASA (角-边-角)。
    ~
  • CPCTC (Corresponding Parts of Congruent Triangles are Congruent)： 全等三角形的对应部分是全等的。这意味着如果两个三角形被证明是全等的，那么它们的对应边和对应角也全等。

解题逻辑和思路

这道题的逻辑是利用已知条件证明两个三角形全等，然后根据全等三角形的性质得出结论。这是一个典型的几何证明题。

解题思路：

  1. 分析已知条件：
    • \(m\angle Q = m\angle R\)，这说明 \(\angle Q \cong \angle R\)。
    • \(\overline{PS}\) 平分 \(\angle QPR\)，这说明 \(\angle QPS \cong \angle RPS\)。
    • 观察图形，我们要证明的是边 \(QP\) 和 \(RP\) 的长度相等，即 \(\overline{QP} \cong \overline{RP}\)。
  2. 确定目标： 目标是证明 \(\overline{QP} \cong \overline{RP}\)。根据 CPCTC 的原理，如果我们能证明 \(\overline{QP}\) 和 \(\overline{RP}\) 是两个全等三角形的对应边，那么它们就全等。
  3. 识别可能的全等三角形： 图中有两个三角形：\(\triangle QPS\) 和 \(\triangle RPS\)。如果能证明这两个三角形全等，那么它们的对应边 \(\overline{QP}\) 和 \(\overline{RP}\) 就全等。
  4. 寻找三角形全等的条件： 考察 \(\triangle QPS\) 和 \(\triangle RPS\)：
    • 我们已知 \(\angle Q \cong \angle R\) (根据已知条件)。
    • 我们已知 \(\angle QPS \cong \angle RPS\) (根据角平分线的定义)。
    • 线段 \(\overline{PS}\) 是两个三角形的公共边。根据全等的自反性，\(\overline{PS} \cong \overline{PS}\)。
  5. 应用三角形全等准则： 现在我们有 \(\angle Q \cong \angle R\) (角)、\(\angle QPS \cong \angle RPS\) (角) 和 \(\overline{PS} \cong \overline{PS}\) (边)。注意 \(\overline{PS}\) 是 \(\angle QPS\) 和 \(\angle RPS\) 的夹边，但不是 \(\angle Q\) 或 \(\angle R\) 的对边，也不是 \(\angle QPS\) 或 \(\angle RPS\) 的对边。然而，对于 \(\triangle QPS\) 和 \(\triangle RPS\)，我们有两个角全等（\(\angle Q\) 和 \(\angle R\)，以及 \(\angle QPS\) 和 \(\angle RPS\)），以及一个**非夹边** \(\overline{PS}\) 全等。这是一个 AAS 准则的应用场景。具体来说，在 \(\triangle QPS\) 中，我们有 \(\angle Q\)，\(\angle QPS\)，和边 \(\overline{PS}\)；在 \(\triangle RPS\) 中，我们有 \(\angle R\)，\(\angle RPS\)，和边 \(\overline{PS}\)。虽然 \(\overline{PS}\) 不是 \(\angle Q\) 或 \(\angle QPS\) 的对边，但我们可以用 AAS 证明全等。更严格地说，我们可以证明 \(\triangle QPS \cong \triangle RPS\) 基于 \(\angle Q \cong \angle R\) (角)、\(\angle QPS \cong \angle RPS\) (角) 和公共边 \(\overline{PS}\) (边)。这里 \(\overline{PS}\) 是 \(\angle Q\) 和 \(\angle QPS\) 所夹的边，是 \(\angle R\) 和 \(\angle RPS\) 所夹的边。因此，实际上更适合用 ASA 准则来理解（如果角度顺序是连续的）。然而，题目给出的证明使用了 AAS，这意味着它可能将 \(\overline{PS}\) 视为某个角的对边。让我们仔细检查：在 \(\triangle QPS\) 中，\(\angle Q\) 的对边是 \(\overline{PS}\)。在 \(\triangle RPS\) 中，\(\angle R\) 的对边是 \(\overline{PS}\)。所以我们有两个角全等 (\(\angle Q \cong \angle R\))，以及它们各自的对边 (\(\overline{PS}\)) 全等。再加上 \(\angle QPS \cong \angle RPS\)，这构成了 AAS 准则的应用：两个角 (\(\angle Q, \angle QPS\)) 和其中一个角的对边 (\(\overline{PS}\) 是 \(\angle Q\) 的对边) 分别全等。所以 AAS 是正确的准则。
  6. 应用 CPCTC 得出结论： 由于 \(\triangle QPS \cong \triangle RPS\)，它们的对应部分全等。对应边 \(\overline{QP}\) 和 \(\overline{RP}\) 是对应边，因此 \(\overline{QP} \cong \overline{RP}\)。
  7. 根据全等线段的定义得出长度相等： 全等线段的定义是它们的长度相等，所以 <span class="overacc2">&#x2015;</span>QP  &#8773; <span class="overacc2">&#x2015;</span>RP 意味着 \(QP = RP\)。

整个证明过程是严谨的，每一步都基于已知的定义、性质或前面已经证明的结论。
