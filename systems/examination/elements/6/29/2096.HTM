数学知识点：

  • 三角函数 (Trigonometric functions)：在直角三角形中，锐角的六种基本三角函数定义了角的度量与边长比值的关系。
    • 正弦 (sine, sin)：对边与斜边的比值。
    • 余弦 (cosine, cos)：邻边与斜边的比值。
    • 正切 (tangent, tan)：对边与邻边的比值。

  • 直角三角形的边 (Sides of a right triangle)：
    • 斜边 (hypotenuse)：直角对面的边，是直角三角形中最长的边。
    • 对边 (opposite)：相对于给定锐角的边。
    • 邻边 (adjacent)：相对于给定锐角的、且不为斜边的边。

解题逻辑和思路：

任务是根据给定的直角三角形，写出角 B 的 csc(B)、sec(B) 和 cot(B) 的表达式。核心思路是先识别出三角形中相对于角 B 的对边、邻边和斜边，然后应用倒数三角函数的定义。

  1. 识别三角形的边：

    在给定直角三角形 ABC 中，直角在 C 处：

    • 角 B 的对边是边 AC，长度为 b。
    • 角 B 的邻边是边 BC，长度为 a。
    • 斜边是边 AB，长度为 c。
  2. 计算 csc(B)：

    余割是正弦的倒数，定义为斜边与对边的比值。

    因此，csc(B) = 斜边 / 对边 = c / b。

  3. 计算 sec(B)：

    正割是余弦的倒数，定义为斜边与邻边的比值。

    因此，sec(B) = 斜边 / 邻边 = c / a。

  4. 计算 cot(B)：

    余切是正切的倒数，定义为邻边与对边的比值。

    因此，cot(B) = 邻边 / 对边 = a / b。
