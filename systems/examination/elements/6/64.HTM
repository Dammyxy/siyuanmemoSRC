### 8.2 “词典语义学”

形式语言的模型, 简单地说, 是对形式语言的非逻辑符号的解释。相对于给定的模型, 我们可以确定语言中句子的真假。这里说的 “词典语义学” 并不是通常说的一阶逻辑的语义学, 而是另外设计的玩具式语义学。讨论这种语义学是为了帮助读者理解一阶逻辑的语义学。

词典语义学中的模型以某些我们熟悉的集合为论域, 用这些论域上我们熟悉的个体、函数、性质和关系来解释形式语言中的个体常项、函数符号和谓词。之所以称这种模型为 “词典模型”,是因为设计这种模型就像在做符号化时设计词典, 只不过词典的使用与做符号化时正好相反。在这种模型的基础上, 我们可以通过与符号化反向的 “翻译”, 把形式语言的句子的真假问题归结为自然语言中句子的真假问题。

### 8.3 简单的集合论知识

这一节我们介绍些简单的集合论知识, 目的是更好地理解后面将要讨论的一阶逻辑的语义学。我们先说几件简单的、读者可能熟悉的事情:

我们不定义什么是集合, 读者可以凭直观来把握这个概念。比如说, 只要我们能把一些东西在观念中放在一起 (同其他东西分隔开), 那么我们就有了一个集合。

我们用 $ \in $ 表示属于关系,即集合的元素与集合之间的成员关系。比如,“ $ a \in  A $ ” 表示 $ a $ 属于 $ A $ 或 $ a $ 是 $ A $ 的元素。需要强调的是,集合概念是 “外延式” 的一一外延相同的集合就是相同的集合,亦即对所有集合 $ A $ 和 $ B $ ,下述命题成立:

如果对所有的 $ a, a \in  A $ 当且仅当 $ a \in  B $ ,那么 $ A = B $ 。

关于集合的简单运算 $ \cup  , \cap  , - $ 等,我们前面的讨论中已有涉及,不再重复,这里只提以下几个记法: 如果 $ {A}_{0},{A}_{1},{A}_{2},\ldots $ 是一系列集合, $ \mathop{\bigcup }\limits_{{k \geq  0}}{A}_{k} $ 表示 $ {A}_{0} \cup  {A}_{1} \cup  {A}_{2} \cup  \cdots $ ,且 $ \mathop{\bigcap }\limits_{{k \geq  0}}{A}_{k} $ 表示 $ {A}_{0} \cap  {A}_{1} \cap  {A}_{2} \cap  \cdots $ 。设 $ A $ 是个集合的集合。 $ \bigcup A $ 是这样一个集合: 对每个 $ a, a \in  \bigcup A $ 当且仅当存在某个 $ B \in  A $ 使得 $ a \in  B $ 。 $ \bigcap A $ (其中 $ A \neq  \varnothing $ ) 是这样一个集合: $ a \in  \bigcap A $ 当且仅当对每个 $ B \in  A $ 都有 $ a \in  B $ 。易见,如果 $ A = \left\{  {{A}_{0},{A}_{1},\ldots }\right\} $ ,那么 $ \bigcup A = \mathop{\bigcup }\limits_{{k \geq  0}}{A}_{k} $ 并且 $ \bigcap A = \mathop{\bigcap }\limits_{{k \geq  0}}{A}_{k} $ 。

#### 8.3.1 有序对和有序组

很多时候, 我们需要把集合中的元素排成一个序列, 甚至需要以排成序列的东西为元素的集合。这里的基本观念是有序对 (ordered pairs)。有序对通常用 $ \langle a, b\rangle $ 这样的表达式来表示。注意, $ \langle a, b\rangle $ 与集合 $ \{ a, b\} $ 不同一尽管它们似乎都只有 $ a $ 和 $ b $ 两个元素,但前者比后者多了一个序: $ a $ 是 $ \langle a, b\rangle $ 的第一个元素而 $ b $ 是它的第二个元素。 $ \{ a, b\} $ 和 $ \{ b, a\} $ 指同一个集合, $ \{ a, a\} $ 与 $ \{ a\} $ 也指同一个集合。但是, $ \langle a, b\rangle $ 和 $ \langle b, a\rangle $ 却是不同的对子 (只要 $ a \neq  b $ ), $ \langle a, a\rangle $ 和 $ \langle a\rangle $ 也是不同的。在集合论中,有序对 $ \langle a, b\rangle $ 用下述方式定义:

当然, 有序对到底应怎样定义并不重要, 重要的是它要满足以下条件:

#### 8.3.2 卡氏积和卡氏幂

设 $ n \geq  1 $ ,并设 $ {A}_{1},\ldots ,{A}_{n} $ 为任意的集合序列。 $ {A}_{1},\ldots ,{A}_{n} $ (以这样的次序)的卡氏积 (cartesian product) 记为:

\[
{A}_{1} \times  \cdots  \times  {A}_{n} \triangleq  \left\{  {\left\langle  {{a}_{1},\ldots ,{a}_{n}}\right\rangle   : {a}_{k} \in  {A}_{k},1 \leq  k \leq  n}\right\}
\]

亦即: $ {A}_{1} \times  \cdots  \times  {A}_{n} $ 是所有 $ n $ 元组 $ \left\langle  {{a}_{1},\ldots ,{a}_{n}}\right\rangle $ 的集合,其中 $ {a}_{1} \in $ $ {A}_{1},\ldots ,{a}_{n} \in  {A}_{n} $ 。

定义 383 (BSD) 设 $ \sigma $ 是模型 $ \mathfrak{A} $ (论域为 $ A $ ) 上的赋值。对所有公式 $ \phi $ ,我们递归地定义 $ {\phi }^{\sigma } $ ( $ \phi $ 在 $ \sigma $ 下的真值) 如下,其中 $ s, t,{t}_{1},\ldots ,{t}_{n} $ 为任意项, $ P $ 为任意 (非逻辑) $ n $ 元谓词 $ \left( {n \geq  1}\right) $ :

(i)

\[
{\left( s \equiv  t\right) }^{\sigma } = \mathrm{T}\text{ iff }{s}^{\sigma } = {t}^{\sigma }
\]

\[
{\left( P{t}_{1}\ldots {t}_{n}\right) }^{\sigma } = \mathrm{T}\text{ iff }\left\langle  {{t}_{1}^{\sigma },\ldots ,{t}_{n}^{\sigma }}\right\rangle   \in  {P}^{\sigma }
\]

(iii)

\[
{\left(  \sim  \psi \right) }^{\sigma } = \mathrm{T}\text{iff}{\psi }^{\sigma } \neq  \mathrm{T}
\]

(iv)

\[
{\left( \psi  \land  \chi \right) }^{\sigma } = \mathrm{T}\text{iff}{\psi }^{\sigma } = \mathrm{T}\text{并且}{\chi }^{\sigma } = \mathrm{T}
\]

\[
{\left( \psi  \vee  \chi \right) }^{\sigma } = \mathrm{T}\text{iff}{\psi }^{\sigma } = \mathrm{T}\text{或者}{\chi }^{\sigma } = \mathrm{T}
\]

(vi)

\[
{\left( \psi  \rightarrow  \chi \right) }^{\sigma } = \mathrm{T}\text{iff}{\psi }^{\sigma } \neq  \mathrm{T}\text{或者}{\chi }^{\sigma } = \mathrm{T}
\]

(vii)

\[
{\left( \psi  \leftrightarrow  \chi \right) }^{\sigma } = \mathrm{T}\text{ iff }{\psi }^{\sigma } = {\chi }^{\sigma }
\]

(viii)

\[
{\left( \forall x\psi \right) }^{\sigma } = \mathrm{T}\text{ iff }\text{ 对每一个 }a \in  A,{\psi }^{\sigma \left( {x/a}\right) } = \mathrm{T}
\]

(ix)

\[
{\left( \exists x\psi \right) }^{\sigma } = \mathrm{T}\text{ iff }\text{ 对某个 }a \in  A,{\psi }^{\sigma \left( {x/a}\right) } = \mathrm{T}
\]

以上两个定义被称为基本语义定义 (basic semantic definition, BSD)。最早明确表述 BSD 的是塔尔斯基 (A. Tarski), 所以 BSD 有时被称作 “塔尔斯基真理定义”、“塔尔斯基满足定义”或“塔尔斯基语义学”。 $ {}^{9} $

定义 384 设 $ \sigma $ 是模型 $ \mathfrak{A} $ 上的赋值。对所有公式集合 $ \Gamma ,\sigma $ 满足 $ \Gamma $ (记为 $ \sigma  \vDash  \Gamma $ ) 当且仅当对每一个 $ \phi  \in  \Gamma $ 都有 $ {\phi }^{\sigma } = \mathrm{T} $ 。我们用 $ \sigma  \nvDash  \Gamma $ 表示并非 $ \sigma  \vDash  \Gamma $ 。如果 $ \Gamma  = \{ \phi \} $ ,我们用 $ \sigma  \vDash  \phi $ 表示 $ \sigma  \vDash  \{ \phi \} $ 。

易见,对每个赋值 $ \sigma $ 和每个公式 $ \phi ,\sigma  \vDash  \phi $ 当且仅当 $ {\phi }^{\sigma } = \mathrm{T} $ ,而且 $ \sigma  \mathrel{\text{\vDash \not{} }} \phi $ 当且仅当 $ {\phi }^{\sigma } = \mathrm{F} $ 。

### 8.6 项的值和公式的真值

我们先举例说明如何计算项的值。设语言 $ {\mathcal{L}}^{ * } $ 中的非逻辑符号只有个体常项 $ \mathrm{a} $ 和一元函数符号 $ \mathrm{f} $ 。令 $ \mathfrak{A} $ 为下述模型:

论域: $ A = \{ a, b, c\} $

个体常项: $ {\mathbf{a}}^{\mathfrak{A}} = b $

函数符号: $ {\mathbf{f}}^{\mathfrak{A}}\left( a\right)  = b,{\mathbf{f}}^{\mathfrak{A}}\left( b\right)  = c,{\mathbf{f}}^{\mathfrak{A}}\left( c\right)  = a $

例 386 设 $ {t}_{0} = \mathrm{{ffa}} $ 且 $ {t}_{1} = \mathrm{{ff}}x $ ,并设 $ \sigma $ 为上述模型 $ \mathfrak{A} $ 上的赋值,满足 $ {x}^{\sigma } = a $ 。计算 $ {t}_{0}^{\sigma } $ 和 $ {t}_{1}^{\sigma } $ 。

$ {t}_{0} $ 中没有个体变项,它在 $ \sigma $ 下的值完全取决于 $ \mathfrak{A} $ 对 $ \mathbf{f} $ 和 $ \mathbf{a} $ 的解释:

\[
{t}_{0}^{\sigma } = {\mathbf{f}}^{\sigma }\left( {\left( \mathbf{f}\mathbf{a}\right) }^{\sigma }\right)  = {\mathbf{f}}^{\sigma }\left( {{\mathbf{f}}^{\sigma }\left( {\mathbf{a}}^{\sigma }\right) }\right)  = {\mathbf{f}}^{\mathfrak{A}}\left( {{\mathbf{f}}^{\mathfrak{A}}\left( {\mathbf{a}}^{\mathfrak{A}}\right) }\right)
\]

\[
= {\mathbf{f}}^{\mathfrak{A}}\left( {{\mathbf{f}}^{\mathfrak{A}}\left( b\right) }\right)  = {\mathbf{f}}^{\mathfrak{A}}\left( c\right)  = a
\]

$ {t}_{1} $ 中有个体变项 $ x $ ,所以 $ {t}_{1}^{\sigma } $ 不仅取决于 $ \mathfrak{A} $ 对 $ \mathrm{f} $ 的解释,也取决于 $ \sigma $ 对 $ x $ 的指派 $ a $ :

\[
{t}_{1}^{\sigma } = {\mathbf{f}}^{\sigma }\left( {\left( \mathbf{f}x\right) }^{\sigma }\right)  = {\mathbf{f}}^{\sigma }\left( {{\mathbf{f}}^{\sigma }\left( {x}^{\sigma }\right) }\right)
\]

\[
= {\mathbf{f}}^{\mathfrak{A}}\left( {{\mathbf{f}}^{\mathfrak{A}}\left( a\right) }\right)  = {\mathbf{f}}^{\mathfrak{A}}\left( b\right)  = c
\]

插议: 我们用斜体字母 $ a, b, c $ 等表示上述论域 $ A $ 的元素,用粗体字母 $ \mathbf{a},\mathbf{b},\mathbf{c} $ 等表示形式语言中的个体常项。首先要注意的是, 论域的元素并不是语言中的常项,二者不可混淆: $ \mathrm{{fa}} $ 中的 $ \mathrm{a} $ 不同于 $ {\mathbf{f}}^{\mathfrak{A}}\left( a\right) $ 中的 $ a $ (当然 $ \mathbf{f} $ 也不同于 $ {\mathbf{f}}^{\mathfrak{A}} $ )。其次, $ \mathbf{a} $ 在模型中的解释也未必是 $ a $ ——事实上, $ \mathbf{a} $ 在上述模型中的解释就是 $ b $ 而不是 $ a $ 。当然,有些教科书在某种很特殊的情况下把这两种东西等同, 即取语言的常项为模型论域的元素, 但这在通常情况下是不成立的。初学者在这种问题上应该小心。

设语言 $ {\mathcal{L}}^{ * } $ 中的非逻辑符号只有一个一元谓词 $ P $ 。下面,我们来看语义学中关于 $ {\left( \forall x\psi \right) }^{\sigma } $ 的计算的基本思想。考虑公式 $ \forall {xPx} $ 和下述模型 $ \mathfrak{A} $ :

论域 : $ A = \{ a, b, c\} $

谓词 : $ {P}^{\mathfrak{A}} = \{ a, b, c\} $

读者也许凭直观就能看出 $ \forall {xPx} $ 应该是真的,但我们现在不去管直观,只看如何根据定义 383 计算出 $ \forall {xPx} $ 的值为真。我们之所以要考虑对个体变项的赋值,是因为我们要把 $ \forall {xPx} $ 的真值 “归结为” 它的子公式 $ {Px} $ 在各种赋值下的真值。

考虑 $ \mathfrak{A} $ 上的任意一个赋值 $ \sigma $ 。 $ \forall {xPx} $ 直观上说的是所有的东西都是 $ {P}^{\sigma } $ (亦即 $ {P}^{\mathfrak{A}} $ )。这里的 “所有的东西”,当然是指 $ A $ 的所有元素,即 $ a, b, c $ 。所以,说所有东西都是 $ {P}^{\sigma } $ ,相当于说, $ a, b, c $ 都有性质 $ {P}^{\sigma } $ ,而这又相当于说, 用 $ a, b, c $ 中的每一个去解释 $ x $ ,都使 $ x $ 的这一解释有性质 $ {P}^{\sigma } $ ,即 $ {Px} $ 在这一解释下是真的。这就是说, 我们有

\[
{x}^{\sigma \left( {x/a}\right) } \in  {P}^{\sigma },{x}^{\sigma \left( {x/b}\right) } \in  {P}^{\sigma },{x}^{\sigma \left( {x/c}\right) } \in  {P}^{\sigma }
\]

从而根据定义 383(ii), 我们有

\[
{\left( Px\right) }^{\sigma \left( {x/a}\right) } = \mathrm{T},{\left( Px\right) }^{\sigma \left( {x/b}\right) } = \mathrm{T},{\left( Px\right) }^{\sigma \left( {x/c}\right) } = \mathrm{T}
\]

进而对每个 $ d \in  A,{\left( Px\right) }^{\sigma \left( {x/d}\right) } = \mathrm{T} $ 。所以根据定义 383(viii), $ {\left( \forall xPx\right) }^{\sigma } = \mathrm{T} $ 。

容易看出,在上述计算中, $ {x}^{\sigma } $ 到底是什么是没有关系的。语义学中关于 $ {\left( \exists x\psi \right) }^{\sigma } $ 的计算的基本思想是类似的。我们来看公式 $ \exists x\left( {{Px} \land  {Qx}}\right) $ 和下述模型 21:

论域: $ A = \{ a, b, c\} $

谓词 : $ {P}^{\mathfrak{A}} = \{ a, b\} ,{Q}^{\mathfrak{A}} = \{ b\} $

考虑 $ \mathfrak{A} $ 上的赋值 $ \sigma \left( {x}^{\sigma }\right. $ 到底是什么并不重要)。要使 $ \exists x\left( {{Px} \land  {Qx}}\right) $ 在 $ \sigma $ 下的值为 $ \mathrm{T} $ ,直观上需要某些 $ {P}^{\sigma } $ 是 $ {Q}^{\sigma } $ (亦即某些 $ {P}^{\mathfrak{A}} $ 是 $ {Q}^{\mathfrak{A}} $ )。“某些”当然是指 $ a, b, c $ 中的。说某些 $ {P}^{\sigma } $ 是 $ {Q}^{\sigma } $ ,相当于说: $ a, b, c $ 中至少有一个可以去解释 $ x $ ,使得在这个解释下, $ {Px} $ 和 $ {Qx} $ 都是真的。易见, $ A $ 中的 $ b $ 恰好既有性质 $ {P}^{\sigma } $ 也有性质 $ {Q}^{\sigma } $ 。

严格地说,根据 $ \sigma $ 的定义 (包括 $ \mathfrak{A} $ 的定义),我们有

\[
{x}^{\sigma \left( {x/b}\right) } = b \in  {P}^{\sigma }\text{ 并且 }{x}^{\sigma \left( {x/b}\right) } = b \in  {Q}^{\sigma },
\]

从而根据定义 $ {383}\left( \mathrm{{ii}}\right) ,{\left( Px\right) }^{\sigma \left( {x/b}\right) } = \mathrm{T} $ 并且 $ {\left( Qx\right) }^{\sigma \left( {x/b}\right) } = \mathrm{T} $ ,进而根据定义 383(iv), $ {\left( Px \land  Qx\right) }^{\sigma \left( {x/b}\right) } = \mathrm{T} $ 。由此可知,对某个 $ d \in  A $ (亦即 $ b $ ), $ ({Px} \land $ $ {Qx}{)}^{\sigma \left( {x/d}\right) } = \mathrm{T} $ ,再运用定义 $ {383}\left( \mathrm{{ix}}\right) $ ,我们得到 $ {\left( \exists x\left( Px \land  Qx\right) \right) }^{\sigma } = \mathrm{T} $ 。

下面我们来看一些计算公式真值的例子。第一个例子中的公式是我们在例 372 中讨论过的公式。

例 387 设语言 $ {\mathcal{L}}^{ * } $ 中的非逻辑符号只有一元谓词 $ P, Q $ 和 $ S $ 。给一个模型 $ \mathfrak{A} $ ,使得 $ \mathfrak{A} \vDash  \forall x\left( {{Px} \rightarrow  {Qx} \land  {Sx}}\right) $ 。

我们可以设计下述模型 $ \mathfrak{A} $ :

论域 : $ A = \{ a, b\} $

谓词 : $ {P}^{\mathfrak{A}} = \{ a\} ,{Q}^{\mathfrak{A}} = {S}^{\mathfrak{A}} = \{ a, b\} $

令 $ \sigma $ 为 $ \mathfrak{A} $ 上的任意赋值。我们证明 $ \sigma  \vDash  \forall x\left( {{Px} \rightarrow  {Qx} \land  {Sx}}\right) $ 。由 $ \mathfrak{A} $ 对谓词的解释和定义 383(ii) 可知,

\[
{\left( Px\right) }^{\sigma \left( {x/a}\right) } = \mathrm{T},\;{\left( Px\right) }^{\sigma \left( {x/b}\right) } = \mathrm{F} \tag{8.7}
\]

\[
{\left( Qx\right) }^{\sigma \left( {x/a}\right) } = \mathrm{T},\;{\left( Sx\right) }^{\sigma \left( {x/a}\right) } = \mathrm{T}
\]

因而根据 (8.7) 和定义 383(iv, vi),

\[
{\left( Px \rightarrow  Qx \land  Sx\right) }^{\sigma \left( {x/a}\right) } = \mathrm{T} \tag{8.8}
\]

\[
{\left( Px \rightarrow  Qx \land  Sx\right) }^{\sigma \left( {x/b}\right) } = \text{ т。 }
\]

因为 $ A = \{ a, b\} $ ,所以由 (8.8) 知对每个 $ d \in  A,{\left( Px \rightarrow  Qx \land  Sx\right) }^{\sigma \left( {x/d}\right) } = \mathrm{T} $ , 再由定义 383(viii) 知

\[
{\left( \forall x\left( Px \rightarrow  Qx \land  Sx\right) \right) }^{\sigma } = \text{ т。 }
\]

至此证明了对每个 $ \mathfrak{A} $ 上的赋值 $ \sigma $ ,都有 $ \sigma  \vDash  \forall x\left( {{Px} \rightarrow  {Qx} \land  {Sx}}\right) $ 。所以,根据定义 $ {385},\mathfrak{A} \vDash  \forall x\left( {{Px} \rightarrow  {Qx} \land  {Sx}}\right) $ 。

例 388 设语言 $ {\mathcal{L}}^{ * } $ 中的非逻辑符号只有一元谓词 $ P $ 和 $ Q $ 以及二元谓词 $ R $ 。给一个模型 $ \mathfrak{A} $ 使得 $ \mathfrak{A} \mathrel{\text{\vDash \not{} }} \phi $ ,其中 $ \phi $ 是下列公式:

\[
\forall x\left( {{Px} \rightarrow  \exists y\left( {{Qy} \land  {Rxy}}\right) }\right)  \rightarrow  \exists x\left( {{Px}\land \forall y\left( {{Qy} \rightarrow  {Rxy}}\right) }\right)
\]

这个例子中的公式是例 374 中讨论过的。我们要做的是, 找一个模型 $ \mathfrak{A} $ 和它上面的赋值 $ \sigma $ ,使得 $ \sigma  \vDash  \forall x\left( {{Px} \rightarrow  \exists y\left( {{Qy} \land  {Rxy}}\right) }\right) $ 并且 $ \sigma  \mathrel{\text{\vDash \not{} }} $ $ \exists x\left( {{Px}\land \forall y\left( {{Qy} \rightarrow  {Rxy}}\right) }\right) $ 。我们可以设计这样一个模型 $ \mathfrak{A} $ :

\[
\text{论域:}A = \{ a\}
\]

\[
\text{谓词:}{P}^{\mathfrak{A}} = \varnothing
\]

这里我们省略了模型中的 $ {Q}^{\mathfrak{A}} $ 和 $ {R}^{\mathfrak{A}} $ 。之所以省略它们,是因为在这个例子中,一旦 $ P $ 被解释为空集,别的谓词的解释就都不重要了 (甚至论域也可以是任意一个非空集)。易见对 $ \mathfrak{A} $ 上的任何赋值 $ \tau $ ,都有 $ \tau  \mathrel{\text{\vDash \not{} }} {Px} $ 。所以,根据定义 383(vi, iv),

对 $ \mathfrak{A} $ 上所有的赋值 $ \tau ,\tau  \vDash  {Px} \rightarrow  \exists y\left( {{Qy} \land  {Rxy}}\right) $ ;(8.9a)

对 $ \mathfrak{A} $ 上所有的赋值 $ \tau ,\tau  \mathrel{\text{\vDash \not{} }} {Px} \land  \forall y\left( {{Qy} \rightarrow  {Rxy}}\right) $ 。(8.9b)

于是我们可以随便挑选一个 $ \mathfrak{A} $ 上的赋值 $ \sigma $ (事实上,当论域 $ A $ 是单元集时, 模型 $ \mathfrak{A} $ 上只有一个赋值)。

根据 (8.9a),对每个 $ d \in  A,\sigma \left( {x/d}\right)  \vDash  {Px} \rightarrow  \exists y\left( {{Qy} \land  {Rxy}}\right) $ ; 进而由定义 383(viii), $ \sigma  \vDash  \forall x\left( {{Px} \rightarrow  \exists y\left( {{Qy} \land  {Rxy}}\right) }\right) $ 。类似地,根据 (8.9b),对每个 $ d \in  A,\sigma \left( {x/d}\right)  \mathrel{\text{\vDash \not{} }} {Px} \land  \forall y\left( {{Qy} \rightarrow  {Rxy}}\right) $ ; 进而由定义 $ {383}\left( \mathrm{{ix}}\right) ,\sigma  \mathrel{\text{\vDash \not{} }} $ $ \exists x\left( {{Px}\land \forall y\left( {{Qy} \rightarrow  {Rxy}}\right) }\right) $ 。在赋值 $ \sigma $ 下, $ \phi $ 的前件真而后件假,所以 $ \sigma  \mathrel{\text{\vDash \not{} }} \phi $ 。 由定义 385 知 $ \mathfrak{A} \mathrel{\text{\vDash \not{} }} \phi $ 。至此完成例 388 的讨论。

从现在起, 我们把定义 382-383 统称为 BSD。上面的例子比较简单。为计算复杂一点的公式的真值, 我们先证明几个命题。下述命题说的是, 对任意赋值 $ \sigma $ ,一个项 $ t $ 在 $ \sigma $ 下的值只依赖于 $ \sigma $ 对出现在 $ t $ 中的符号的解释。

命题 389 设 $ t $ 为任意项,设 $ \sigma $ 和 $ \tau $ 分别为模型 $ \mathfrak{A} = \langle A, I\rangle $ 和 $ {\mathfrak{A}}^{\prime } = \left\langle  {A,{I}^{\prime }}\right\rangle $ 上的任意赋值,并设对 $ t $ 中出现的所有 $ {\mathcal{L}}^{ * } $ -符号 $ X $ 都有 $ {X}^{\sigma } = {X}^{\tau } $ 。我们有: $ {t}^{\sigma } = {t}^{\tau } $ 。

证明 施归纳于 $ t $ 的复杂度。如果 $ t $ 是个体常项或个体变项,由题设知 $ {t}^{\sigma } = {t}^{\tau } $ 。设 $ t = \mathbf{f}{t}_{0}\ldots {t}_{n} $ 。由题设、BSD 和归纳假设,

\[
{\left( \mathbf{f}{t}_{0}\ldots {t}_{n}\right) }^{\sigma } = {\mathbf{f}}^{\sigma }\left( {{t}_{0}^{\sigma },\ldots ,{t}_{n}^{\sigma }}\right)
\]

\[
= {\mathbf{f}}^{\tau }\left( {{t}_{0}^{\tau },\ldots ,{t}_{n}^{\tau }}\right)
\]

\[
\begin{array}{l}  = {\left( \mathbf{f}{t}_{0}\ldots {t}_{n}\right) }^{\tau } \end{array}
\]

亦即 $ {t}^{\sigma } = {t}^{\tau }{}_{ \circ  }^{10}\mathrm{O} $

下述命题说的是,对任意赋值 $ \sigma $ ,一个公式 $ \phi $ 在 $ \sigma $ 下的真值只依赖于 $ \sigma $ 对出现在 $ \phi $ 中的非逻辑符号和自由出现在 $ \phi $ 中的个体变项的解释。(我们约定: 自由出现在 $ \phi $ 中的个体变项就是在 $ \phi $ 中有自由出现的个体变项。)

命题 390 设 $ \phi $ 为任意公式,设 $ \sigma $ 和 $ \tau $ 为任意模型 $ \mathfrak{A} = \langle A, I\rangle $ 和 $ {\mathfrak{A}}^{\prime }\; = \;\langle A,{I}^{\prime }\rangle $ 上的赋值,并设对每个出现在 $ \phi $ 中的非逻辑符号 $ X $ 都有 $ {X}^{\sigma } = {X}^{\tau } $ ,且对每个自由出现在 $ \phi $ 中的个体变项 $ y $ 都有 $ {y}^{\sigma } = {y}^{\tau } $ 。我们有: $ {\phi }^{\sigma } = {\phi }^{\tau } $ (亦即 $ \sigma  \vDash  \phi $ 当且仅当 $ \tau  \vDash  \phi $ )。

证明 施归纳于 $ \phi $ 的复杂度。设 $ \phi  = P{t}_{0}\ldots {t}_{n} $ 。如果 $ \sigma  \vDash  \phi $ ,那么根据BSD, $ \left\langle  {{t}_{0}^{\sigma },\ldots ,{t}_{n}^{\sigma }}\right\rangle   \in  {P}^{\sigma } $ ,从而由命题 389 知 $ \left\langle  {{t}_{0}^{\tau },\ldots ,{t}_{n}^{\tau }}\right\rangle   \in  {P}^{\tau } $ ,于是再运用BSD得到 $ \tau  \vDash  \phi $ 。类似可证,如果 $ \tau  \vDash  \phi $ 那么 $ \sigma  \vDash  \phi $ 。设 $ \phi $ 是 $ s \equiv  t $ 。 与上述情况相仿,如果 $ \sigma  \vDash  \phi $ ,那么由 $ \mathrm{{BSD}} $ 知 $ {s}^{\sigma } = {t}^{\sigma } $ ,再根据命题 389 知 $ {s}^{\tau } = {t}^{\tau } $ ,最后由 BSD 得到 $ \tau  \vDash  \phi $ 。类似可证,如果 $ \tau  \vDash  \phi $ 那么 $ \sigma  \vDash  \phi $ 。

如果 $ \phi $ 是 $ \sim  \psi ,\psi  \vee  \chi ,\psi  \land  \chi ,\psi  \rightarrow  \chi $ 或 $ \psi  \leftrightarrow  \chi $ ,由归纳假设和 BSD 易得 $ \sigma  \vDash  \phi $ 当且仅当 $ \tau  \vDash  \phi $ 。

设 $ \phi  = \forall {x\psi } $ 。根据 BSD,如果 $ \sigma  \vDash  \phi $ ,那么对每个 $ a \in  A,\sigma \left( {x/a}\right)  \vDash  \psi $ 。 考虑任意 $ a \in  A $ 。易见,自由出现在 $ \psi $ 中的个体变项,如果不是 $ x $ ,一定自由出现在 $ \phi $ 中。所以由题设和定义 381 知,对自由出现在 $ \psi $ 中的每一个体变项 $ y,{y}^{\sigma \left( {x/a}\right) } = {y}^{\tau \left( {x/a}\right) } $ ,因而由归纳假设, $ \tau \left( {x/a}\right)  \vDash  \psi $ 。由此可知,如果 $ \sigma  \vDash  \phi $ ,那么对每个 $ a \in  A,\tau \left( {x/a}\right)  \vDash  \psi $ ; 于是根据 BSD 有 $ \tau  \vDash  \forall {x\psi } $ ,即 $ \tau  \vDash  \phi $ 。类似可证,如果 $ \tau  \vDash  \forall {x\psi } $ 则 $ \sigma  \vDash  \forall {x\psi } $ 。 $ \phi  = \exists {x\psi } $ 的情况留作习题。

插议:命题 389-390有时称为 “合同引理”。注意:两个命题中的模型 $ \mathfrak{A} $ 和 $ {\mathfrak{A}}^{\prime } $ 不必是同一个语言的模型。假设 $ \mathfrak{A} $ 是 $ \mathcal{L} $ -模型, $ {\mathfrak{A}}^{\prime } $ 是 $ {\mathcal{L}}^{\prime } $ -模型,而 $ \mathfrak{A} $ 和 $ {\mathfrak{A}}^{\prime } $ 对 $ \mathcal{L} $ 和 $ {\mathcal{L}}^{\prime } $ 共有的非逻辑符号的解释相同。我们同样有: 对所有既是 $ \mathcal{L} $ -公式又是 $ {\mathcal{L}}^{\prime } $ -公式的 $ \phi $ ,对所有 $ \mathfrak{A} $ 上赋值 $ \sigma $ 和 $ {\mathfrak{A}}^{\prime } $ 上赋值 $ \tau $ ,只要 $ \sigma $ 和 $ \tau $ 对自由出现在 $ \phi $ 中的个体变项的指派也相同,那么 $ \sigma  \vDash  \phi $ 当且仅当 $ \tau  \vDash  \phi $ 。

把 $ {Rxy} $ 看作 “ $ x < y $ ”,读者立刻就明白上述几个公式在 $ \mathfrak{A} $ 上是真的。但为了掌握好相关的语义概念, 我们还是 (最后一次) 一步步地把公式的值 “算” 出来。读者在上述练习后对 BSD 的内容已比较熟悉, 我们在运用BSD时可以不提它。

令 $ \sigma $ 为 $ \mathfrak{A} $ 上的任意赋值。根据命题 392,我们只需证明 $ \sigma $ 满足上述几个句子。

### 8.7 可满足性、逻辑蕴涵、逻辑等值和有效式

这一节我们讨论几个基本的语义概念: 可满足性、逻辑蕴涵、逻辑等值和逻辑有效式等。这些是谓词逻辑中重要的语义概念, 类似于命题逻辑中的可满足性、重言蕴涵、重言等值和重言式等概念。

#### 8.7.1 可满足性

定义 395 一个 $ {\mathcal{L}}^{ * } $ -公式集 $ \Gamma $ 是可满足的当且仅当存在某个赋值 $ \sigma $ 使得 $ \sigma  \vDash  \Gamma $ 。一个 $ {\mathcal{L}}^{ * } $ -公式 $ \phi $ 是可满足的当且仅当 $ \{ \phi \} $ 是可满足的。

定义 396 一个 $ {\mathcal{L}}^{ * } $ -公式集 $ \Gamma $ 是不可满足的当且仅当它不是可满足的。

当一个模型 $ \mathfrak{A} $ 满足 $ \Gamma $ (即 $ \mathfrak{A} \vDash  \Gamma $ ),我们称 $ \mathfrak{A} $ 为 $ \Gamma $ 的模型。当 $ \Gamma  = \{ \phi \} ,\Gamma $ 的模型也称为 $ \phi $ 的模型。如果存在某个模型 $ \mathfrak{A} $ 使得 $ \mathfrak{A} \vDash  \Gamma \left( {\mathfrak{A} \vDash  \phi }\right) $ ,我们也说 $ \Gamma $ (或 $ \phi $ ) 有模型。句子集合常称为理论。由命题 392 易见,一个理论可满足当且仅当它有模型。

插议:一个理论的一致性常被理解为它的可满足性, 也就是说被理解为它有模型。这没问题, 只要 “有模型” 没有理解错。很多时候, 某些理论的提倡者或研究者, 因以刻画某个对象为目标, 常常称该对象为理论的 “预期模型” 或 “预期解释” (the intended model/interpretation), 也往往说该理论有预期模型。初学者应注意, 理论有预期模型和上面说的理论有模型是两回事, 不可以混为一谈。有模型的理论是一致的, 但有预期模型的理论却未必是一致的。因为第一, 理论的预期模型未必是理论的模型; 第二, 预期模型有时很模糊, 甚至可能不是模型。换句话说, 研究对象的存在并不能保证为了刻画该对象而建立的理论的一致性。

前面讨论过的例 387、388、393 和 394,都是可满足公式 (句子) 的例子。 下面我们看一个不可满足的公式集的例子。

例 397 设语言 $ {\mathcal{L}}^{ * } $ 中的非逻辑符号只有一个二元谓词 $ R $ 。令 $ \Gamma $ 为下列句子的集合:

\[
\forall x \sim  {Rxx}
\]

\[
\forall x\exists {yRxy}
\]

\[
\forall x\forall y\forall z\left( {{Rxy} \land  {Rxz} \rightarrow  {Ryz}}\right)
\]

证明 $ \Gamma $ 不可满足。

证明 设 $ \mathfrak{A} = \langle A, I\rangle $ 为任意模型, $ \sigma $ 为 $ \mathfrak{A} $ 上的任意赋值。假定 $ \sigma $ 满足后两个公式。以下我们证明: $ \sigma $ 不满足第一个公式。

由于 $ A \neq  \varnothing $ ,我们设 $ a \in  A $ 。因为 $ \sigma  \vDash  \forall x\exists {yRxy} $ ,所以 $ \sigma \left( {x/a}\right)  \vDash  \exists {yRxy} $ , 于是有某个 $ b \in  A $ 使得 $ \langle a, b\rangle  \in  {R}^{\mathfrak{A}} $ 。由于 $ \sigma  \vDash  \forall x\forall y\forall z\left( {{Rxy} \land  {Rxz} \rightarrow  {Ryz}}\right) $ , 我们有 $ \sigma \left( {x/a}\right) \left( {y/b}\right) \left( {z/b}\right)  \vDash  {Rxy} \land  {Rxz} \rightarrow  {Ryz} $ ; 而由于 $ \langle a, b\rangle  \in  {R}^{\mathfrak{A}} $ ,我们有 $ \sigma \left( {x/a}\right) \left( {y/b}\right) \left( {z/b}\right)  \vDash  {Rxy} \land  {Rxz} $ 。因此, $ \sigma \left( {x/a}\right) \left( {y/b}\right) \left( {z/b}\right)  \vDash  {Ryz} $ ,从而根据命题 391,我们有 $ \sigma \left( {y/b}\right) \left( {z/b}\right)  \vDash  {Ryz} $ ,再由 $ \mathrm{{BSD}} $ 得到 $ \langle b, b\rangle  \in  {R}^{\mathfrak{A}} $ 。由此可知, $ \sigma \left( {x/b}\right)  \vDash  {Rxx} $ ,从而 $ \sigma \left( {x/b}\right)  \mathrel{\text{\vDash \not{} }}  \sim  {Rxx} $ ,所以 $ \sigma  \mathrel{\text{\vDash \not{} }} \forall x \sim  {Rxx} $ 。

#### 8.7.2 逻辑蕴涵 (逻辑后承)

定义 398 设 $ \Gamma $ 为任意 $ {\mathcal{L}}^{ * } $ -公式集, $ \phi $ 为任意 $ {\mathcal{L}}^{ * } $ -公式。 $ \Gamma $ 逻辑蕴涵 $ \phi $ (记为 $ \Gamma  \vDash  \phi $ ) 当且仅当对每个赋值 $ \sigma $ ,如果 $ \sigma  \vDash  \Gamma $ 则 $ \sigma  \vDash  \phi 。\phi $ 是 $ \Gamma $ 的逻辑后承当且仅当 $ \Gamma  \vDash  \phi $ 。我们用 $ \Gamma ,{\phi }_{0},...,{\phi }_{n} \vDash  \psi $ 表示 $ \Gamma  \cup  \{ {\phi }_{0},...,{\phi }_{n}\}  \vDash  \psi $ ,用 ⊨⇐ $ \phi $ 表示 $ \varnothing  \vDash  \phi $ 。

我们看几个简单的逻辑蕴涵的例子。

例 399 对所有公式 $ \phi ,\psi $ 和 $ \chi $ ,对所有个体变项 $ x,\forall x\left( {\phi  \rightarrow  \psi }\right) ,\forall x(\psi  \rightarrow $ $ \chi ) \vDash  \forall x\left( {\phi  \rightarrow  \chi }\right) 。 $

证明 令 $ \mathfrak{A} = \langle A, I\rangle $ 为任意模型,并令 $ \sigma $ 为 $ \mathfrak{A} $ 上的任意赋值。设 $ \sigma  \vDash $ $ \forall x\left( {\phi  \rightarrow  \psi }\right) $ 并且 $ \sigma  \vDash  \forall x\left( {\psi  \rightarrow  \chi }\right) $ 。令 $ a $ 为 $ A $ 的任意元素。由假设和 BSD 知 $ \sigma \left( {x/a}\right)  \vDash  \phi  \rightarrow  \psi $ 且 $ \sigma \left( {x/a}\right)  \vDash  \psi  \rightarrow  \chi $ ,进而有 $ \sigma \left( {x/a}\right)  \vDash  \phi  \rightarrow  \chi $ 。既然 $ a $ 是 $ A $ 的任意元素,我们有: 对所有 $ a \in  A,\sigma \left( {x/a}\right)  \vDash  \phi  \rightarrow  \chi $ ,于是有 $ \sigma  \vDash  \forall x\left( {\phi  \rightarrow  \chi }\right) $ 。

例 400 $ \forall x\left( {\phi  \rightarrow  \psi }\right) ,\phi  \vDash  \forall {x\psi } $ ,其中 $ x $ 不在 $ \phi $ 中自由出现。

证明 设 $ \phi $ 和 $ \psi $ 为任意公式,其中 $ x $ 不在 $ \phi $ 中自由出现,设 $ \mathfrak{A} = \langle A, I\rangle $ 为任意模型,并设 $ \sigma $ 为 $ \mathfrak{A} $ 上的任意赋值,使得 $ \sigma  \vDash  \forall x\left( {\phi  \rightarrow  \psi }\right) $ 并且 $ \sigma  \vDash  \phi $ 。对每个 $ a \in  A $ ,由 BSD 知 $ \sigma \left( {x/a}\right)  \vDash  \phi  \rightarrow  \psi $ ,而由命题 391 知 $ \sigma \left( {x/a}\right)  \vDash  \phi $ ,进而 $ \sigma \left( {x/a}\right)  \vDash  \psi $ 。所以, $ \sigma  \vDash  \forall {x\psi } $ 。

例 401 $ \forall x\left( {\phi  \rightarrow  \psi }\right) ,\exists {x\phi } \vDash  \exists {x\psi } $

证明 设 $ \phi $ 和 $ \psi $ 为任意公式,设 $ \mathfrak{A} = \langle A, I\rangle $ 为任意模型,并设 $ \sigma $ 为 $ \mathfrak{A} $ 上的任意赋值,使得 $ \sigma  \vDash  \forall x\left( {\phi  \rightarrow  \psi }\right) $ 且 $ \sigma  \vDash  \exists {x\phi } $ 。根据BSD,对所有的 $ a \in  A,\sigma \left( {x/a}\right)  \vDash  \phi  \rightarrow  \psi $ ,而且对某个 $ b \in  A,\sigma \left( {x/b}\right)  \vDash  \phi $ ,因而有 $ \sigma \left( {x/b}\right)  \vDash  \psi $ ,所以 $ \sigma  \vDash  \exists {x\psi } $ 。

#### 8.7.3 逻辑等值

定义 402 对任意 $ {\mathcal{L}}^{ * } $ -公式 $ \phi $ 和 $ \psi ,\phi $ 与 $ \psi $ 逻辑等值当且仅当对每个赋值 $ \sigma ,{\phi }^{\sigma } = {\psi }^{\sigma }\left( {\sigma  \vDash  \phi \text{ 当且仅当 }\sigma  \vDash  \psi }\right) $ 。

例 403 对任意公式 $ \phi $ 和任意个体变项 $ x $ ,下列各组中的公式逻辑等值:

(i) $ \exists {x\phi } $ 和 $ \sim  \forall x \sim  \phi $

(ii) $ \forall {x\phi } $ 和 $ \sim  \exists x \sim  \phi $

(iii) $ \sim  \exists {x\phi } $ 和 $ \forall x \sim  \phi $

(iv) $ \sim  \forall {x\phi } $ 和 $ \exists x \sim  \phi $

证明 令 $ \sigma $ 为任意模型 $ \mathfrak{A} = \langle A, I\rangle $ 上的任意赋值。(i) 根据BSD,易见下列等价式成立:

$ \sigma  \vDash  \exists {x\phi } $ iff 存在某个 $ a \in  A $ 使得 $ \sigma \left( {x/a}\right)  \vDash  \phi $

iff 存在某个 $ a \in  A $ 使得 $ \sigma \left( {x/a}\right)  \mathrel{\text{\vDash \not{} }}  \sim  \phi $

iff 并非对每个 $ a \in  A $ 都有 $ \sigma \left( {x/a}\right)  \vDash   \sim  \phi $

iff $ \sigma  \mathrel{\text{\vDash \not{} }} \forall x \sim  \phi $

iff $ \sigma  \vDash   \sim  \forall x \sim  \phi $

(ii)-(iv) 留作习题。

例 404 对任意公式 $ \phi $ 和 $ \psi $ ,及任意个体变项 $ x,\forall x\left( {\phi  \land  \psi }\right) $ 和 $ \forall {x\phi } \land  \forall {x\psi } $ 逻辑等值。

证明 令 $ \mathfrak{A} = \langle A, I\rangle $ 为任意模型,并令 $ \sigma $ 为 $ \mathfrak{A} $ 上的任意赋值。设 $ \sigma  \vDash $ $ \forall x\left( {\phi  \land  \psi }\right) $ 。对每个 $ a \in  A $ ,因为 $ \sigma \left( {x/a}\right)  \vDash  \phi  \land  \psi $ ,所以 $ \sigma \left( {x/a}\right)  \vDash  \phi $ 。 根据BSD, $ \sigma  \vDash  \forall {x\phi } $ 。同理可知, $ \sigma  \vDash  \forall {x\psi } $ ,于是有 $ \sigma  \vDash  \forall {x\phi } \land  \forall {x\psi } $ 。设 $ \sigma  \vDash  \forall {x\phi } \land  \forall {x\psi } $ 。于是有 $ \sigma  \vDash  \forall {x\phi } $ 且 $ \sigma  \vDash  \forall {x\psi } $ 。对每个 $ a \in  A,\sigma \left( {x/a}\right)  \vDash  \phi $ 且 $ \sigma \left( {x/a}\right)  \vDash  \psi $ ,进而有 $ \sigma \left( {x/a}\right)  \vDash  \phi  \land  \psi $ 。根据 BSD, $ \sigma  \vDash  \forall x\left( {\phi  \land  \psi }\right) $ 。■

例 405 对任意公式 $ \phi $ 和任意个体变项 $ x $ ,如果 $ x $ 不在 $ \phi $ 中自由出现,那么 $ \forall {x\phi }\text{、}\phi $ 和 $ \exists {x\phi } $ 逻辑等值。

证明 令 $ \mathfrak{A} = \langle A, I\rangle $ 为任意模型,并令 $ \sigma $ 为 $ \mathfrak{A} $ 上的任意赋值。如果 $ \sigma  \vDash  \forall {x\phi } $ ,那么显然有 $ \sigma  \vDash  \phi $ ,进而有 $ \sigma  \vDash  \exists {x\phi } $ 。设 $ \sigma  \vDash  \exists {x\phi } $ 。根据BSD, 存在某个 $ b \in  A $ 使得 $ \sigma \left( {x/b}\right)  \vDash  \phi $ 。因为 $ x $ 不在 $ \phi $ 中自由出现,所以由命题 391 知, $ \sigma  \vDash  \phi $ 。类似地,对每个 $ a \in  A $ ,因为 $ \sigma  \vDash  \phi $ 且 $ x $ 不在 $ \phi $ 中自由出现,所以由命题 391 知, $ \sigma \left( {x/a}\right)  \vDash  \phi $ 。所以 $ \sigma  \vDash  \forall {x\phi } $ 。

例 406 设 $ \phi $ 和 $ \psi $ 为任意公式,并设 $ x $ 不在 $ \phi $ 中自由出现。下列命题成立:

(i) $ \forall x\left( {\phi  \vee  \psi }\right) $ 和 $ \phi  \vee  \forall {x\psi } $ 逻辑等值。

(ii) $ \exists x\left( {\phi  \land  \psi }\right) $ 和 $ \phi  \land  \exists {x\psi } $ 逻辑等值。

(iii) $ \forall x\left( {\phi  \rightarrow  \psi }\right) $ 和 $ \phi  \rightarrow  \forall {x\psi } $ 逻辑等值。

(iv) $ \exists x\left( {\phi  \rightarrow  \psi }\right) $ 和 $ \phi  \rightarrow  \exists {x\psi } $ 逻辑等值。

(v) $ \forall x\left( {\psi  \rightarrow  \phi }\right) $ 和 $ \exists {x\psi } \rightarrow  \phi $ 逻辑等值。

(vi) $ \exists x\left( {\psi  \rightarrow  \phi }\right) $ 和 $ \forall {x\psi } \rightarrow  \phi $ 逻辑等值。

证明 (i) 令 $ \mathfrak{A} = \langle A, I\rangle $ 为任意模型,并且令 $ \sigma $ 为 $ \mathfrak{A} $ 上的任意赋值。设 $ \sigma  \vDash  \forall x\left( {\phi  \vee  \psi }\right) $ 。如果 $ \sigma  \vDash  \phi $ ,那么当然有 $ \sigma  \vDash  \phi  \vee  \forall {x\psi } $ 。假设 $ \sigma  \mathrel{\text{\vDash \not{} }} \phi $ 。我们知道: 对每个 $ a \in  A $ ,或者 $ \sigma \left( {x/a}\right)  \vDash  \phi $ 或者 $ \sigma \left( {x/a}\right)  \vDash  \psi $ ,而既然 $ \sigma  \mathrel{\text{\vDash \not{} }} \phi $ ,由命题 391 知 $ \sigma \left( {x/a}\right)  \mathrel{\text{\vDash \not{} }} \phi $ 。所以,对每个 $ a \in  A $ ,一定有 $ \sigma \left( {x/a}\right)  \vDash  \psi $ 。由此可知, $ \sigma  \vDash  \forall {x\psi } $ ,进而 $ \sigma  \vDash  \phi  \vee  \forall {x\psi } $ 。

设 $ \sigma  \vDash  \phi  \vee  \forall {x\psi } $ 。如果 $ \sigma  \vDash  \phi $ ,那么根据命题 391,对每个 $ a \in  A,\sigma \left( {x/a}\right)  \vDash $ $ \phi $ ,从而 $ \sigma \left( {x/a}\right)  \vDash  \phi  \vee  \psi $ ; 进而有 $ \sigma  \vDash  \forall x\left( {\phi  \vee  \psi }\right) $ 。如果 $ \sigma  \vDash  \forall {x\psi } $ ,那么对每个 $ a \in  A,\sigma \left( {x/a}\right)  \vDash  \psi $ ,从而 $ \sigma \left( {x/a}\right)  \vDash  \phi  \vee  \psi $ ; 进而有 $ \sigma  \vDash  \forall x\left( {\phi  \vee  \psi }\right) $ 。

(ii)-(vi) 留作习题。

#### 8.7.4 逻辑有效式

定义 407 设 $ \phi $ 为任意 $ {\mathcal{L}}^{ * } $ -公式。如果对所有赋值 $ \sigma $ 都有 $ \sigma  \vDash  \phi $ ,则称 $ \phi $ 是 (逻辑) 有效式 (或逻辑真理)。

例 408 下列公式都是有效式,其中 $ \mathbf{c} $ 是个体常项, $ P $ 是一元谓词, $ R $ 是二元谓词,并且 $ \phi $ 和 $ \psi $ 是任意公式:

(i) $ \forall {xR}\mathbf{c}x \rightarrow  \exists {xR}\mathbf{c}x $

(ii) $ \forall x\left( {\phi  \rightarrow  \psi }\right)  \rightarrow  \left( {\forall {x\phi } \rightarrow  \forall {x\psi }}\right) $

(iii) $ \forall x\forall y\left( {x \equiv  y \rightarrow  y \equiv  x}\right) $

(iv) $ \forall x\forall y\forall z\left( {x \equiv  y \land  y \equiv  z \rightarrow  x \equiv  z}\right) $

(v) $ \forall x\left( {\phi  \rightarrow  \psi }\right)  \rightarrow  \left( {\exists {x\phi } \rightarrow  \exists {x\psi }}\right) $

(vi) $ \forall x\left( {\phi  \land  \psi }\right)  \leftrightarrow  \forall {x\phi } \land  \forall {x\psi } $

(vii) $ \forall x\left( {\phi  \leftrightarrow  \psi }\right)  \rightarrow  \left( {\forall {x\phi } \leftrightarrow  \forall {x\psi }}\right) $

证明 (i) 对任意模型 $ \mathfrak{A} = \langle A, I\rangle $ 上的任意赋值 $ \sigma $ ,如果 $ \sigma  \vDash  \forall {xR}\mathbf{c}x $ ,那么对每个 $ b \in  A $ ,都有 $ \sigma \left( {x/b}\right)  \vDash  R\mathbf{c}x $ ; 由于 $ A \neq  \varnothing $ ,所以存在 $ a \in  A $ ,从而 $ \sigma \left( {x/a}\right)  \vDash  R\mathbf{c}x $ ,进而 $ \sigma  \vDash  \exists {xR}\mathbf{c}x $ 。

(ii) 对任意模型 $ \mathfrak{A} = \langle A, I\rangle $ 上的任意赋值 $ \sigma $ ,如果 $ \sigma  \vDash  \forall x\left( {\phi  \rightarrow  \psi }\right) $ 且 $ \sigma  \vDash  \forall {x\phi } $ ,那么对每个 $ a \in  A $ ,都有 $ \sigma \left( {x/a}\right)  \vDash  \phi  \rightarrow  \psi $ 且 $ \sigma \left( {x/a}\right)  \vDash  \phi $ ,所以对每个 $ a \in  A $ 都有 $ \sigma \left( {x/a}\right)  \vDash  \psi $ ,进而 $ \sigma  \vDash  \forall {x\psi } $ 。

(iii)-(vii) 留作习题。

例 409 对所有项 $ t $ 和个体变项 $ x $ ,如果 $ x $ 不在 $ t $ 中出现,那么 $ \exists x\left( {t \equiv  x}\right) $ 是有效式。

证明 设 $ x $ 不在 $ t $ 中出现。令 $ \mathfrak{A} = \langle A, I\rangle $ 为任意模型,令 $ \sigma $ 为 $ \mathfrak{A} $ 上的任意赋值,并令 $ {\sigma }^{\prime } = \sigma \left( {x/{t}^{\sigma }}\right) $ 。我们知道 $ {x}^{{\sigma }^{\prime }} = {t}^{\sigma } \in  A $ 。因为 $ x $ 不在 $ t $ 中出现,所以由命题 389 知 $ {t}^{\sigma } = {t}^{{\sigma }^{\prime }} $ ,进而有 $ {t}^{{\sigma }^{\prime }} = {x}^{{\sigma }^{\prime }} $ 。根据 BSD,这意味着 $ {\sigma }^{\prime } \vDash  t \equiv  x $ ,亦即 $ \sigma \left( {x/{t}^{\sigma }}\right)  \vDash  t \equiv  x $ ,所以有 $ \sigma  \vDash  \exists x\left( {t \equiv  x}\right) $ 。∎

注意: 如果允许 $ x $ 在 $ t $ 中出现,那么 $ \exists x\left( {t \equiv  x}\right) $ 不见得是有效式。由例 409 知,对每个闭项 $ t,\exists x\left( {t \equiv  x}\right) $ 是有效式; 特别地,对每一个体常项 $ \mathbf{c},\exists x\left( {\mathbf{c} \equiv  x}\right) $ 是有效式。

插议: 有些人说 $ \exists x\left( {\mathbf{c} \equiv  x}\right) $ 不是有效的,有些 “专家” 甚至断言:“用符号不能表示‘歌德存在’”。学过这个例子后可不能再盲从“专家”了。

例 410 对每个一元谓词 $ F $ 及个体变项 $ x $ 和 $ y,\exists x\left( {{Fx} \rightarrow  \forall {yFy}}\right) $ 是有效式。

证明 令 $ \mathfrak{A} = \langle A, I\rangle $ 为任意模型,且令 $ \sigma $ 为 $ \mathfrak{A} $ 上的任意赋值。根据BSD, 对每一个体变项 $ z $ 和每个 $ c \in  A $ ,

\[
\sigma \left( {z/c}\right)  \vDash  {Fz}\text{当且仅当}c \in  {F}^{\mathfrak{A}}\text{。} \tag{8.15}
\]

易见,或者 $ {F}^{\mathfrak{A}} = A $ 或者 $ {F}^{\mathfrak{A}} \neq  A $ 。设 $ {F}^{\mathfrak{A}} = A $ 。显然,对每个 $ a \in  A $ 都有 $ a \in  {F}^{\mathfrak{A}} $ ,进而由 (8.15) 知,对每个 $ a \in  A $ 都有 $ \sigma \left( {y/a}\right)  \vDash  {Fy} $ ,于是有 $ \sigma  \vDash  \forall {yFy} $ 。由此易见 $ \sigma  \vDash  {Fx} \rightarrow  \forall {yFy} $ ,进而由 $ \mathrm{{BSD}} $ 知 $ \sigma  \vDash  \exists x\left( {{Fx} \rightarrow  \forall {yFy}}\right) $ 。 设 $ {F}^{\mathfrak{A}} \neq  A $ 。因为 $ {F}^{\mathfrak{A}} \subset  A $ ,所以存在 $ b \in  A $ 而 $ b \notin  {F}^{\mathfrak{A}} $ 。由 (8.15) 知 $ \sigma \left( {x/b}\right)  \mathrel{\text{\vDash \not{} }} $ $ {Fx} $ ,所以 $ \sigma \left( {x/b}\right)  \vDash  {Fx} \rightarrow  \forall {yFy} $ ,进而由 $ \mathrm{{BSD}} $ 知 $ \sigma  \vDash  \exists x\left( {{Fx} \rightarrow  \forall {yFy}}\right) $ 。∎

#### 8.7.5 基本语义概念的简单运用

下述命题 411-413 中绝大部分命题与 §§3.3-3.4 中的部分命题或 §3.10 中的部分习题相似。证明留作习题。

命题 411 对所有公式集 $ \Gamma $ 和 $ \Delta $ ,以及所有公式 $ \phi ,\psi ,{\phi }_{0},\ldots ,{\phi }_{n} $ ,下述命题成立:

(i) 如果 $ \phi  \in  \Gamma $ 那么 $ \Gamma  \vDash  \phi $ 。

(ii) $ \phi ,\phi  \rightarrow  \psi  \vDash  \psi $ 。

(iii) 如果 $ \Gamma $ 不可满足,那么对每一个公式 $ \phi ,\Gamma  \vDash  \phi $ 。

(iv) 如果 $ \phi $ 是有效式,那么 $ \Gamma  \vDash  \phi $ 。

(v) 如果 $ \Gamma  \vDash  \phi $ 并且 $ \phi $ 与 $ \psi $ 逻辑等值,那么 $ \Gamma  \vDash  \psi $ 。

(vi) $ \Gamma ,\phi  \vDash  \psi $ 当且仅当 $ \Gamma  \vDash  \phi  \rightarrow  \psi $ 。

(vii) $ \Gamma ,\phi  \vDash  \psi $ 当且仅当 $ \Gamma , \sim  \psi  \vDash   \sim  \phi $ 。

(viii) $ \Gamma  \cup  \{ \phi \} $ 不可满足当且仅当 $ \Gamma  \vDash   \sim  \phi $ ,并且 $ \Gamma  \cup  \{  \sim  \phi \} $ 不可满足当且仅当 $ \Gamma  \vDash  \phi $ 。

(ix) $ \Gamma  \cup  \{ \phi \} $ 可满足当且仅当 $ \Gamma  \nvDash   \sim  \phi $ ,并且 $ \Gamma  \cup  \{  \sim  \phi \} $ 可满足当且仅当 $ \Gamma  \mathrel{\text{\vDash \not{} }} \phi $ 。

(x) $ \phi $ 与 $ \psi $ 逻辑等值当且仅当 $ \phi  \vDash  \psi $ 并且 $ \psi  \vDash  \phi $ 。

(xi) 如果 $ \Gamma ,{\phi }_{0},\ldots ,{\phi }_{n} \vDash  \psi $ 并且对所有 $ i \leq  n,\Delta  \vDash  {\phi }_{i} $ ,那么 $ \Gamma  \cup  \Delta  \vDash  \psi $ 。

(xii) 如果 $ \Gamma  \vDash  \phi $ 且 $ \phi  \vDash  \psi $ ,那么 $ \Gamma  \vDash  \psi $ 。

(xiii) 如果对每个 $ i \leq  n $ 都有 $ \Gamma  \vDash  {\phi }_{i} $ ,那么 $ \Gamma  \vDash  {\phi }_{0} \land  \cdots  \land  {\phi }_{n} $ 。

(xiv) $ \Gamma ,{\phi }_{0},\ldots ,{\phi }_{n} \vDash  \psi $ 当且仅当 $ \Gamma ,{\phi }_{0} \land  \cdots  \land  {\phi }_{n} \vDash  \psi $ 。

命题 412 令 $ \phi $ 和 $ \psi $ 为任意公式。我们有:

(i) $ \phi  \land  \psi $ 是有效式当且仅当 $ \phi $ 是有效式并且 $ \psi $ 是有效式。

(ii) 如果 $ \phi $ 或 $ \psi $ 是有效式,那么 $ \phi  \vee  \psi $ 是有效式; 反之不成立。

(iii) 如果 $ \phi  \rightarrow  \psi $ 是有效式,那么,如果 $ \phi $ 是有效式则 $ \psi $ 是有效式; 反之不成立。

(iv) 如果 $ \phi  \leftrightarrow  \psi $ 是有效式,那么, $ \phi $ 是有效式当且仅当 $ \psi $ 是有效式; 反之不成立。

(v) $ \phi  \leftrightarrow  \psi $ 是有效式当且仅当 $ \phi  \rightarrow  \psi $ 和 $ \psi  \rightarrow  \phi $ 都是有效式。

(vi) $ \parallel \phi \parallel $ 是有效式当且仅当 $ \forall {x\phi } $ 是有效式。

命题 413 令 $ \phi ,{\phi }_{0},\ldots ,{\phi }_{n} $ 和 $ \psi $ 为任意公式。我们有:

(i) $ \phi $ 是有效式当且仅当 $ \vDash  \phi $ (即 $ \varnothing  \vDash  \phi $ )。

(ii) $ \phi  \vDash  \psi $ 当且仅当 $ \phi  \rightarrow  \psi $ 是有效式。

(iii) $ {\phi }_{0},\ldots ,{\phi }_{n} \vDash  \psi $ 当且仅当 $ {\phi }_{0} \rightarrow  \left( {\cdots  \rightarrow  \left( {{\phi }_{n} \rightarrow  \psi }\right) \cdots }\right) $ 是有效式。

(iv) $ \phi $ 逻辑等值于 $ \psi $ 当且仅当 $ \phi  \leftrightarrow  \psi $ 是有效式。

命题 414 对任意公式集 $ \Gamma $ ,任意公式 $ \phi $ 和任意个体变项 $ x $ ,如果 $ \Gamma  \vDash  \phi $ 且 $ x $ 不在 $ \Gamma $ 中自由出现,那么 $ \Gamma  \vDash  \forall {x\phi } $ ; 特别地,如果 $ \vDash  \phi $ 则 $ \vDash  \forall {x\phi } $ 。

证明 设 $ \Gamma  \vDash  \phi $ 且 $ x $ 不在 $ \Gamma $ 中自由出现。令 $ \mathfrak{A} = \langle A, I\rangle $ 为任意模型并令 $ \sigma $ 为 $ \mathfrak{A} $ 上的任意赋值。假设 $ \sigma  \vDash  \Gamma $ 。(以下证明 $ \sigma  \vDash  \forall {x\phi } $ )。考虑任意 $ a \in  A $ 。由于 $ x $ 不在 $ \Gamma $ 中自由出现,那么根据命题 391,对每个 $ \psi  \in  \Gamma $ 都有 $ \sigma \left( {x/a}\right)  \vDash  \psi $ ,因而 $ \sigma \left( {x/a}\right)  \vDash  \Gamma $ 。因为 $ \Gamma  \vDash  \phi $ ,所以 $ \sigma \left( {x/a}\right)  \vDash  \phi $ 。由此可知: $ \sigma \left( {x/a}\right)  \vDash  \phi $ 对所有 $ a \in  A $ 都成立,进而根据 BSD, $ \sigma  \vDash  \forall {x\phi } $ 。∎

命题 415 对任意公式集 $ \Gamma $ ,任意公式 $ \phi $ 和 $ \psi $ 以及任意个体变项 $ x $ ,如果 $ \Gamma ,\phi  \vDash  \psi $ 且 $ x $ 既不在 $ \Gamma $ 也不在 $ \psi $ 中自由出现,那么 $ \Gamma ,\exists {x\phi } \vDash  \psi $ 。

证明 设 $ \Gamma ,\phi  \vDash  \psi $ 且 $ x $ 既不在 $ \Gamma $ 也不在 $ \psi $ 中自由出现。令 $ \mathfrak{A} = \langle A, I\rangle $ 为任意模型并令 $ \sigma $ 为 $ \mathfrak{A} $ 上的任意赋值。假设 $ \sigma  \vDash  \Gamma  \cup  \{ \exists {x\phi }\} $ 。我们证明 $ \sigma  \vDash  \psi $ 。 因为 $ \sigma  \vDash  \exists {x\phi } $ ,所以有 $ a \in  A $ 使得 $ \sigma \left( {x/a}\right)  \vDash  \phi $ 。既然 $ x $ 不在 $ \Gamma $ 中自由出现, 与命题 414 的证明类似,我们知道 $ \sigma \left( {x/a}\right)  \vDash  \Gamma $ ,所以有 $ \sigma \left( {x/a}\right)  \vDash  \Gamma  \cup  \{ \phi \} $ 。 由于 $ \Gamma ,\phi  \vDash  \psi $ ,于是 $ \sigma \left( {x/a}\right)  \vDash  \psi $ ; 而 $ x $ 又不在 $ \psi $ 中出现,所以根据命题 391, $ \sigma  \vDash  \psi $ 。

让我们考虑那些以联结词为主联结符号的公式。我们知道, 命题逻辑的真理定义 (定义 45) 和谓词逻辑的真理定义 (定义 383) 对联结词的解释是一样的, 而且命题逻辑的公式和谓词逻辑的公式在给定解释后都是非真即假的。由此我们知道, $ R\mathbf{{bc}} $ 或 $ x \equiv  y $ 这样的公式虽可真可假,但 $ R\mathbf{{bc}} \vee   \sim  R\mathbf{{bc}} $ 和 $ x \equiv  y \rightarrow  \left( {R\mathbf{{bc}} \rightarrow  x \equiv  y}\right) $ 这样的公式却一定是有效的。同时,命题 411- 413 也向我们 “暗示” 重言式和有效式、以及重言蕴涵和逻辑蕴涵之间有密切的关系。由此, 我们自然会期待一些一般性的结论, 比如:
