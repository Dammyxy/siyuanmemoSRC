2. 数学知识点

  • 根式方程（Radical Equations）：包含有变量在根号内的方程。
  • 两边平方原理：将方程的两边同时进行平方运算以消除平方根。这是解根式方程的主要方法。
  • 二项式平方展开：应用公式 (a + b)2 = a2 + 2ab + b2 来展开含有两项的表达式的平方，例如本题中的 (√x + 4)2。
  • 移项与合并同类项：对方程进行代数变形，将相似的项（如含x的项、常数项、含根式的项）合并，以简化方程。
  • 二次方程（Quadratic Equations）：形如 ax2 + bx + c = 0 的方程。本题通过两次平方最终得到了一个二次方程。
  • 因式分解（Factoring）：将一个多项式分解为几个更简单的多项式的乘积。这是解二次方程的常用方法之一。
  • 增根（Extraneous Solutions）：在解方程过程中（特别是通过两边平方），可能会产生不满足原方程的解。这些解被称为增根或无关解。
  • 解的检验（Verification）：将求出的潜在解代回原方程进行验证，是解根式方程必不可少的一步，用以排除增根。

3. 解题逻辑和思路

解决这类复杂的根式方程的策略如下：

  • 第一步：首次平方

    原方程两边都含有根式。策略是对方程两边同时进行平方。这一步可以消去左边的根号，但在右边，由于是二项式 (√x + 4) 的平方，展开后仍会留下一个根式项。

  • 第二步：分离剩余的根式

    在第一次平方和化简后，重新整理方程。将含有根式的项（8√x）分离到等式的一边，并将所有其他项（变量x和常数）移动到另一边，形成一个形如“根式 = 线性表达式”的结构。

  • 第三步：再次平方

    对整理后的方程两边再次进行平方。这个步骤将彻底消除方程中剩余的根号，从而得到一个不含根式的多项式方程（本例中为一元二次方程）。

  • 第四步：解多项式方程

    求解得到的一元二次方程。将所有项移到一边使方程等于零，然后通过因式分解（或使用求根公式）来找出潜在的解。本题中解出 x = 4 和 x = 100。

  • 第五步：验根（关键步骤）

    将每一个求得的潜在解（x=4 和 x=100）分别代回最原始的方程进行检验。这是必须的步骤，因为两边平方的操作可能引入不符合原方程的“增根”。

    • 检验 x = 4 发现等式不成立 (2 ≠ 6)，因此 x = 4 是一个增根，必须舍弃。
    • 检验 x = 100 发现等式成立 (14 = 14)，因此 x = 100 是一个有效解。
  • 第六步：得出结论

    舍弃所有增根后，剩下的有效解即为原方程的最终解。因此，本题的唯一解是 x = 100。
