引言

多项式方程是可以写成 Pn(x) = 0 形式的方程，其中 Pn(x) 是一个 n 次多项式。三次方程是 n = 3 的多项式方程。

要解一个没有常数项的多项式方程，我们使用最大公因式来因式分解多项式部分。完成这一步后，我们可以对得到的因式应用零积率。

例如，考虑三次方程 x3 − x = 0。

首先，注意多项式的所有项都有一个公因式 x。我们可以将 x 提取出来，如下所示：

x3 − x = 0

x(x2 − 1) = 0

现在，我们使用平方差公式来因式分解表达式 x2 − 1：

x(x2 − 1) = 0

x(x + 1)(x − 1) = 0

最后，通过应用零积率，我们得出解为 x = 0，x = −1，和 x = 1。

数学知识点

  • 多项式方程 (Polynomial Equation): 指可以表示为 Pn(x) = 0 形式的方程，其中 Pn(x) 是一个 n 次多项式。
  • 三次方程 (Cubic Equation): 指最高次数为 3 的多项式方程。
  • 因式分解 (Factoring): 将一个多项式分解为多个更简单的因式的乘积的过程。
  • 最大公因式 (Greatest Common Factor - GCF): 一个多项式中所有项共同拥有的最大的因式。
  • 平方差公式 (Difference of Squares): 一个代数公式，a2 − b2 = (a + b)(a − b)。
  • 零积率 (Zero Product Rule): 如果多个因子的乘积为零，那么至少有一个因子必须为零。

解题逻辑与思路

本文档演示了求解一类特殊多项式方程（无常数项）的通用策略，并通过一个三次方程的例子进行说明。其解题策略遵循以下步骤：

  1. 分析方程特征:
    • 首先识别出这是一个多项式方程，并观察到它没有常数项。在本例中，方程为 x3 − x = 0。
  2. 提取最大公因式:
    • 由于没有常数项，变量 x 必然是所有项的公因式。
    • 将 x 从方程中提取出来，得到 x(x2 − 1) = 0。
  3. 继续分解剩余因式:
    • 观察括号内的多项式 (x2 − 1)，判断是否可以进一步分解。
    • 识别出 x2 − 1 是一个平方差（即 x2 − 12）。
    • 应用平方差公式 a2 − b2 = (a + b)(a − b)，将其分解为 (x + 1)(x − 1)。
    • 此时，方程完全分解为 x(x + 1)(x − 1) = 0。
  4. 应用零积率求解:
    • 根据零积率，将每一个因式分别设为等于零，以找出所有可能的解。
    • 设置 x = 0。
    • 设置 x + 1 = 0，解得 x = −1。
    • 设置 x − 1 = 0，解得 x = 1。
  5. 得出最终结论:
    • 总结所有解，该方程的解集为 {0, −1, 1}。
