你提到的德摩根定律 (A∪B)' = A'∩B' 和 (A∩B)' = A'∪B'，它们处理的是“并集的补集”和“交集的补集”，非常有用。但你遇到的 P(A'∪B) 形式不同，它是一个补集和一个原集的并集，所以不能直接套用德摩根定律。

不过，确实有可以“速算”的定律或推论，其本质是基于集合的划分。我给你提供两种核心方法，其中第一种是最高效的。

方法一：最高效的“速算”方法（基于集合划分）

这个方法的核心思想是：将 A'∪B 拆解成两个互不相交的部分，这样它们的概率就可以直接相加。

Title: 核心定律/推论：P(A' ∪ B) = P(A') + P(A ∩ B)推导与理解（为什么这个定律成立）： 我们可以用文氏图来理解。

  1. A'∪B 指的是“不属于A的区域”与“属于B的区域”的并集。
  2. 想象一下，A' 是整个样本空间中除了A圆圈之外的所有区域。
  3. B 是B圆圈的全部。
  4. 把这两块区域合并在一起，你会发现 A' 已经包含了“只属于B而不属于A”的部分 (A'∩B)。为了构成完整的 A'∪B，我们还需要补充上被 A' 遗漏掉的那部分，而这部分恰好就是 A和B的交集 (A∩B)。
  5. 因为 A' 和 A∩B 这两个区域是互斥的（一个在A之外，一个在A之内），所以它们的并集概率可以直接相加。

计算步骤：

  1. 计算 P(A')： P(A') = 1 - P(A) = 1 - 0.4 = 0.6
  2. 直接使用已知条件 P(A ∩ B)： P(A ∩ B) = 0.1
  3. 相加得到结果： P(A' ∪ B) = P(A') + P(A ∩ B) = 0.6 + 0.1 = 0.7

这就是最快的计算方法。它把一个看似复杂的问题，转化成了一个补集概率和交集概率的简单加法。

方法二：更通用的标准方法（基于概率加法公式）

如果你没有想到方法一的巧妙拆分，也可以使用最基础的概率加法公式，这更具普适性。

核心定律（概率加法公式）： P(X ∪ Y) = P(X) + P(Y) - P(X ∩ Y)

计算步骤： 在这里，我们令 X = A'，Y = B。 P(A' ∪ B) = P(A') + P(B) - P(A' ∩ B)

我们需要分步计算出公式中的每一项：

  1. 计算 P(A')： P(A') = 1 - P(A) = 1 - 0.4 = 0.6
  2. P(B) 已知： P(B) = 0.3
  3. 计算 P(A' ∩ B)： A' ∩ B 的含义是“事件B发生，但事件A不发生”。这等价于从B的概率中减去A和B同时发生的部分。 P(A' ∩ B) = P(B) - P(A ∩ B) = 0.3 - 0.1 = 0.2
  4. 代入总公式： P(A' ∪ B) = 0.6 + 0.3 - 0.2 = 0.7

总结与对比

  • 方法一（速算）：P(A' ∪ B) = P(A') + P(A ∩ B)

    • 优点：步骤最少，计算最快，是解决这类特定问题的“捷径”。
    • 要求：需要你对集合的结构有更深刻的理解，能看出 A'∪B 可以被拆分为 A' 和 A∩B 这两个互斥事件。

  • 方法二（标准）：P(A' ∪ B) = P(A') + P(B) - P(A' ∩ B)

    • 优点：逻辑非常通用，适用于任何两个事件的并集，不容易出错。
    • 缺点：计算步骤稍多，需要额外计算 P(A' ∩ B)。

专业建议： 在解决问题时，两种方法都应该掌握。方法一能让你在处理特定结构时表现得更高效、更专业。方法二则是你的基本功，是解决所有并集问题的安全网。

最直观的辅助工具是文氏图。当你对公式感到困惑时，画一个文氏图，把已知概率填入对应的区域（交集、A独有、B独有、两者都无），所有问题都会迎刃而解。

对于本题，文氏图的四个区域概率为：

  • P(A ∩ B) = 0.1 (A和B的交集)
  • P(A ∩ B') = P(A) - P(A ∩ B) = 0.4 - 0.1 = 0.3 (只属于A)
  • P(A' ∩ B) = P(B) - P(A ∩ B) = 0.3 - 0.1 = 0.2 (只属于B)
  • P(A' ∩ B') = 1 - P(A∪B) = 1 - (0.3 + 0.2 + 0.1) = 0.4 (A和B都不属于)

P(A' ∪ B) 就是 P(A' ∩ B) + P(A ∩ B) + P(A' ∩ B') = 0.2 + 0.1 + 0.4 = 0.7。这与我们用公式算出的结果完全一致。
