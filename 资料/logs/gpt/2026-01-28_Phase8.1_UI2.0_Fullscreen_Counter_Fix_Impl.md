## 一、问题描述

### 问题 1: 全屏功能不完整 (P0)
**现象**: 点击全屏按钮后，界面没有填满整个屏幕，宽度仍受限于对话框的 maxWidth

**根因分析**:
- `dialog.ts:62` 设置了内联样式 `dialogContainer.style.maxWidth = '1024px'`
- 即使 CSS 设置了 `width: 100vw !important`，也无法覆盖内联样式的优先级
- 需要动态修改内联样式才能实现真正的全屏

### 问题 2: 提取练习计数器显示为 0 (P0)
**现象**: 提取练习界面的计数器没有正确显示剩余卡片数量，全部显示为 0

**根因分析**:
- `RetrievalPracticeAdapter` 期望 `stats.label` 格式为 `'新卡/复习卡'`（如 `'2/5'`）
- `ExtractionPracticeProvider.getStats()` 返回的 `label` 只是剩余数量（如 `'5'`）
- 解析失败导致 `newCards` 和 `reviewCards` 都是 0

### 2.2 提取练习计数器修复

#### 实施步骤

**Step 1**: 检测 label 格式

**文件**: `src/ui/review/v2/adapters/RetrievalPracticeAdapter.ts`
**位置**: lines 37-69

```typescript
// 从 label 解析新卡和复习卡数量（格式：'2/5' 表示 2 新卡，5 复习卡）
let statsNewCards = 0;
let statsReviewCards = 0;
let useParsedLabel = false;

if (stats.label && typeof stats.label === 'string' && stats.label.includes('/')) {
  const parts = stats.label.split('/');
  if (parts.length === 2) {
    statsNewCards = Number(parts[0]) || 0;
    statsReviewCards = Number(parts[1]) || 0;
    useParsedLabel = true;
  }
}

// 获取当前剩余数量和已复习数量
const statsRemaining = Number((stats as any)?.remaining) || 0;
const statsTotal = Number((stats as any)?.total) || 0;
const statsReviewed = Number((stats as any)?.reviewed) || 0;

// 如果没有从 label 解析出新卡/复习卡数量，使用 total 作为复习卡数量
let newCards = statsNewCards;
let reviewCards = statsReviewCards;
if (!useParsedLabel) {
  // 提取练习等模式：没有新卡/复习卡区分，所有卡片都是复习卡
  newCards = 0;
  reviewCards = statsTotal || statsRemaining;
}
```

**Step 2**: 计算当前剩余数量

**文件**: `src/ui/review/v2/adapters/RetrievalPracticeAdapter.ts`
**位置**: lines 141-144

```typescript
return {
  header: {
    stats: {
      current,
      currentNewCards: useParsedLabel ? newCards - Math.max(0, newCards - statsReviewed) : 0,
      currentReviewCards: useParsedLabel
        ? reviewCards - Math.max(0, reviewCards - Math.max(0, statsReviewed - newCards))
        : statsRemaining,
      total: Math.max(newCards + reviewCards, 0),
      label,
      queueName,
      newCards,
      reviewCards,
    },
    // ...
  },
};
```

**技术要点**:
- 使用 `label.includes('/')` 判断是否为 '新卡/复习卡' 格式
- 非标准格式时，使用 `total` 字段作为复习卡数量
- 计算当前剩余数量时区分两种模式

## 五、技术总结

### 关键发现

1. **内联样式优先级**: 需要将属性设置为空字符串才能被 CSS 覆盖
2. **SiYuan 原生全屏**: 使用 `position: fixed` + `width/height: 100vw/vh` + `z-index: 8`
3. **统计格式兼容**: 不同队列类型可能返回不同格式的统计数据
4. **事件冒泡处理**: 在按钮点击时需要阻止事件冒泡

### 设计模式

1. **动态样式修改**: 根据状态切换动态修改内联样式
2. **格式检测与兼容**: 使用特征检测（label.includes('/')）支持多种格式
3. **适配器扩展**: 单一适配器支持多种队列类型

- **SiYuan 原生实现**: `siyuan/app/src/assets/scss/main/_main.scss:28-56`
