## 三、技术要点

### 3.1 内联样式优先级处理

**问题**: CSS 的 `!important` 无法覆盖内联样式

**解决**: 动态设置内联样式为空字符串

```typescript
// 进入全屏：移除限制
dialogContainer.style.maxWidth = '';  // 空字符串

// 退出全屏：恢复限制
dialogContainer.style.maxWidth = '1024px';
```

### 3.2 SiYuan 原生全屏参考

**参考文件**: `siyuan/app/src/assets/scss/main/_main.scss:28-56`

**关键样式**:
```css
.fullscreen {
  position: fixed !important;
  top: 0 !important;
  left: 0 !important;
  width: 100% !important;
  height: 100vh !important;
  z-index: 8 !important;
  border-radius: 0 !important;
}
```

### 3.3 统计格式兼容性

**特征检测**: 使用 `label.includes('/')` 判断格式

```typescript
if (stats.label && typeof stats.label === 'string' && stats.label.includes('/')) {
  // '新卡/复习卡' 格式（如 '2/5'）
  const parts = stats.label.split('/');
  newCards = Number(parts[0]) || 0;
  reviewCards = Number(parts[1]) || 0;
} else {
  // 纯数字格式（如 '5'）
  newCards = 0;
  reviewCards = statsTotal || statsRemaining;
}
```

### 3.4 适配器扩展模式

**单一适配器支持多种队列**:
- `RetrievalPracticeAdapter` 同时服务于：
  - 提取练习（ExtractionPracticeProvider）
  - FSRS 复习（FSRSRetrievalProvider）
  - 其他需要新卡/复习卡区分的队列

**当前状态**: 对话框圆角样式已在 dialog.ts 中设置，但可能仍有视觉效果问题

**当前状态**: 全屏切换时直接修改样式，可能有轻微卡顿

**建议**:
- 添加 CSS 过渡动画
- 使用 `transform` 替代 `width/height` 改变

- 提高代码可维护性
