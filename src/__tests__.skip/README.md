# 旧架构测试文件

这个目录包含已废弃的旧架构测试文件。这些测试被保留用于参考，但不会在常规测试运行中执行。

## 为什么这些测试被跳过？

这些测试针对的是已经被新 DDD 架构替代的旧代码：
- 旧的 `StorageManager` (manager.ts) - 已被 `UnifiedStorageManager` 替代
- 旧的数据结构和接口
- 已废弃的功能模块

## 如何运行这些测试？

如果需要运行这些测试（例如用于迁移验证），可以：

```bash
# 运行特定的旧测试文件
npm test -- __tests__.skip/specific-test.test.ts
```

## 何时可以删除？

当确认新架构完全稳定且不再需要参考旧实现时，可以安全删除这个目录。
