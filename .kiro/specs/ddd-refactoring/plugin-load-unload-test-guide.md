# 插件加载/卸载手动测试指南

## 概述

本文档提供插件加载和卸载的手动测试清单，用于验证 DDD 架构重构后的 ApplicationContext 和服务生命周期管理是否正常工作。

**测试目标**：
- 验证插件可以正常加载和初始化所有服务
- 验证插件可以正常卸载并释放所有资源
- 验证插件重新加载后功能正常
- 验证错误处理和降级机制

**测试环境**：
- 思源笔记桌面版或移动版
- 开发者工具（F12）用于查看控制台日志

---

## 第一部分：插件加载测试

### 1.1 正常加载测试

**测试步骤**：
1. 打开思源笔记
2. 启用 SiYuanMemo 插件（如果已禁用）
3. 观察控制台日志（F12）

**预期结果**：
- ✅ 控制台显示 `[SiYuanMemo] Plugin loading...`
- ✅ 控制台显示 `[ApplicationContext] ✅ ApplicationContext created successfully`
- ✅ 控制台显示以下服务初始化日志：
  - `[ApplicationContext] ✅ All queues initialized`
  - `[ApplicationContext] ✅ XiuyuanService initialized`
  - `[ApplicationContext] ✅ Application services initialized`
  - `[ApplicationContext] ✅ UnifiedDataSourceManager initialized with Advanced mode`
- ✅ 控制台显示 `[SiYuanMemo] Plugin loaded successfully`
- ✅ 顶部工具栏出现 SiYuanMemo 图标（间隔重复系统）
- ✅ 没有错误日志

**验证点**：
- [ ] 插件图标正常显示
- [ ] 控制台无错误
- [ ] 所有服务初始化成功

---

### 1.2 服务初始化验证

**测试步骤**：
1. 插件加载完成后
2. 在控制台执行以下命令验证服务可访问：

```javascript
const plugin = window.siyuanMemoPlugin;

// 验证核心服务
console.log('Storage:', plugin.storage);
console.log('Scheduler:', plugin.schedulerRouter);
console.log('UnifiedDataSourceManager:', plugin.unifiedDataSourceManager);

// 验证队列
console.log('RetrievalQueue:', plugin.retrievalQueue);
console.log('FinalDrillQueue:', plugin.finalDrillQueue);
console.log('IncrementalQueue:', plugin.incrementalQueue);

// 验证 Xiuyuan 服务
console.log('XiuyuanService:', plugin.xiuyuanService);
console.log('XiuyuanStorage:', plugin.xiuyuanStorage);
```

**预期结果**：
- ✅ 所有服务对象都不为 `undefined` 或 `null`
- ✅ 每个服务都有预期的方法和属性

**验证点**：
- [ ] 核心服务可访问
- [ ] 队列服务可访问
- [ ] Xiuyuan 服务可访问

---

### 1.3 UI 管理器懒加载验证

**测试步骤**：
1. 插件加载完成后
2. 在控制台执行：

```javascript
const plugin = window.siyuanMemoPlugin;
const context = plugin.context;

// 验证 UI 管理器尚未创建（懒加载）
console.log('DialogManager created:', context.isServiceCreated('dialogManager'));
console.log('MenuManager created:', context.isServiceCreated('menuManager'));
console.log('TabManager created:', context.isServiceCreated('tabManager'));
```

**预期结果**：
- ✅ 所有 UI 管理器显示 `false`（尚未创建）

**验证点**：
- [ ] UI 管理器采用懒加载策略

### 1.4 UI 功能触发验证

**预期结果**：

## 第二部分：插件卸载测试

2. 观察控制台日志（F12）

**预期结果**：
- ✅ 控制台显示 `[ApplicationContext] Starting disposal...`
- ✅ 控制台显示以下服务停止日志：
  - `[ApplicationContext] ✅ TransactionWebSocketService stopped`（如果启用）
  - `[ApplicationContext] ✅ Full sync timer cleared`（如果启用）
  - `[ApplicationContext] ✅ HybridSyncService stopped`（如果启用）
- ✅ 控制台显示 `[ApplicationContext] Saving storage data...`
- ✅ 控制台显示 `[ApplicationContext] Storage data saved successfully`
- ✅ 控制台显示 `[ApplicationContext] Disposed successfully`
- ✅ 顶部工具栏的 SiYuanMemo 图标消失
- ✅ 没有错误日志

**验证点**：
- [ ] 插件图标消失
- [ ] 所有服务正常停止
- [ ] 数据正常保存
- [ ] 控制台无错误

---

### 2.2 资源释放验证

**测试步骤**：
1. 插件卸载后
2. 在控制台执行：

```javascript
const plugin = window.siyuanMemoPlugin;

// 验证插件对象仍然存在（但已标记为已销毁）
console.log('Plugin exists:', !!plugin);
console.log('Context disposed:', plugin.context?.isDisposed());
```

**预期结果**：
- ✅ 插件对象存在但上下文已标记为已销毁
- ✅ `context.isDisposed()` 返回 `true`

**验证点**：
- [ ] 上下文正确标记为已销毁

---

### 2.3 事件监听器清理验证

**测试步骤**：
1. 插件卸载后
2. 检查顶部工具栏图标是否移除
3. 尝试右键点击原图标位置（如果仍可见）

**预期结果**：
- ✅ 图标已移除或不响应事件
- ✅ 没有事件监听器泄漏

**验证点**：
- [ ] 事件监听器已清理

---

### 2.4 定时器清理验证

**测试步骤**：

3. 观察控制台，确认没有定时器继续执行

**预期结果**：
- ✅ 全量同步定时器已停止
- ✅ 没有定时器相关的日志或错误

**验证点**：
- [ ] 定时器已清理

## 故障排查指南

### 问题 1：插件加载失败

**症状**：
- 控制台显示 `[SiYuanMemo] Plugin initialization failed:`
- 插件图标不显示

**可能原因**：
1. 数据文件损坏
2. 配置文件格式错误
3. 依赖服务初始化失败

**排查步骤**：
1. 检查控制台完整错误堆栈
2. 检查数据文件是否存在且格式正确
3. 尝试删除数据文件重新初始化
4. 检查是否有其他插件冲突

---

### 问题 2：插件卸载失败

**症状**：
- 控制台显示卸载错误
- 插件图标仍然显示
- 事件监听器未清理

**可能原因**：
1. 服务停止失败
2. 数据保存失败
3. 事件监听器移除失败

**排查步骤**：
1. 检查控制台错误日志
2. 检查哪个服务停止失败
3. 手动清理残留资源
4. 重启思源笔记

---

### 问题 3：重新加载后数据丢失

**症状**：
- 卡片数据丢失
- 设置重置为默认值

**可能原因**：
1. 数据保存失败
2. 数据文件被删除
3. 数据格式不兼容

**排查步骤**：
1. 检查数据文件是否存在
2. 检查数据文件修改时间
3. 检查控制台保存日志
4. 尝试从备份恢复

---

### 问题 4：内存泄漏

**症状**：
- 多次重载后内存持续增长
- 思源笔记变慢

**可能原因**：
1. 事件监听器未清理
2. 定时器未清理
3. 服务引用未释放

**排查步骤**：
1. 使用 Memory Profiler 检查内存快照
2. 对比加载前后的对象数量
3. 检查是否有未清理的监听器或定时器
4. 检查服务容器是否正确清空

---

### 问题 5：UI 功能异常

**症状**：
- 对话框无法打开
- 菜单不显示
- Tab 无法切换

**可能原因**：
1. UI 管理器初始化失败
2. 依赖服务未就绪
3. 事件路由错误

**排查步骤**：
1. 检查 UI 管理器是否创建成功
2. 检查依赖服务是否可访问
3. 检查事件监听器是否正确注册
4. 检查控制台错误日志

## 总结

本测试指南涵盖了插件加载/卸载的所有关键场景：

1. **正常流程**：加载、卸载、重载
