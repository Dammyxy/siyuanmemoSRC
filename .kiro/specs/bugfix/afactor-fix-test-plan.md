# A-Factor 修复测试计划

## 修复内容

修复了 Topic 卡片的 A-Factor 在【编辑SRS数据】对话框中显示为 "-" 的问题。

## 根本原因

`XiuyuanRepository.cardToFSRSCard()` 方法在将 `Card` 转换为 `FSRSCard` 时，没有将 `Xiuyuan.meta.aFactor` 复制到 `FSRSCard.aFactor`。

## 修复方案

在 `XiuyuanRepository.cardToFSRSCard()` 方法中添加：

```typescript
// 🔧 修复：A-Factor（从 Xiuyuan.meta 复制到 FSRSCard）
aFactor: meta.aFactor,
```

## 测试步骤

### 测试 1：新建 Topic 卡片的 A-Factor 初始化

**步骤**：
1. 在思源笔记中创建一个新的文档块
2. 将其添加为 Topic 卡片（通过插件菜单）
3. 打开【编辑SRS数据】对话框
4. 查看 A-Factor 字段

**预期结果**：
- A-Factor 应该显示一个数值（1.2-6.0 范围内）
- 不应该显示 "-"

**验证点**：
- 核心状态概览区域显示 A-Factor
- 元数据区域显示 A-Factor
- 两处显示的值应该一致

### 测试 2：评分后 A-Factor 更新

**步骤**：
1. 对一个 Topic 卡片进行复习
2. 给出评分（Good 或 Easy）
3. 再次打开【编辑SRS数据】对话框
4. 查看 A-Factor 字段

**预期结果**：
- A-Factor 应该显示更新后的数值
- 数值应该在 1.2-6.0 范围内
- 不应该显示 "-"

### 测试 3：不同优先级的 A-Factor 初始值

**步骤**：
1. 创建 3 个 Topic 卡片，设置不同的优先级：
   - 卡片 A：优先级 0
   - 卡片 B：优先级 50
   - 卡片 C：优先级 100
2. 分别打开【编辑SRS数据】对话框
3. 查看 A-Factor 字段

**预期结果**：
- 卡片 A：A-Factor ≈ 1.2
- 卡片 B：A-Factor ≈ 3.6
- 卡片 C：A-Factor ≈ 6.0

**公式**：`aFactor = 1.2 + (priority / 100) * 4.8`

### 测试 4：Item 卡片不显示 A-Factor

**步骤**：
1. 创建一个 Item 卡片（包含挖空符号）
2. 打开【编辑SRS数据】对话框
3. 查看 A-Factor 字段

**预期结果**：
- A-Factor 应该显示 "-"
- 因为 Item 卡片不使用 A-Factor 算法

5. 查看 A-Factor 字段
