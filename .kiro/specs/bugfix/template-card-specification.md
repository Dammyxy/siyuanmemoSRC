# 模版卡片规范文档

## 概述

本文档规范了右键块菜单中【创建模版卡片】功能的所有可用模版及其作用。

## 访问路径

1. 选中一个或多个块
2. 右键点击块图标
3. 选择"创建模版卡片"
4. 在弹出的对话框中选择模版

## 可用模版列表

### 1. 基础问答 (builtin-basic-qa)

**描述**: 简单的问答卡片，第一个块为问题，第二个块为答案

**字段**:
- question: 问题
- answer: 答案

**卡片规则**:
- 正面: question
- 反面: answer

**使用场景**: 最基础的问答卡片，适用于简单的知识点记忆

---

### 2. 双向卡片 (builtin-bidirectional)

**描述**: 生成正向和反向两张卡片（需要两个块）

**字段**:
- term: 术语
- definition: 定义

**卡片规则**:
- 卡片1（正向）: term → definition
- 卡片2（反向）: definition → term

**使用场景**: 需要双向记忆的内容，如术语-定义、单词-释义等

---

### 3. 快速制卡双向 (builtin-quick-bidirectional)

**描述**: 单块生成正向和反向两张卡片（用于 `<>` 符号）

**字段**:
- content: 包含 `<>` 符号的块内容

**卡片规则**:
- 卡片1（正向）: content（左侧） → content（右侧）
- 卡片2（反向）: content（右侧） → content（左侧）

**示例**:
```markdown
DDD <> 领域驱动设计
```

**使用场景**: 快速创建双向卡片，只需一个块，通过 `<>` 分隔

---

### 4. 填空卡片 (builtin-cloze)

**描述**: 包含填空位置的卡片

**字段**:
- content: 包含填空的内容

**卡片规则**:
- 正面: content（隐藏填空）
- 反面: content（显示填空）

**使用场景**: 需要填空记忆的内容

---

### 5. 多填空卡片 (builtin-multi-cloze)

**描述**: 每个填空生成一张独立的卡片

**字段**:
- content: 包含多个填空的内容

**支持的填空符号**:
- `{{填空内容}}`
- `==填空内容==`

**示例**:
```markdown
==线粒体==是细胞的==能量工厂==，负责生成==ATP==
```

生成3张卡片：
- 卡片1: [___]是细胞的能量工厂，负责生成ATP → 线粒体
- 卡片2: 线粒体是细胞的[___]，负责生成ATP → 能量工厂
- 卡片3: 线粒体是细胞的能量工厂，负责生成[___] → ATP

**使用场景**: 一个句子中有多个需要记忆的关键词

---

### 6. 列表项模版 (builtin-list-item)

**描述**: 父列表项作为问题，每个子列表项作为独立答案

**字段**:
- question: 问题（父列表项）
- answer: 答案（子列表项）

**示例**:
```markdown
- 什么是 FSRS？（父列表项）
  - FSRS 是一种间隔重复算法（子级1 → 卡片1的答案）
  - 它基于记忆遗忘曲线（子级2 → 卡片2的答案）
  - 可以优化复习时间（子级3 → 卡片3的答案）
```

生成3张卡片，每张卡片的正面都是"什么是 FSRS？"，背面分别是3个子级列表项。

**使用场景**: 一个问题有多个要点需要分别记忆

---

### 7. 概念-描述符 (builtin-concept-descriptor)

**描述**: 用于概念及其属性的卡片

**字段**:
- concept: 概念块
- descriptor: 描述符块

**示例**:
```markdown
线粒体 :: 细胞的能量工厂
  ├─ 起源 ;; 被认为是通过内共生起源的
  ├─ 功能 ;; 为细胞生成ATP
  └─ 结构 ;; 具有双层膜结构
```

**卡片规则**:
- 正面: 概念 + 描述符标题
- 反面: 概念定义 + 描述符内容

**使用场景**: 概念的多个属性需要分别记忆

---

### 8. 概念定义 (builtin-concept-definition)

**描述**: 用于概念及其定义的卡片

**字段**:
- concept: 概念块（块引用指向的文档块）
- definition: 定义块（包含 `::` 符号的块）

**示例**:
```markdown
[[思源]]::本地 PKM 软件
```

**卡片规则**:
- 正面: 概念名称
- 反面: 定义

**支持定义挖空**:
```markdown
[[思源]]::本地 ==PKM== 软件
```

**使用场景**: 为已存在的概念文档添加定义卡片

---

### 9. 概念卡（简单）(builtin-concept-simple)

**描述**: 单块概念卡，用于记忆概念、术语、定义

**字段**:
- concept: 概念的内容块

**卡片规则**:
- 正面: concept
- 反面: concept
- 卡片类型: concept

**使用场景**: 
- 记忆概念、术语、定义
- 自动检测引用创建概念卡
- 手动制作概念卡

**特点**: 正反面显示相同内容，主要用于概念的识别和记忆

---

### 10. 符号问答卡 (builtin-symbol-qa)

**描述**: 通过 `<>` 符号标记的问答卡

**字段**:
- content: 包含问答符号的内容块

**卡片规则**:
- 正面: content（问题部分）
- 反面: content（答案部分）
- 卡片类型: qa

**示例**:
```markdown
<什么是 DDD？>
```

**使用场景**: 
- 自动检测 `<问题>` 符号创建问答卡
- 符号检测制卡
- 快速标记问题

**特点**: 通过 `<>` 符号自动识别问题，适合在阅读时快速标记

---

### 11. 快速卡片 (builtin-quick-card)

**描述**: 快速创建的单块卡片

**字段**:
- content: 卡片内容块

**卡片规则**:
- 正面: content
- 反面: content
- 卡片类型: basic

**使用场景**: 
- 快速制卡
- 默认卡片创建
- 简单的单块记忆

**特点**: 最简单的卡片类型，适合快速创建基础记忆卡片

---

## 模版选择建议

### 按使用频率

1. **高频使用**:
   - 基础问答 (builtin-basic-qa)
   - 填空卡片 (builtin-cloze)
   - 多填空卡片 (builtin-multi-cloze)

2. **中频使用**:
   - 双向卡片 (builtin-bidirectional)
   - 列表项模版 (builtin-list-item)
   - 概念定义 (builtin-concept-definition)

3. **特殊场景**:
   - 快速制卡双向 (builtin-quick-bidirectional)
   - 概念-描述符 (builtin-concept-descriptor)
   - 概念卡（简单）(builtin-concept-simple)
   - 符号问答卡 (builtin-symbol-qa)
   - 快速卡片 (builtin-quick-card)

### 按块数量

- **单块**: 填空卡片、多填空卡片、快速制卡双向
- **双块**: 基础问答、双向卡片
- **多块**: 列表项模版
- **特殊结构**: 概念-描述符、概念定义

## 规范建议

### 1. 模版命名规范

建议统一模版命名格式：
- 中文名称应简洁明了
- 英文 ID 使用 `builtin-` 前缀
- 描述应说明使用场景和块数量要求

### 2. 模版分类

建议将模版分为以下类别：

**基础类**:
- 基础问答
- 双向卡片

**填空类**:
- 填空卡片
- 多填空卡片

**列表类**:
- 列表项模版

**概念类**:
- 概念定义
- 概念-描述符
- 概念卡（简单）

**快速制卡类**:
- 快速制卡双向
- 快速卡片
- 符号问答卡

### 3. UI 改进建议

1. **分类显示**: 在模版选择对话框中按类别分组显示
2. **使用提示**: 为每个模版添加"需要块数量"的提示
3. **预览功能**: 显示模版生成的卡片示例
4. **常用模版**: 支持标记常用模版，置顶显示
5. **搜索功能**: 支持按名称或描述搜索模版

### 4. 模版字段类型说明

所有模版的字段都支持以下类型：
- **block**: 块内容，可以是文本、图片、代码等
- **text**: 纯文本内容
- **reference**: 块引用

### 5. 卡片类型说明

模版生成的卡片可以有以下类型：
- **basic**: 基础卡片
- **concept**: 概念卡片
- **qa**: 问答卡片
- **cloze**: 填空卡片
- **list-qa**: 列表问答卡片
- **concept-descriptor**: 概念描述符卡片
- **concept-definition**: 概念定义卡片
